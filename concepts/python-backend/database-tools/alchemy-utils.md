# alchemy-utils 0.1a0

The article announces the alpha release of alchemy-utils, a Python library and CLI that extends the core API of sqlite-utils to multiple database engines using SQLAlchemy. The project was created as a research spike using AI coding agents Codex and GPT-5.6 Sol Ultra, with a prompt to replicate sqlite-utils methods like insert, upsert, insert_all, and table introspection, while supporting PostgreSQL, SQLite, and DuckDB. Development used uv for project initialization, red/green TDD with pytest, and PostgreSQL tests modeled after django-sql-dashboard. The article demonstrates usage examples: listing rows from a PostgreSQL database with uvx, and inserting a CSV of San Francisco trees into DuckDB, noting performance optimization reduced runtime from nearly an hour to about 35 seconds.

- alchemy-utils is a database-agnostic reimplementation of sqlite-utils built on SQLAlchemy.
- It supports PostgreSQL, SQLite, and DuckDB with the same core API for inserts, upserts, and table introspection.
- The prototype was generated by Codex and GPT-5.6 with minimal follow-up, then released as an alpha.
- Example commands show how to query Postgres and load CSV data into DuckDB via `uvx`.
- The project uses uv, pytest TDD, and was optimized for performance (CSV loading from ~1 hour to ~35 seconds).
