# Profiling web-edit with Python 3.15: flame graphs and source heatmaps

Simon Willison tested the new Python 3.15 sampling profiler by having GPT-6 Astra Extra High in Codex run it against his web-edit app. The prompt was: "I need a Python 3.15 flame graph and heatmap demo of the 'web-edit' app from PyPI - research first then make me those demos" (source).

The exercise produced two demo artifacts: an interactive flame graph and a source heatmap, both published as HTML pages (source). The flame graph visualizes call-stack sampling over time, while the heatmap maps profiling data back onto source lines.

The post frames this as a practical demonstration of the new Python 3.15 profiler, which is described as a sampling profiler (source). The research repo contains the full methodology and generated outputs.

- Python 3.15 introduces a new sampling profiler.
- The profiler was applied to the web-edit app from PyPI.
- Outputs include an interactive flame graph and a source heatmap.
- The demo was generated by GPT-6 Astra Extra High in Codex from a single prompt.
