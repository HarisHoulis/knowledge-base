# Cloudflare Details Its Migration from WordPress to EmDash

Cloudflare recently documented the migration of its main blog from WordPress to EmDash, the open source content management system developed internally (InfoQ).

The new platform is designed to improve performance and caching, and it was tested to handle traffic of up to 7000 requests per second (InfoQ).

- Cloudflare migrated its main blog from WordPress to its internally developed open source CMS, EmDash (InfoQ).
- The EmDash platform was designed to improve performance and caching (InfoQ).
- The migration was tested to handle traffic of up to 7000 requests per second (InfoQ).
