# How to get started with programming

Kent C. Dodds argues that beginners should avoid focusing on "learning to code" in the abstract and instead focus on solving a problem that interests them. He calls this approach "learning backwards": start with what you want to create, then learn the things you need to accomplish that goal. This makes the subject, which is all about abstraction, feel less abstract.

Dodds addresses three common obstacles to picking a first idea: having too many ideas, having overly ambitious ideas, and having no ideas at all. His advice is to choose just one idea and accept that the first program you write will have "a LOT of problems." To generate an idea, he suggests identifying a hobby and finding a repetitive task within it, then building a simple program to automate that task. He gives a personal example: a program that helps his group decide which board or card game to play.

For learning, Dodds recommends Scratch as a code-free way to pick up foundational concepts like variables, loops, conditional statements, and events. For actual coding he suggests JavaScript, citing its balance of approachability, ubiquity, and capability, and noting it was the most commonly used language in the Stack Overflow Survey 2018. Beginners can start writing JavaScript immediately in the browser's developer console (e.g., typing `1 + 2`), and can save work in an HTML file using a `<script>` tag. He recommends installing VSCode and, for deeper study, the "You Don't Know JS" book series.

Dodds emphasizes that there is no shortcut to experience: the more time spent writing code, the better one gets, and "the process of success/failure is where you'll do the bulk of your learning." Once a few simple programs are written, he advises returning to the original problem and building the simplest possible version, without expecting it to look amazing or work perfectly.

- Don't focus on learning to code—focus on solving a problem that interests you ("learning backwards").
- To find a first idea, pick a hobby and automate a repetitive task within it; choose one idea and accept the first version will have many problems.
- Use Scratch to learn foundational concepts (variables, loops, conditionals, events) without writing code.
- JavaScript is recommended for its balance of approachability, ubiquity, and capability, and can be run directly in the browser's developer console.
- There's no shortcut to experience—the bulk of learning happens through the process of trying, succeeding, and failing.
