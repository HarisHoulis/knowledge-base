# Build vs Buy: Component Libraries edition

Ultimately, the article advises a balanced approach between build and buy, acknowledging that many companies should have a component library but should avoid reinventing well-solved problems. The decision to build should be based on actual business needs rather than the excitement of creating perfect abstractions.

- Mature open-source component libraries exist for common UI elements, making it wasteful to build them from scratch.
- Resistance to existing APIs may stem from familiarity rather than genuine issues; evaluate critically.
- Companies should build their own component library to wrap and limit capabilities of existing components for consistency.
- Components unique to the application or composed of lower-level primitives are good candidates for internal libraries.
- Focus on business sustainability and avoid building for fun; only build when necessary for success.
