# The Web Browser as a Powerful, Cheapening Application Platform

In a short quoted excerpt, Paul Ford argues that the web browser is "very, very, very powerful software for applications," and that the cost of accessing that power is falling "seemingly every day." The claim frames the browser as a capable application platform rather than merely a document viewer.

The emphasis is on the declining cost of tapping into browser capabilities, suggesting that building on the web is becoming more accessible over time. Simon Willison surfaces the quote under tags for browsers, Paul Ford, and web development.

- The browser is characterized as very powerful software for building applications.
- The cost of accessing that power is described as declining continually.
- The framing positions the web as an increasingly accessible application platform.
