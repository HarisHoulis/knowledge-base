# Why No One Dethroned React

Kent C. Dodds responds to Dax's question about why no framework has dethroned React, arguing that React's success was initially functional, then social and emotional as it reached mass adoption. In the early days, React offered unique functional advantages: a simple state mechanism that kept UI in sync, a strong composition model that allowed reusable components with minimal abstraction leaks, and the ability to be embedded into existing projects incrementally. These made React significantly easier for developers coming from Backbone.js or Angular.js, including Dodds himself.

- React's initial success was due to concrete functional benefits: easy state-to-UI synchronization, component composition, and incremental adoption in existing codebases.
- As React reached mass adoption, its moat became social/emotional and ecosystem-driven, not purely technical.
- Dodds previously predicted React would be the last UI library developers need to learn because AI would soon build applications, and he believes that is now happening.
- With AI coding assistants, framework choice matters less; Dodds finds models like those used with Remix can work well even if the framework wasn't heavily represented in training data.
