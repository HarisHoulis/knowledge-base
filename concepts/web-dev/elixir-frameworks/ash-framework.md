# Ash Framework: Declarative Elixir Web Apps

This GOTO Book Club conversation features host Christian Alexander interviewing Rebecca Le and Zach Daniel, co-authors of a book on the Ash Framework and maintainers of the framework itself. Rebecca, a core team member who has worked with Ash since version 1.x, describes her focus on the front-end and UI layer, including libraries like Cinder, a data table library for Ash that supports easy sorting and filtering, as well as documentation and book writing. Zach, the creator of Ash, recalls the early 1.0 days at Alembic, acknowledging that the initial 1.0 barely deserved that status and was a difficult trip, and credits Rebecca as a constructive critic who used the framework for real client work and kept pushing it forward.

- Ash is an Elixir framework maintained by a core team including Rebecca Le and Zach Daniel, who co-authored a book about it.
- Rebecca Le focuses on the front-end/UI layer, including the Cinder data table library for Ash.
- Zach Daniel created Ash and admits the early 1.0 release was rough and barely deserved the version number.
- The book was written to fill a gap the authors themselves experienced when learning Ash.
