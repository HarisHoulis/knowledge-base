# Uber Eats Rebuilds Search Pipeline to Cut End-to-End Latency by 50%

Uber has rebuilt major parts of the Uber Eats search pipeline, reporting a 50% reduction in end-to-end latency [1].

The changes include Above-the-Fold measurement, reduced retrieval work, parallel hydration, advertising data redesign, infrastructure optimizations, and an agentic coding workflow [1].

Uber is also exploring microbatching, product-based retrieval, and HTTP multipart streaming [1].
