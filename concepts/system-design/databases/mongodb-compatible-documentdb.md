# Open Source DocumentDB 1.0 Reaches General Availability

DocumentDB 1.0 is the first generally available release of an open source, MIT-licensed document database built on PostgreSQL, offering compatibility with the MongoDB wire protocol (InfoQ). Because it speaks the MongoDB wire protocol, most MongoDB drivers, tools, and queries work without changes, lowering migration friction for teams already invested in MongoDB tooling. The release pairs PostgreSQL's storage and operational maturity with a document-oriented interface, positioning it as an open alternative for document workloads.

- DocumentDB 1.0 is the first GA release, MIT-licensed and built on PostgreSQL
- It is compatible with the MongoDB wire protocol
- Most MongoDB drivers, tools, and queries work without changes
