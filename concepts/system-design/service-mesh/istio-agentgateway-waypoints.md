# Istio 1.31 Adds Agentgateway Waypoints and Moves Release Artifacts off Google Cloud

Istio 1.31 introduces agentgateway waypoints in ambient mode, with a canary configuration fix included in 1.31.1 (InfoQ). The release also ends the publication of images and Helm charts to Google Cloud, requiring repository migration ahead of the 13 October outage test and signing-key updates for teams verifying images (InfoQ).

- Istio 1.31 adds agentgateway waypoints for ambient mode.
- A canary configuration fix is included in Istio 1.31.1.
- Images and Helm charts are no longer published to Google Cloud, requiring repository migration.
- Migration must occur ahead of the 13 October outage test.
- Signing-key updates are required for teams verifying images.
