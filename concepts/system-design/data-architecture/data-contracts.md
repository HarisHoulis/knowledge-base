# Data Contracts

Data contracts describe the contents and guarantees of datasets, applying API-design practices to data by treating datasets as data-providing services—such as data products—whose interfaces should be defined as clearly as possible. Simon Harrer and Arif Wider detail what data contracts are and how to use them.

The approach significantly increases the robustness of large-scale data landscapes. It also gives both people and AI agents the explicit, trustworthy metadata they need to work with data autonomously, which is why more and more enterprises are adopting data contracts.

- Data contracts describe the contents and guarantees of datasets, applying API-design practices to data.
- Datasets are treated as data-providing services (data products) with clearly defined interfaces.
- They increase the robustness of large-scale data landscapes.
- They provide explicit, trustworthy metadata that lets people and AI agents work with data autonomously.
