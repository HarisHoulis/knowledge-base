# Google Cloud Adds Self-Managed VMware Cloud Foundation on Bare Metal

Google Cloud has made a self-managed VMware solution generally available, running VMware Cloud Foundation 9.x on dedicated Z3 bare metal with root access across ESXi, vCenter and NSX in 22 regions (InfoQ). It sits alongside the existing Google-managed VMware Engine, giving customers a choice between a fully managed offering and one they operate themselves.

The offering matches customer-operated VMware options from AWS and Oracle, shifting lifecycle management, patching and Broadcom licensing responsibilities back to the customer. This positions Google Cloud to serve organizations that need VMware compatibility but want direct control over the stack.

- Self-managed VMware Cloud Foundation 9.x runs on dedicated Z3 bare metal with root access to ESXi, vCenter and NSX.
- Available in 22 regions alongside the Google-managed VMware Engine.
- Shifts lifecycle, patching and Broadcom licensing responsibility to the customer.
- Matches customer-operated VMware offerings from AWS and Oracle.
