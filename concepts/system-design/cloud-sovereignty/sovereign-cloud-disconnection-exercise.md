# AWS Runs European Sovereign Cloud Without Global Backbone for Several Hours

AWS plans to operate its European Sovereign Cloud without a connection to the AWS Global Network backbone on October 24, using a team of EU residents along with the region's own hardware and software [InfoQ]. The exercise severs two systems, which AWS states are not operation-critical.

The announcement has drawn divided reactions among practitioners, who question whether the test actually answers the question customers are asking about true operational independence [InfoQ]. The core tension is between demonstrating regional self-sufficiency and the limited scope of the systems being disconnected.

- AWS will run its European Sovereign Cloud disconnected from the AWS Global Network backbone for several hours on October 24.
- The operation relies on EU-resident staff and the region's own hardware and software.
- AWS says neither of the two severed systems is operation-critical.
- Practitioners are divided on whether the exercise addresses customers' actual sovereignty concerns.
