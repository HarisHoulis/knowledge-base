# Azure Logic Apps Standard Gets a Local CLI in Preview

Microsoft has released a public preview of the logicapp extension for the Azure CLI, bringing Logic Apps Standard development into the terminal. The extension supports local project creation, workflow authoring, a runtime lifecycle, connector management, run inspection, and test scaffolding—capabilities that previously required the VS Code extension (Wiggers, InfoQ).

The product team frames the terminal surface as a source of determinism for AI-assisted development, suggesting that scriptable, CLI-driven workflows are easier for automated agents to drive and reproduce than GUI-based tooling.

- The logicapp Azure CLI extension is in public preview for Logic Apps Standard.
- It covers project creation, workflow authoring, runtime lifecycle, connectors, run inspection, and test scaffolding.
- These tasks previously required the VS Code extension.
- Microsoft positions the CLI as deterministic tooling for AI-assisted development.
