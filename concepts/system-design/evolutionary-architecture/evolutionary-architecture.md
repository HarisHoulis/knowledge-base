# Mini book: Evolutionary Architecture in Practice

InfoQ's mini book addresses how to keep software evolvable as systems, technology, and teams shift. It frames evolution as an ongoing concern rather than a one-time design decision, arguing for moving beyond static diagrams toward continuous feedback systems that keep change safe and intentional.

The edition highlights several practices: agentic fitness functions to detect semantic drift, treating human comprehension as a core design metric, cross-cloud guardrails that preserve regional autonomy, and aligning technical boundaries with Conway's Law. Together these ideas position architecture as something continuously guided by feedback rather than fixed upfront.

- Evolutionary architecture replaces static diagrams with continuous feedback systems that keep change safe and intentional.
- Agentic fitness functions can detect semantic drift as systems evolve.
- Human comprehension should be treated as a core design metric.
- Cross-cloud guardrails enable regional autonomy while maintaining alignment.
- Technical boundaries should be aligned with Conway's Law.
