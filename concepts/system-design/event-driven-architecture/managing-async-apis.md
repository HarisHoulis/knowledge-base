# Managing Asynchronous APIs at Scale

Ian Cooper discusses managing asynchronous APIs in event-driven architectures at scale. He explains the "ABCs" of messaging—Address, Binding, and Contract—as a framework for async API work. (Ian Cooper, "Presentation: Managing Asynchronous APIs at Scale," InfoQ)

The talk addresses discovery, governance, and provisioning for async APIs at scale. It cites AsyncAPI, CloudEvents, and schema registries as tools used to handle these concerns. (Source)

Cooper shares automated CI/CD infrastructure pipelines and real-world engineering practices from Just Eat Takeaway. (Source)

- Async APIs in event-driven architectures require managing discovery, governance, and provisioning at scale.
- The "ABCs" of messaging—Address, Binding, Contract—provide a framing for async API design and operation.
- The talk covers AsyncAPI, CloudEvents, and schema registries as relevant tooling.
- Automated CI/CD infrastructure pipelines are used based on real-world engineering practices at Just Eat Takeaway.
