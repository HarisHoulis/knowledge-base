# Cloudflare Basin: Serverless Analytics on Apache Iceberg and R2

Cloudflare has announced the general availability of Basin, a managed serverless analytics platform built on Apache Iceberg and R2 Object Storage (InfoQ, Losio). The service emphasizes open data formats and interoperability, integrating with tools such as DuckDB, Snowflake, and Apache Spark.

A notable commercial characteristic is the absence of data egress fees, positioning the offering around open formats and low-friction data access rather than lock-in.

- Basin is a serverless analytics platform built on Apache Iceberg and R2 Object Storage
- It supports open data formats and integrates with DuckDB, Snowflake, and Apache Spark
- The service has no data egress fees
