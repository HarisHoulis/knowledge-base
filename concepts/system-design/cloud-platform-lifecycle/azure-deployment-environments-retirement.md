# Microsoft Retires Azure Deployment Environments with No Replacement Product

Microsoft is retiring Azure Deployment Environments (ADE) on February 22, 2027, and has named no successor product, directing teams instead to use Bicep or ARM templates directly. Microsoft Dev Box follows with a retirement date of September 18, 2028, with Microsoft pointing users to Windows 365 while acknowledging it is not a one-to-one replacement. Remaining Dev Box workloads should expect deletion.

The announcement, reported by Steef-Jan Wiggers for InfoQ, signals a shift away from managed environment provisioning services toward direct infrastructure-as-code tooling. Teams relying on ADE for templated environment creation will need to migrate to Bicep or ARM templates before the 2027 cutoff.

- Azure Deployment Environments retires February 22, 2027, with no replacement product; Microsoft recommends Bicep or ARM templates directly.
- Microsoft Dev Box retires September 18, 2028, with Windows 365 suggested as a successor that is explicitly not a one-to-one replacement.
- Remaining Dev Box workloads should expect deletion.
