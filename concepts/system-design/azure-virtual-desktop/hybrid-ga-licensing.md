# Azure Virtual Desktop Hybrid Reaches GA with Unpublished Licensing Details

The announcement comes with notable gaps in pricing and support. Microsoft has not published pricing for the Hybrid service itself. Additionally, Windows Server deployments require Remote Desktop Services (RDS) Client Access Licenses (CALs) with Software Assurance, and multi-session Windows is not supported in the Hybrid model (Wiggers, 2026).

- Azure Virtual Desktop Hybrid is now generally available.
- Session hosts run on customer hardware through Azure Arc, with brokering in Azure.
- Hybrid service pricing is not yet published.
- Windows Server support requires RDS CALs with Software Assurance.
- Multi-session Windows is not supported in this offering.
