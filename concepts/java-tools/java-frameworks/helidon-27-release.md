# Helidon 27 Introduces Restructured Programming Models and New Messaging and Data Modules

Helidon 27 is the first release to follow Oracle's Tip & Tail Model of Library Development, in which the Tip adopts the latest Java technology while the Tail provides a more stable and secure baseline (Redlich, 2026). The release coincided with JDK 27.

New features in Helidon 27 include an introduction to new major modules, Helidon Messaging and Helidon Data JDBC, alongside restructured programming models (Redlich, 2026).

- Helidon 27 is the first release following Oracle's Tip & Tail Model of Library Development
- The Tip adopts the latest Java technology while the Tail provides a more stable and secure baseline
- The release was concurrent with JDK 27
- New major modules introduced: Helidon Messaging and Helidon Data JDBC
