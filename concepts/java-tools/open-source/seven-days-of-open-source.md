# Seven Days of Open Source

Square Engineering announced a week-long series of open source releases to coincide with Google I/O 2013. The blog post explains that each weekday during the following week would feature a new project release with a dedicated post on the company blog, all focused on Android and Java, the two platforms Square is deeply invested in. The releases listed are OkHttp, Dagger, MimeCraft/JavaWriter/ProtoParser, Robolectric 2.0, IntelliJ plugins, Retrofit, and Picasso, each considered a major milestone. The post serves as an index to the upcoming detailed announcements.

- Square released a series of major open source milestones during Google I/O week.
- All releases target the Android and Java development platforms.
- Projects included OkHttp, Dagger, MimeCraft, JavaWriter, ProtoParser, Robolectric 2.0, IntelliJ plugins, Retrofit, and Picasso.
- Each project had its own detailed blog post with motivation and usage at Square.
