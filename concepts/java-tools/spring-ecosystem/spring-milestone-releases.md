# Spring News Roundup: Second Milestone Releases Across the Spring Portfolio

InfoQ's Spring news roundup for the week of September 21st, 2026 reports a concentrated batch of milestone releases across the Spring portfolio, authored by Michael Redlich.

The headline activity was second milestone releases for nine projects: Spring Boot, Spring Batch, Spring Security, Spring AMQP, Spring Integration, Spring Data, Spring Framework, Spring for GraphQL, and Spring for Apache Kafka.

Alongside those, first milestone releases were published for Spring AI, Spring Cloud, Spring Web Services, and Spring LDAP, marking earlier-stage progress on a separate set of projects.

- Second milestone releases shipped for Spring Boot, Spring Batch, Spring Security, Spring AMQP, Spring Integration, Spring Data, Spring Framework, Spring for GraphQL, and Spring for Apache Kafka.
- First milestone releases shipped for Spring AI, Spring Cloud, Spring Web Services, and Spring LDAP.
- All release activity is dated to the week of September 21st, 2026.
