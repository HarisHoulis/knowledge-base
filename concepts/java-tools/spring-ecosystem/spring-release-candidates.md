# Spring Ecosystem Ships First Release Candidates Across 17 Projects

During the week of October 19th, 2026, the Spring ecosystem saw a coordinated wave of activity in which seventeen projects published their first release candidates. The affected projects span the core runtime and data layers, including Spring Boot, Spring Framework, Spring Data, Spring Cloud, and Spring Security, as well as integration and messaging projects such as Spring Integration, Spring AMQP, Spring for Apache Kafka, and Spring LDAP.

The roundup also covers web and API tooling, with Spring for GraphQL, Spring Session, Spring HATEOAS, Spring REST Docs, and Spring Web Services reaching the same milestone. Newer and specialized projects are represented too: Spring Modulith, Spring AI, and Spring Batch all issued first release candidates in the same window.

Because the announcement is a news roundup, it reports the breadth of the releases rather than detailing individual features or changes in each project.

- Seventeen Spring projects published first release candidates in the week of October 19th, 2026.
- Core projects involved include Spring Boot, Spring Framework, Spring Data, Spring Cloud, and Spring Security.
- Integration and messaging projects such as Spring Integration, Spring AMQP, Spring for Apache Kafka, and Spring LDAP also released RCs.
- Newer projects Spring Modulith and Spring AI reached the first release candidate milestone alongside established ones.
