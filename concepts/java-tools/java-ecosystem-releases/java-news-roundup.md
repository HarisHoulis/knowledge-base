# Java News Roundup: Grails 8, Open Liberty, GlassFish, Infinispan, LangChain4j, Spock

This week's Java roundup for October 5th, 2026 covers a broad set of ecosystem updates. OpenJDK JEPs were proposed to target for JDK 28, and Lazy Constants were elevated to Candidate status. On the release side, Apache Grails 8.0 and Open Liberty 20.0.0.10 reached general availability, while TornadoVM, Infinispan, LangChain4j, and Spock shipped point releases and GlassFish received a maintenance release.

- OpenJDK JEPs proposed to target for JDK 28; Lazy Constants elevated to Candidate status
- Apache Grails 8.0 and Open Liberty 20.0.0.10 reached GA
- Point releases for TornadoVM, Infinispan, LangChain4j, and Spock; maintenance release for GlassFish
