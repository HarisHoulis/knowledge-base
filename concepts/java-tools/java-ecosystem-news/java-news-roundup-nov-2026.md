# Java News Roundup: Java4Shell, Oracle CSPUs, OpenJDK, Azul Payara, BellSoft, Helidon, LangChain4j

This week's Java roundup for November 16th, 2026 covers a range of ecosystem news, headlined by the Java4Shell remote code execution vulnerability. Oracle also published its Critical Patch Update advisories (CSPUs) for the period.

- Java4Shell is a remote code execution (RCE) vulnerability highlighted in this week's news.
- Oracle released Critical Patch Updates (CSPUs).
- Lazy Constants are targeted for JDK 28 in OpenJDK.
- Azul Payara shipped its November 2026 edition, alongside point releases of Java Operator SDK, LangChain4j, and Micrometer.
- Maintenance releases arrived for Liberica JDK and Helidon, plus second release candidates of Hibernate Reactive.
