# Java News Roundup: JDK 28 Schedule, Oracle CPUs, eMudhra Certs, Apache POI, WildFly, Azul, BellSoft

This roundup covers the week of October 19th, 2026 in the Java ecosystem, headlined by the proposed release schedule for JDK 28. It also reports on the eMudhra Intermediate CA certificates breach and Oracle's October 2026 Critical Patch Update, alongside vendor CPU releases from Azul and BellSoft.

On the tooling side, the roundup notes GA releases of WildFly 42 and Apache POI 6.0, plus the beta release of Open Liberty 26.0.0.11. Maintenance releases of Micronaut and JobRunr round out the coverage.

- Proposed release schedule for JDK 28 was announced
- eMudhra Intermediate CA certificates breach and Oracle's October 2026 Critical Patch Update were covered
- Azul and BellSoft issued CPU releases
- WildFly 42 and Apache POI 6.0 reached GA; Open Liberty 26.0.0.11 entered beta
- Micronaut and JobRunr shipped maintenance releases
