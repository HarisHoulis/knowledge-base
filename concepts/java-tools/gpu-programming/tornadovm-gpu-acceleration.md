# TornadoVM 7 Enables GPU-Native Workloads From Java Applications

TornadoVM, an open-source heterogeneous programming framework for Java, has reached version 7.0. It automatically accelerates Java programs across multi-core CPUs and GPUs, offering a rich GPU programming ecosystem within Java (InfoQ, Ben Evans).

The release emphasizes broad JDK compatibility: TornadoVM 7 works with any mainstream JDK distribution, including Temurin, Red Hat OpenJDK, Corretto, Oracle, GraalVM, and Zulu. This lets developers add GPU acceleration without changing their existing JDK toolchain.

- TornadoVM 7.0 is an open-source framework that automatically accelerates Java programs on multi-core CPUs and GPUs.
- It provides a GPU programming ecosystem usable directly from Java.
- It supports any mainstream JDK distribution, including Temurin, Red Hat OpenJDK, Corretto, Oracle, GraalVM, and Zulu.
