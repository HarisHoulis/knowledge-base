# Agentic SDLC at Uber — Uday Kiran Medisetty & Adam Huda, Uber

Uber has invested heavily in agentic AI across its software development lifecycle, with over 70% of pull requests now generated by local or cloud agents and lines of code per engineer doubling year-over-year. The company also handled more than 250 automated migrations, covering 9 million lines of code automatically. These gains were built on earlier investments in monorepos and Bazel, which provided a solid foundation for AI acceleration (Medisetty & Huda, 2026).

A key building block is the model gateway, which ensures no PII leaves Uber's perimeter by default, enforces bounded latency, and provides per-user, per-project, and per-team attribution. All internal and external use cases go through a single OpenAI/Anthropic-compatible endpoint, with middlewares for identity/authentication via Spire, a data anonymizer that redacts 20+ PII types, and an AI guard with 5 specialized safety models—all under 100ms. The gateway now handles over 100 million model requests per day across 800+ projects, with caching and token optimization strategies at that layer.

Another critical block is the MCP (Model Context Protocol) gateway. Uber automated the projection of thousands of internal APIs into MCPs via a crawler, and unified SaaS tools like Google, Slack, and Jira through a single entry point with token exchange. To reduce token consumption, they evolved from direct MCPs to Omni MCP (a single MCP that discovers and invokes any gateway MCP), then projected MCPs into CLI pattern to avoid context bloat, and recently introduced a code-mode skill that auto-installs and generates Python scripts to hyper-optimize top token-consuming use cases.

- 70% of PRs at Uber are now by local or cloud agents, and lines of code per engineer doubled year-over-year.
- The model gateway centralizes model access with PII redaction, safety guardrails, latency bounds, and spend attribution across 800+ projects.
- Uber's MCP gateway makes internal and SaaS tools agent-accessible through a single entry point, with token optimization via Omni MCP, CLI projection, and code-mode skills.
- Prior investments in monorepos and Bazel laid the foundation for accelerating agentic AI adoption.
