# Extensible Software in the Age of LLMs

Jeremy Morrell's hypothesis, as quoted by Simon Willison, suggests that LLMs open a new opportunity for extensible software on the web. LLMs significantly lower the cost of authoring extensions, while modern sandbox primitives reduce deployment costs and provide strong security boundaries. This allows apps to be built as a solid, accountable core, with users safely extending functionality in many directions via LLM-generated code. The idea is to give users 'super powers' by enabling safe, flexible customization without compromising the integrity of the core application.

- LLMs lower the authoring cost of extensions, making it easier for users to create custom functionality.
- Modern sandboxing primitives provide secure deployment boundaries at lower cost.
- Apps can maintain a solid, accountable core while being extensible.
- Users can safely extend apps in many directions with LLM assistance, gaining super powers.
