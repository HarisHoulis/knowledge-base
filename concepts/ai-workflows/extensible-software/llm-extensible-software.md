# Extensible Software in the Age of LLMs

This source presents a hypothesis from Jeremy Morrell about a renewed opportunity for extensible software on the web, driven by recent advances in LLMs and sandboxing. The key insight is that LLMs radically lower the cost of authoring extensions, allowing users to customize software without deep programming expertise. Meanwhile, modern sandbox primitives reduce deployment costs and provide strong security boundaries, making it safe to run third-party or user-generated code. The proposed architecture is an application built as a solid, accountable core, which users can extend in many directions by having LLMs fill in the missing pieces. This approach aims to give users 'super powers' by safely enabling flexible, personalized functionality beyond what the original developers could anticipate. The hypothesis suggests that combining LLM-driven code generation with secure sandboxing could transform how web applications are designed and used.

- LLMs lower the cost of authoring software extensions, making them accessible to broader users.
- Modern sandbox primitives lower deployment costs and provide effective security boundaries for running extensions.
- Apps can be built as a solid, accountable core that users safely extend via LLM-generated code.
- This combination creates a new opportunity for extensible software on the web, empowering users with super powers.
