# Intelligence + Continual Learning = Expertise — Yu Su, NeoCognition

Yu Su argues that modern LLM-based agents have achieved unprecedented success in coding because code exists in a language-native, symbolic world where structure and tests are already available. This success, however, masks a critical limitation: agents fail in broader enterprise and personal settings because these environments are not monolithic but consist of millions of idiosyncratic 'micro worlds'—every company, domain, and even configuration differs. A static model cannot compress this heterogeneity into one fixed representation (Su, 2026).

Su frames this as a modern version of Moravec's paradox: symbolic reasoning tasks like coding and math are now easy for AI, while everyday digital work remains hard because it demands continual learning and adaptation to local constraints and affordances. The solution, he argues, is that agents must continually learn on the job to acquire specialized expertise for each specific microworld. This distinction between raw intelligence and expertise is central to overcoming the brittleness of current agents and achieving the 'decade of agents' Andrew Ng envisioned (Su, 2026).

- Coding agents succeed because code is already symbolic, structured, and testable, making it an ideal environment for LLMs.
- Outside coding, agents struggle due to the extreme heterogeneity of enterprise and personal digital worlds, each with unique local physics.
- A monolithic, static model cannot handle the dynamic and idiosyncratic nature of real-world tasks.
- Agents must adopt continual learning to build specialized expertise on the job, moving beyond generalized intelligence.
- This is a modern Moravec's paradox: symbolic reasoning is easy, but everyday digital work is hard for current AI.
