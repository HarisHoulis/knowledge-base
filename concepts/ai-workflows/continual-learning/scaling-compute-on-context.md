# Scaling Compute on Context — Jack Morris, Engram

Jack Morris, a researcher at startup Engram, introduces the concept of "scaling compute on context" as the pursuit of depth in AI, contrasting with the breadth exhibited by large pre-trained models. He uses mathematician Terence Tao's observations to illustrate that while AI can connect diverse public knowledge, it lacks the deep, intuitive understanding of a specialist. Morris argues that current models are fundamentally limited because they cannot acquire new knowledge after training, whether that is recent events, long-tail skills like AMD kernel development, or personal data about users (Morris, 2026).

The talk frames this as a core problem with the current paradigm: models are trained on public data and therefore cannot be personalized to individual users or private knowledge. Morris cites multiple names for the proposed solution—sleep time compute, continual learning, neural memory, write time compute, machine studying, amortized inference—all describing the same early-stage idea of enabling models to update and deepen their knowledge over time. He emphasizes that unlike pre-training or post-training, this paradigm has not yet been solidified, but it represents a critical direction for AI to achieve true expertise and personalization (Morris, 2026).

- Scaling compute on context refers to teaching models new knowledge after training, enabling depth rather than just breadth.
- Current models are restricted to public pre-training data, lacking access to recent events, long-tail skills, and personal information.
- The concept has many names, including continual learning, sleep-time compute, and machine studying, indicating an early, unformed paradigm.
- Terence Tao's example highlights the difference between AI's broad knowledge and human-like specialized intuition, which scaling compute on context aims to address.
