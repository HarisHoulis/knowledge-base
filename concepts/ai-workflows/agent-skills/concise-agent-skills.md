# Your Skills Are Way Too Long: Writing Leaner Agent Skills

Matt Pocock argues that bloated agent skills degrade AI agent performance and that authors should be ruthless when editing them. The core message is that massive skills hurt your AI agents, so smaller, more effective skills are preferable [source: video description].

The video frames concise skill authoring as an editing discipline rather than a writing exercise: the goal is to cut content down, not to add more instructions. Pocock points viewers to his own skills collection as an ongoing example of the approach [source: video description].

No specific techniques, metrics, or examples beyond this framing are provided in the available source text.
