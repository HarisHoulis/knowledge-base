# This change makes /grill-me SO MUCH BETTER

Matt Pocock demonstrates a significant improvement to the /grill-me skill by introducing a batch-based question system. Instead of asking questions one-by-one, the skill now groups questions into rounds, which reduces the wait time between questions and minimizes context switching for the user. This change makes the interaction more fluid and efficient, especially in scenarios where multiple questions need to be addressed sequentially.

The batch-based approach also accounts for question dependencies, meaning that related or dependent questions can be organized and presented together in a logical order. This ensures that the user can answer questions in a coherent sequence without needing to revisit previous answers or re-establish context. Overall, the update enhances the user experience by streamlining the questioning process and making the skill feel more responsive and intelligent.

- The /grill-me skill now uses a batch-based question system instead of asking questions one-by-one.
- Questions are presented in rounds, which reduces wait times and context switching.
- The system handles question dependencies, allowing related questions to be grouped logically.
- This change improves the overall efficiency and flow of the skill.
