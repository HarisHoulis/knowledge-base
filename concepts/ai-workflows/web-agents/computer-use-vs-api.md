# Computer-use models will agentify the web, not APIs

Dhruv Batra argues that the common assumption that AI agents will drive the web via APIs is wrong, especially for the long tail of the web. While popular websites might offer APIs, the vast majority of sites—like small restaurant pages—will never expose structured endpoints. Instead, computer-use models that can see and click through pages like humans are the practical path to automating the web (Batra, 2026).

- The long tail of the web will not provide APIs, so agents must interact with raw HTML, PDFs, and images.
- Computer-use agents can handle unstructured content: restaurant menus in PDFs or JPEG galleries, school district procurement pages.
- Protocol-based approaches like MCP are insufficient for the messy, multimodal reality of most websites.
- The head of the web may get APIs, but the full web requires computer-use models for agentification.
- Building agents that mimic human browsing is more scalable than waiting for universal API adoption.
