# The next chapter: EpicAI.pro

Kent C. Dodds announces EpicAI.pro, a new educational platform focused on building applications architected for intelligent interaction and powered by AI. He argues that the user experience is shifting from direct manipulation (forms, buttons, links) to conversational and agent-driven interfaces, where users give high-level instructions and AI agents orchestrate complex tasks across services. This shift requires developers to rethink application structure, data exposure, and capability integration (Kent C. Dodds, 2025). The platform will teach enduring principles like designing for AI interaction, structuring data and capabilities for machine understanding, and understanding emerging standards like the Model Context Protocol (MCP). MCP is highlighted as a framework that allows AI agents to discover, understand, and securely use an application's capabilities. Dodds emphasizes security and reliability challenges, such as authentication, authorization, and the risk of "tool poisoning" when letting AI interact with systems. He positions this as a natural evolution of web development, focusing on architectural principles rather than hype (source: https://kentcdodds.com/blog/the-next-chapter-epicai-pro). To kick off, Dodds is hosting a free live event on April 16, 2025, where he will live-code an MCP server and show how an AI assistant can use it to interact with an application's capabilities.

- AI is shifting the primary interaction model from direct manipulation to conversational, agent-driven instructions, requiring apps to be built for both human and AI users.
- Developers need to architect applications for machine understanding—exposing capabilities securely and predictably, with MCP as a key emerging standard.
- EpicAI.pro will teach foundational principles for AI-powered application architecture, avoiding hype and focusing on security, reliability, and maintainability.
- A live event on April 16, 2025 will demonstrate building an MCP server and connecting it to an AI assistant.
