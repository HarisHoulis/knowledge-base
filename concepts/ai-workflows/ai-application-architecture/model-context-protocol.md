# The Next Chapter: EpicAI.pro

Kent C. Dodds announces EpicAI.pro, a new educational platform focused on building AI-powered applications. He argues that the user interaction paradigm is shifting from direct manipulation (forms, buttons, links) to conversational and agent-driven interfaces, requiring developers to architect applications for intelligent interaction. The platform will teach foundational principles like designing for AI interaction, structuring data and capabilities for machine understanding, and understanding emerging standards like the Model Context Protocol (MCP). It will also address security and reliability challenges such as authentication and 'tool poisoning'.

- Applications need to be architected for AI agents as primary users, not just humans.
- MCP (Model Context Protocol) is a key standard for enabling AI to discover and use app capabilities securely.
- Developers must focus on foundational principles rather than vendor-specific AI hype.
- Security concerns like tool poisoning and authentication/authorization are critical when letting AI interact with systems.
- A free live event on April 16, 2025 will demonstrate live-coding an MCP server.
