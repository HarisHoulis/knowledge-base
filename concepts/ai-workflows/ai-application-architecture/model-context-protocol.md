# The next chapter: EpicAI.pro

Kent C. Dodds announces EpicAI.pro, a new educational platform focused on building applications architected for intelligent interaction and powered by AI. He argues that the shift from traditional UI paradigms (forms, buttons, links) to conversational and agent-driven interfaces requires developers to rethink how applications are structured. The platform will teach foundational principles like designing for AI interaction, structuring data and capabilities, and understanding emerging standards such as the Model Context Protocol (MCP) for secure and predictable AI-to-application communication ([source](https://kentcdodds.com/blog/the-next-chapter-epicai-pro)).

Dodds emphasizes that this is not about chasing hype but about a fundamental transformation in user experience, citing accessibility gains and the ability to orchestrate actions across multiple services via simple instructions. He acknowledges the architectural challenges—such as authentication, security (including tool poisoning), and reliability—and positions EpicAI.pro as a resource for developers to become architects of AI-driven experiences. He also announces a free live event where he will live-code an MCP server and demonstrate how an AI assistant can interact with an application's capabilities ([source](https://kentcdodds.com/blog/the-next-chapter-epicai-pro)).

- EpicAI.pro focuses on enduring principles for building AI-powered applications, not vendor-specific trends.
- Developers must design applications for both human users and AI agents, exposing services in machine-understandable ways.
- The Model Context Protocol (MCP) is highlighted as an emerging standard for AI-to-application communication.
- Key challenges include security (e.g., tool poisoning), authentication, and reliability when AI interacts with systems.
- A free live event on April 16, 2025 will demonstrate building an MCP server and connecting an AI assistant.
