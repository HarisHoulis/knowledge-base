# The next chapter: EpicAI.pro

The article announces EpicAI.pro, a new educational platform by Kent C. Dodds focused on teaching developers how to build applications architected for AI interaction. It argues that the traditional paradigm of forms, buttons, and direct manipulation is evolving toward conversational, agent-driven experiences where users give high-level instructions and AI agents perform tasks across multiple services. This shift requires developers to design interfaces not just for humans but also for machines, exposing capabilities in ways AI can reliably discover and use ([source](https://kentcdodds.com/blog/the-next-chapter-epicai-pro)).

EpicAI.pro will emphasize enduring principles over vendor hype, covering topics like designing for AI interaction, structuring data and capabilities, understanding the Model Context Protocol (MCP), and addressing security and reliability challenges such as "tool poisoning." The article positions this as an architectural challenge, similar to previous shifts in web development, and stresses that early adoption will position developers at the forefront of the evolution. It also announces a free live online event on April 16, 2025, where Dodds will live-code an MCP server and demonstrate how an AI assistant can interact with an application ([source](https://kentcdodds.com/blog/the-next-chapter-epicai-pro)).

- Application development is shifting from human-only interfaces to AI-agent-driven interactions, requiring apps to be designed for machine understanding as well as human use.
- EpicAI.pro teaches foundational principles for building AI-powered applications, including structuring capabilities for AI and using the Model Context Protocol (MCP).
- Security and reliability are critical: developers must address challenges like authentication, authorization, and 'tool poisoning' when letting AI interact with systems.
- The article promotes a live coding event on April 16, 2025, to demonstrate building an MCP server from scratch.
- The focus is on enduring architectural principles rather than chasing fleeting trends or specific vendor tools.
