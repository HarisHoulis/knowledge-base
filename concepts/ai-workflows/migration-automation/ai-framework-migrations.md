# The Pulse: We need to talk about migrations with AI

The article reports on how AI is transforming large-scale framework migrations. Asana needed to migrate off the Enzyme testing framework, a task that involved rewriting a massive number of test cases. With AI assistance, the project was completed in two weeks, whereas without AI it would likely have been postponed indefinitely. This illustrates AI's effectiveness for mechanical, repetitive migration work. Airbnb and Uber share similar success stories, suggesting that AI is a superb fit for framework migrations (Orosz, 2026).

The article also discusses the shifting relevance of Gartner's Magic Quadrant, noting that major AI vendors like Anthropic, Cursor, and OpenAI are not paying the 'Gartner tax,' which has led Gartner to rank traditional incumbents like AWS, Microsoft, and IBM above them. This raises questions about the credibility of such rankings in the AI era. Additionally, the newsletter covers industry events: a multi-hour GitHub outage, rising GitHub alternatives, Slack Code, Claude watermarking, and Uber open-sourcing SubmitQueue, reflecting broader changes in developer tools and AI integration (Orosz, 2026).

- AI can turn a massive migration project into a two-week task, as Asana demonstrated with Enzyme.
- Airbnb and Uber report similar success using AI for framework migrations, making it a proven approach.
- Major AI companies are bypassing Gartner's Magic Quadrant by refusing to pay for inclusion, questioning its relevance.
- The newsletter also notes GitHub outages, Slack Code, and Uber's SubmitQueue open-source release.
