# TDD inside the agent loop - theater or actual value?

The article investigates whether instructing LLM agents to use Test-Driven Development (TDD) genuinely improves software output or is merely a performative ritual. Birgitta Böckeler, a Thoughtworks colleague, conducted experiments to assess the real impact of TDD when embedded in the agent-driven development loop. The work stems from a culture where TDD is highly valued, prompting curiosity about its applicability in AI-assisted coding workflows. The findings aim to separate theater from actual value, offering evidence-based guidance for practitioners using generative AI in software development.

- Thoughtworks practitioners generally advocate TDD, leading to questions about its role in AI agent workflows.
- Birgitta Böckeler ran experiments specifically to test whether TDD in the agent loop changes outcomes.
- The article seeks to determine if TDD within agent-based development is theater or delivers concrete value.
