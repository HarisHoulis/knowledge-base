# Donating Agent Skills to the Agentic AI Foundation

Anthropic announced it is donating the Agent Skills standard to the Agentic AI Foundation (AAIF) under the Linux Foundation, aiming to keep skills open, community-driven, and vendor-neutral. The AAIF was co-founded by Anthropic with Block and OpenAI, and previously received the Model Context Protocol (MCP) donation.

Simon Willison notes he predicted this outcome in December 2025, when Anthropic first declared skills an open standard, anticipating it would land in the AAIF as MCP had. He also demonstrates a practical use of MCP: querying his own blog content via the datasette-mcp plugin to have Claude find his earlier post about donating skills to a standards body.

- Anthropic donated the Agent Skills standard to the Agentic AI Foundation under the Linux Foundation to keep it open and vendor-neutral.
