# What is Code

The article by Martin Fowler, as summarized by Unmesh Joshi, argues that code serves two distinct but intertwined purposes: instructions to a machine and a conceptual model of the problem domain. It emphasizes the importance of building a vocabulary to communicate with the machine, noting that programming languages act as thinking tools. As humans increasingly delegate writing code to agents, the article explores whether source code will still exist in the future, stressing that understanding the dual nature of code is vital for working with LLMs. The piece suggests that the conceptual modeling aspect of code remains crucial even as machine instruction generation becomes automated (Fowler, "What is Code").

- Code has two intertwined purposes: instructing a machine and modeling the problem domain.
- Building a vocabulary to talk to the machine is vital for effective programming.
- Programming languages are thinking tools, not just syntax for machines.
- As agents write more code, the future of source code depends on understanding its dual nature.
- LLMs change how code is produced, but the conceptual model remains essential.
