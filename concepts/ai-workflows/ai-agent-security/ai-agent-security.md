# AI Agents Gone Rogue? Build, Defend & Attack AI-Enabled Apps

In this YOW! 2025 talk, Katie Paxton-Fear, a security advocate at Semgrep, introduces the shift from confined chatbots to autonomous AI agents. She describes agents as specialized AIs that can work autonomously on specific tasks, each with access to limited resources and tools—for example, an email agent can read only the inbox, while a calendar agent can only access the calendar. When a task requires cross-domain knowledge, such as adding an event from an email to a calendar, the agents hand off the work to each other via a central assistant. This agentic flow enables more complex operations like booking flights based on emails and budget constraints, but it also expands the attack surface as agents gain access to sensitive tools and data. Although the full talk covers building, defending, and attacking AI-enabled apps, the opening frames the security concerns around giving AI systems autonomous agency and resource access. Paxton-Fear identifies herself as an AI skeptic rather than an enthusiast, and she notes that many commercial claims about AI agents are hype, but the security risks are real and will shape the future of application security.

- AI agents are specialized autonomous systems that operate within defined resource and tool boundaries, unlike traditional all-in-one chatbots.
- A central assistant coordinates by delegating tasks to specialist agents when it lacks the necessary access or capability.
- Giving agents access to emails, calendars, bank accounts, and other tools introduces significant security risks that need to be defended against.
- The speaker, an AI skeptic with a PhD in AI and cybersecurity, warns that much of the AI agent buzz is commercially driven, but the underlying security implications deserve serious attention.
