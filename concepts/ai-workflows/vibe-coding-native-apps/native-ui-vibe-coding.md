# Stop Making TUIs

Simon Willison reflects on his experience vibe-coding macOS menu bar apps for bandwidth and GPU monitoring, which he still uses daily. He notes that despite having these successful native UIs, he has not yet extended the approach to other projects, but feels he is running out of excuses. His experience demonstrates that AI-assisted development can produce durable, useful native applications.

Willison quotes Thomas Ptacek, who encourages developers to turn throwaway CLIs into native apps, arguing that doing so will likely change the way they think. Willison endorses this perspective, highlighting how AI reduces the friction of building native interfaces and opens up new possibilities for small, personal tools that would previously have remained command-line only.

- Vibe-coded native apps can be durable and used daily, as shown by Willison's monitoring tools.
- AI enables developers to quickly build native UIs for tools that would typically be CLIs.
- Turning CLIs into native apps can change your thinking about UI design and development.
- The post encourages developers to experiment with AI-assisted native UI creation.
