# Bringing agents onto the world wide web

The web was built for humans, not agents, creating significant friction for automation: pages change frequently, content is token-inefficient, and agents encounter broken browsers and blockers. Despite decades of painful web automation, agents have advanced considerably, but progress on computer use has stalled because the true bottleneck is no longer model capability. Models have improved dramatically in long-context tasks and computer use, driven by RL environments trained on real web trajectories, yet agents still lack the right harness and tools to operately interact with the web effectively. Paul Klein argues that the missing piece is the harness—the scaffolding and systems around the model—and that investing in harness engineering can unlock the latent overhang in model capabilities. He references Karpathy's 2023 tweet about building systems around LLMs, including a code interpreter, browser, and subagents, as a forward-looking blueprint that the industry is now actively building toward.

- The web was designed for people, not agents, leading to issues like page instability, high token usage, broken browsers, and blockers.
- Model capabilities have caught up; the current bottleneck is the harness and tools surrounding the model.
- Harness engineering can extract more value from existing models, unlocking the 'overhang' in model capabilities.
- Karpathy's vision of a code interpreter, browser, and subagents around LLMs is proving prescient as the industry evolves.
- Investment in RL environments for computer use is driving rapid model improvements, making harness design the key differentiator.
