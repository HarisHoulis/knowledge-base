# Five Ways To Use AI Coding Agents to Improve Your Software Architecture

The article argues that AI coding agents can improve software architecture by helping teams understand poorly documented legacy services (Pureur et al., 2026). It notes that modern architectures often rely on legacy services for specific tasks, but these services may lack accurate documentation, making their use risky when teams do not understand them well (Pureur et al., 2026).

According to the authors, AI coding agents can help close that knowledge gap (Pureur et al., 2026). The article presents five ways to use AI coding agents for this purpose, though the provided excerpt focuses on the legacy-service documentation problem (Pureur et al., 2026).

- Modern architectures often depend on legacy services for specific tasks.
- Legacy services may lack accurate documentation.
- Using legacy services is risky when teams do not understand them well.
- AI coding agents can help close the knowledge gap around legacy services.
