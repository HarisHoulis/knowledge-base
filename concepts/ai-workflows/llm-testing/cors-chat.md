# CORS Chat

CORS Chat is a web-based tool built by Simon Willison (with assistance from GPT-5.6-Sol xhigh) to test OpenAI-Responses-compatible chat endpoints from the browser. It is designed to work with locally hosted models, such as Qwen 3.8 27B running in LM Studio on an M5 MacBook Pro or an NVIDIA DGX Spark, as well as cloud endpoints like OpenRouter. The tool addresses CORS restrictions by supporting servers that enable the `--cors` option, allowing direct browser-to-API communication.

Conversations are stored in the browser and can be exported as copy-pasted JSON, making it easy to share or analyze interactions. A notable feature is its ability to detect SVG images generated by the model and progressively render them in the chat interface while tokens are still streaming, providing a live preview of image generation.

- Provides a web UI for exercising OpenAI-Responses-compatible chat endpoints.
- Works with LM Studio (using the `--cors` option) and OpenRouter.
- Persists conversations in the browser and supports export as JSON.
- Progressively renders streaming SVG images during chat responses.
