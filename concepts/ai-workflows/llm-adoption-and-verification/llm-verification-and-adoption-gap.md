# Fragments: July 21 - AI Adoption, Verification, and Writing Voice

Martin Fowler's July 21 fragment wraps up notes from the Future of Software Development Retreat, highlighting a key shift: code generation is no longer the bottleneck, verification is. The Thoughtworks report cited in the source identifies five findings, including the emergence of 'harness engineering' and a real apprenticeship crisis. Fowler emphasizes that organizations are more constrained by the executive/engineer expectation gap than by technical limits, exemplified by a $100 billion loss from an ML model trained on desert equipment but used in the arctic, where rotting mosquitoes created a fire risk (source).

- Verification has become the primary bottleneck in code generation; harness engineering is emerging as a distinct discipline.
- There is a dangerous gap between executive expectations of LLM productivity and engineer awareness of security risks, illustrated by the arctic air filter example.
- Citizen developers and vibe coding can create massive shadow IT, requiring platform controls and threat modeling at board level.
- Domain-specific languages (DSLs) are an effective way to make LLM output secure and token-efficient, and LLMs are adept at learning them.
- LLM-generated prose is increasingly discredited by readers; using one's own voice, especially through reading aloud, is a key differentiator.
