# The VibeSec Reckoning

Vibe coding has significantly accelerated software prototyping, but AI agents frequently recommend insecure configurations, creating security problems. According to the article by Martin Fowler, this challenge was observed by Gautam Koul, Lucian Moss, Neil Drew-Lopez, and Daberechi Ruth Edeokoh while building applications for Thoughtworks's global marketing (Martin Fowler, https://martinfowler.com/articles/vibesec-reckoning.html).

To combat these security issues, the team learned several key practices. First, they emphasize writing a security context file to guide the AI's recommendations. Second, they advise being cautious with AI permission requests to avoid unintended access. Third, they suggest creating a daily security intelligence feed to stay updated on threats. Finally, they recommend providing builders with a secure-by-default harness and templates to reduce the risk of insecure configurations.

- AI agents frequently recommend insecure configurations during vibe coding, leading to security problems.
- Writing a security context file helps guide AI agents toward secure choices.
- Be cautious with AI permission requests to prevent unintended access or actions.
- A daily security intelligence feed keeps builders informed of emerging threats.
- Secure-by-default harnesses and templates minimize the risk of insecure setups.
