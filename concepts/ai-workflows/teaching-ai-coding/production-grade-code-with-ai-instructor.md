# Hiring: Part Time Instructor, Write Production Grade Code with AI

ByteByteGo is hiring a part-time instructor for a live, cohort-based course titled "Write Production Grade Code with AI", aimed at helping software engineers reliably ship production-grade software using coding agents. The role involves refining the curriculum, teaching live sessions, answering student questions, and sharing practical lessons from the instructor's own experience building software with AI. The commitment is approximately 2 to 10 hours every two weeks after initial onboarding, making it flexible alongside a full-time engineering role, with competitive compensation based on experience (ByteByteGo, 2026).

Ideal candidates have 5+ years of professional software engineering experience, use AI coding agents like Claude Code, Codex, or Cursor daily, and understand how these agents work including planning, tool use, context management, and common failure modes. They should also have experience breaking down complex engineering problems into clear specifications and implementation plans that AI can execute, and have worked extensively with large or legacy codebases to make them AI friendly. Additionally, candidates need to have reviewed significant amounts of AI-generated code to verify correctness, catch subtle bugs, identify security risks, and maintain long-term code quality, alongside strong fundamentals in testing, CI/CD, debugging, and code review (ByteByteGo, 2026).

- Course focuses on teaching engineers to delegate real work to coding agents, write executable specs and plans, and verify/review/secure AI-generated code.
- Role responsibilities include curriculum refinement, live teaching, answering questions, and sharing practical AI-building experience.
- Time commitment is 2-10 hours every two weeks after onboarding, designed to fit alongside a full-time engineering position.
- Strong candidates demonstrate daily use of AI coding agents, experience with legacy codebases, and expertise in reviewing AI-generated code for correctness and security.
- Interested applicants should email jobs@bytebytego.com with their background, AI workflow usage, and teaching or writing examples.
