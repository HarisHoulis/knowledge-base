# Microsoft Ignite 2026: Copilot as the Work OS and Agent Governance

At Ignite 2026, Microsoft framed Copilot as the operating system for work, extending agent identity, governance, and cost controls across Azure, Foundry, Entra, and Defender (Wiggers, 2026). The announcement positions agents as first-class enterprise entities that need the same identity and policy treatment as users and services.

Infrastructure and platform highlights included Cobalt 200 VMs, Azure HorizonDB, a continuous improvement loop in Foundry, Microsoft IQ, and a standalone Azure AI Gateway. Windows Server 2028 was also announced.

The through-line is governance at scale: agent identity tied to Entra, policy enforcement via Defender, and cost controls spanning the agent lifecycle. The standalone AI Gateway suggests a dedicated control plane for routing and managing model and agent traffic.

- Copilot is positioned as the operating system for work, not just an assistant
- Agent identity, governance, and cost controls span Azure, Foundry, Entra, and Defender
- New platform pieces include Cobalt 200 VMs, Azure HorizonDB, Microsoft IQ, and a standalone Azure AI Gateway
- Foundry gains a continuous improvement loop for agents
- Windows Server 2028 was announced
