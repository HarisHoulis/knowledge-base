# The Harness Is the New Operating System

At QCon San Francisco 2026, Mad Labs founder and CEO Manju Rajashekhar argued in his opening keynote that the harness around an AI model—not the model itself—determines what an agent can do and how safely it operates. The talk framed the harness as the decisive layer of agent design, shifting attention away from raw model capability toward the surrounding infrastructure.

Rajashekhar mapped the components of a harness—context, tools, state, permissions, and feedback loops—onto the jobs that operating systems already perform. This analogy positions the harness as the mediating layer that governs resources, enforces boundaries, and coordinates execution for the model, much as an OS does for applications.

- The harness around an AI model, not the model, decides an agent's capabilities and safety.
- A harness comprises context, tools, state, permissions, and feedback loops.
- These harness components map onto functions traditionally performed by operating systems.
