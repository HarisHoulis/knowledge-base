# Everyone Has the Same AI Models: What Sets Agents Apart

Richmond Alake argues that since everyone has access to the same underlying AI models, differentiation comes from the surrounding architecture: memory, control planes, software factories, and what he calls the "plane of intelligence." He defines agent memory as the mechanism an agent uses to store, reuse, reproduce, and refine information (the "four Ps"), organized by a taxonomy spanning short-term vs. long-term memory and cognitive functions such as semantic, episodic, procedural, and working memory. He notes that awareness of agent memory has grown sharply—when he spoke on it a year earlier, few in the audience knew the concept.

He describes a control plane as a centralized management system regulating an agent: which tools it can access, what it can and cannot do, plus identification, policies, defenses, orchestration of access rights, and auditing. He observes that fewer practitioners are familiar with control planes than with memory, and predicts familiarity will keep decreasing across his keyword list.

He traces the term "software factory" back to Bob Beamer at General Electric in 1968, who described building programs in a measurable and repeatable way. In the agent era, a software factory is a system that reliably produces a software product by giving agents a set of processes and workflows to follow, typically with multiple agents working in parallel.

He introduces the "plane of intelligence" as his forward-looking concept, promising—as he did with agent memory the prior year—that the material is about six months ahead of most people. He illustrates the value of assembling fragmentary information with the WWII story of the code "AF": analysts in Pearl Harbor, who had collected intercepts for months, determined that AF meant Midway, a crucial insight for the Pacific War.

- Since models are commoditized, agent differentiation comes from architecture: memory, control planes, and software factories.
- Agent memory is defined by the four Ps—store, reuse, reproduce, refine—with a taxonomy of short-term/long-term and semantic, episodic, procedural, and working memory.
- A control plane centrally governs agent identity, tool access, policies, defenses, orchestration, and auditing.
- The term "software factory" dates to Bob Beamer at GE in 1968 and now describes systems where multiple agents follow defined workflows to reliably produce software.
- The "plane of intelligence" is presented as an emerging concept, illustrated by the WWII code-breaking insight that 'AF' meant Midway.
