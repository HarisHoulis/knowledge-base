# Claude Code's system tools are SO BLOATED

In this video, Matt Pocock demonstrates how to drastically reduce Claude Code's system prompt token count from 25,000 to just 8,000 by disabling unused features and tools. The customization is done through the global settings.json file, allowing users to trim unnecessary bloat from the system prompt. The video references a guide at aihero.dev for detailed steps, and encourages viewers to follow Matt for more AI workflow tips (Pocock, 2026).

- Claude Code's default system prompt can be as large as 25,000 tokens.
- Disabling unused features and tools can cut the system prompt down to about 8,000 tokens.
- The optimization is achieved by customizing the global settings.json file.
- A detailed guide is available at the provided link.
