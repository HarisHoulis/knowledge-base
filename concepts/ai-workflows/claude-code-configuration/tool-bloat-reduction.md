# Claude Code's system tools are SO BLOATED

Matt Pocock demonstrates that Claude Code's default system prompt contains excessive bloat from unused features and tools, which inflates the token count and may hinder performance. By customizing the global settings.json file, users can disable these unnecessary components and dramatically reduce the system prompt size from roughly 25,000 tokens down to around 8,000 tokens. This optimization makes the AI workflow more efficient and cost-effective. The video provides a direct guide for implementing these changes, emphasizing that the reduction is achieved through simple configuration tweaks rather than modifying core functionality (Matt Pocock, 2026-07-16).

- Claude Code's default system prompt is bloated with unused tools and features, reaching around 25,000 tokens.
- Disabling unnecessary components via the global settings.json file can cut the system prompt to about 8,000 tokens.
- This reduction can improve efficiency and reduce costs in AI-assisted development workflows.
