# Claude Code's system tools are SO BLOATED

The video demonstrates how Claude Code's default system prompt includes a large number of tools and features, resulting in significant bloat. By editing the global settings.json file to disable unused features and tools, users can dramatically reduce the system prompt size from 25,000 tokens down to 8,000 tokens. This reduction helps streamline the AI's context and improve efficiency by removing unnecessary noise.

- Default Claude Code system prompt can be as large as 25,000 tokens.
- Customizing the global settings.json file disables unused tools and features.
- Disabling bloat can shrink the system prompt to around 8,000 tokens.
- A smaller system prompt reduces context noise and improves workflow efficiency.
