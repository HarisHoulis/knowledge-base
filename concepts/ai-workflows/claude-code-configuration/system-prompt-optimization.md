# Claude Code's system tools are SO BLOATED

The video addresses the bloat in Claude Code's system prompt, which by default contains about 25,000 tokens. This large prompt can degrade performance and increase costs. The author demonstrates a method to reduce the prompt size to roughly 8,000 tokens by disabling unused features and tools.

The optimization is achieved by customizing the global settings.json file for Claude Code. By turning off features that are not needed for a given workflow, users can streamline the system prompt. The video provides a guide link for implementing these changes, emphasizing that a leaner system prompt improves efficiency and focus.

- Default Claude Code system prompt is about 25,000 tokens, which is considered bloated.
- Disabling unused features and tools can reduce the prompt to roughly 8,000 tokens.
- Customization is done through the global settings.json file.
- Smaller system prompts can lead to better performance and lower token usage.
