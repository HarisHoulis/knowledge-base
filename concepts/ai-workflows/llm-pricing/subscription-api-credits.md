# API Credits Benefit for Eligible ChatGPT Subscriptions

OpenAI has launched a benefit that grants API credits to holders of higher-tier ChatGPT subscriptions: subscribers on the $100, $200, or $500 plans receive an equivalent quantity of credits applicable to one of their API organizations (source: OpenAI help article, via Simon Willison). Simon Willison notes this mirrors a similar deal from another company (Anthropic), and since he maintains subscriptions with both, the change is welcome news for him.

The practical effect is that API usage for demos and experiments can be covered by existing subscription spend rather than separate pay-as-you-go billing. Willison says he may now ship public-facing demos since the credits are already covered by his subscriptions.

- $100, $200, and $500 ChatGPT subscription tiers now include an equal amount of API credits
- Credits apply to one API organization per subscriber
- The arrangement mirrors a similar offer from Anthropic
- Covered credits lower the barrier to shipping public-facing demos
