# TDD inside the agent loop - theater or actual value?

Birgitta Böckeler from Thoughtworks conducted experiments to determine whether instructing LLM agents to use Test-Driven Development (TDD) genuinely improves outcomes or is just performative. The article, hosted on Martin Fowler's site, explores whether the practice of writing tests before code changes the behavior of AI coding agents in meaningful ways. It compares agent performance with and without explicit TDD instructions, analyzing factors like correctness, code quality, and alignment with user intent. The findings suggest that TDD can provide tangible benefits in some contexts, but its effectiveness depends on how the agent is prompted and the nature of the task. The article cautions against blindly applying human development practices to agents without empirical validation.

- The article investigates whether TDD instructions to LLM agents produce measurable improvements or are merely symbolic.
- Experiments were conducted by Birgitta Böckeler to compare agent behavior with and without TDD guidance.
- Results indicate that TDD can add value in certain scenarios, but the effect is not uniform and requires careful prompt design.
- The author emphasizes the need for empirical evaluation of AI agent workflows rather than assuming human practices translate directly.
