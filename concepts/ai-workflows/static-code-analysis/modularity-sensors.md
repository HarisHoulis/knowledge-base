# Three more static code analysis sensors

The findings indicate that while rule-based computational sensors have a place, a hybrid approach that leverages inferential AI review may better capture the nuances of modular design. This has implications for how coding agents are equipped with analysis capabilities.

- Dependency-check sensors enforce rules well but are limited by expressiveness.
- Coupling-data sensors were ineffective for assessing modularity.
- Inferential sensors that review modularity directly proved more effective.
- Combining computational enforcement with AI-driven review is promising.
