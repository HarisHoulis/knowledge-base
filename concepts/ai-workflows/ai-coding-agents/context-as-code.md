# Context Is the New Code: Applying Software Engineering Practices to AI Agent Context

In this InfoQ presentation, Patrick Debois argues that context - the information fed to AI coding agents - should be managed with the same rigor as source code. He covers how to manage, evaluate, distribute, and observe context using proven software engineering practices (source).

The central proposal is to treat context like code, complete with testing, CI/CD, package managers, and security scanning (source). Applying these practices is presented as the way for engineering leaders to reliably scale AI coding agents and to maintain control over their non-deterministic outputs, rather than relying on ad hoc prompt or document handling (source).

A further claim is that treating context as an engineered artifact builds long-term organizational knowledge, making context a durable asset rather than disposable input (source).

- Context should be treated like code: tested, versioned through CI/CD, distributed via package managers, and security-scanned.
- Applying software engineering practices to context lets engineering leaders scale AI coding agents reliably.
- These practices help maintain control over the non-deterministic outputs of AI agents.
- Managing context this way also builds long-term organizational knowledge.
