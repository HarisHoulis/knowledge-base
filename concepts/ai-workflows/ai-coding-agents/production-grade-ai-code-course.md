# Hiring: Part Time Instructor, Write Production Grade Code with AI

ByteByteGo is hiring a part-time instructor for a live, cohort-based course titled 'Write Production Grade Code with AI'. The course aims to teach software engineers how to reliably ship production-grade software using coding agents. Students learn to delegate real work to agents, write executable specs and plans, and verify, review, and secure AI-generated code. The instructor will help refine the curriculum, teach live sessions, answer questions, and share practical lessons from their own AI-assisted development experience.

- The course focuses on using AI coding agents to ship production-grade software, including delegation, spec-writing, and code verification.
- The instructor role involves curriculum refinement, live teaching, Q&A, and sharing practical experience.
- Ideal candidates have 5+ years of software engineering experience, daily use of AI coding agents like Claude Code or Cursor, and strong fundamentals in testing, CI/CD, and code review.
- The commitment is approximately 2 to 10 hours every two weeks, with competitive compensation based on experience.
