# The Pulse: We Need to Talk About Migrations with AI

In The Pulse, Gergely Orosz reports that AI is becoming a powerful tool for large-scale framework migrations. Asana's migration off the Enzyme testing framework, which involved rewriting a massive number of test cases, was completed in two weeks with AI assistance. Without AI, this work would likely have been postponed indefinitely. Airbnb and Uber report similar experiences, suggesting AI is a superb fit for framework migrations (Orosz, 2026).

The article also examines Gartner's Magic Quadrant for AI code modernization tools, which ranked AWS, Microsoft, and IBM above Anthropic, Cursor, and OpenAI. Orosz notes this is likely because the first three pay large sums to Gartner, while AI labs and vendors refuse to pay the 'Gartner tax.' This raises questions about the relevance of traditional analyst rankings in the AI era. Additionally, The Pulse covers industry news including a lengthy GitHub outage, new GitHub alternatives, Slack Code, Claude text watermarking, and Uber open-sourcing SubmitQueue.

- Asana completed its Enzyme migration in two weeks using AI, a task that otherwise would likely have been deferred indefinitely.
- Airbnb and Uber have similar success stories with AI-driven framework migrations.
- Gartner ranked AWS, Microsoft, and IBM above AI-first vendors in AI code modernization tools, possibly due to incumbent spending rather than product capability.
- AI labs and vendors are refusing to pay Gartner's fees, potentially making traditional analyst rankings less relevant.
- Other notable industry updates include a multi-hour GitHub outage, Slack Code launch, Claude text watermarking, and Uber open-sourcing SubmitQueue.
