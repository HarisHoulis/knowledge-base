# An Accidental Blackboard

The article, by Martin Fowler, relays a report from Giles Edwards-Alexander about an experiment exploring fully agentic engineering practices. During the experiment, a team inadvertently prompted their AI agents to create a blackboard coordination system inside the git repository. The blackboard emerged as an accidental outcome of the agentic workflow, rather than being intentionally designed. The source provides this anecdote as an observation of how AI agents can spontaneously produce architectural patterns in unexpected places, though it does not elaborate on the details or consequences of this system.

- A team experimenting with fully agentic engineering accidentally created a blackboard coordination system in their git repository.
- The blackboard system emerged from agent interactions rather than being deliberately planned by the team.
- The example illustrates unintended architectural consequences that can arise when using AI agents in development workflows.
