# Quoting Paul Dix

Paul Dix describes how AI wrote one million lines of code and then refined it over several months into reliable software running on millions of developer machines. He acknowledges the common objection that an oracle (a reference implementation) made the task easier, but argues this undersells the achievement. Dix emphasizes that with a verification system and proper direction, AI can produce and iteratively refine highly complex software until it works. The quote appears on Simon Willison's blog, where it is shared as a notable observation about AI-assisted programming.

- AI generated 1M LOC and iteratively refined it into production software used on millions of machines.
- The presence of an oracle for comparison does not diminish the difficulty of the task.
- Verification systems and clear direction enable AI to build sophisticated software.
- AI can continuously refine code until it meets reliability standards.
