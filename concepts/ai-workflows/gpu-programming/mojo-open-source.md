# Mojo is now open source

Mojo, a language initially positioned as a superset of Python, has been open sourced. The original plan was to be fully compatible with Python to leverage its ecosystem, but that changed around August 2025. The project now acknowledges that Mojo may or may not become a full Python superset, and it's acceptable if it doesn't.

- Mojo is now open source.
- The stated goal of being a Python superset was abandoned around August 2025.
- AI-assisted coding tools are expected to help migrate Python code to Mojo.
- Mojo is optimized for GPU programming with Python-inspired syntax, not necessarily 100% compatible with existing Python code.
