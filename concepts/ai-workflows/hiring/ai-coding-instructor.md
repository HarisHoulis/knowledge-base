# Hiring: Part Time Instructor, Write Production Grade Code with AI

ByteByteGo is hiring a part-time instructor for a live, cohort-based course titled 'Write Production Grade Code with AI'. The course focuses on teaching software engineers how to reliably ship production-grade software using AI coding agents. Students learn to delegate real work to agents, write specs and plans that agents can execute, and verify, review, and secure the resulting code (Source: ByteByteGo, 2026).

- The course teaches engineers to delegate real work to coding agents, write executable specs, and verify AI-generated code.
- Instructor responsibilities include refining curriculum, teaching live sessions, answering student questions, and sharing practical AI-engineering lessons.
- Commitment is approximately 2 to 10 hours every two weeks after initial onboarding, fitting alongside a full-time engineering role.
- Ideal candidates have 5+ years of professional experience, daily use of AI coding agents, and expertise in spec-writing, code review, and AI agent internals.
- Compensation is competitive and based on experience; interested applicants contact jobs@bytebytego.com.
