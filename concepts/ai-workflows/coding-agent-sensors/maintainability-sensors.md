# Maintainability sensors for coding agents

The article introduces Birgitta Böckeler's work on harness engineering for coding agent users, presenting a mental model of guides and sensors that help improve the quality of agent outputs. Guides increase the probability of good outcomes, while sensors enable self-correction before problems reach human review. This specific installment focuses on static analysis as a sensor, particularly using basic code linting to maintain codebase health.

- Harness engineering for coding agents involves a system of guides and sensors.
- Sensors increase the probability of good agent outputs by detecting issues early.
- Sensors enable self-correction before issues reach human eyes.
- Static analysis with basic code linting is one effective type of sensor for maintainability.
