# Stop Burning Your Context Cash

He advises against stating obvious information that agents can infer from the repository and strongly recommends using progressive disclosure to keep context lean. He also warns that conflicting instructions from system prompts, auto-loaded skills, and user requests can confuse agents, so skills should be generally applicable and loaded on demand rather than always in context. As models improve, workflows must adapt; previously valuable context engineering tactics may become myths that waste resources (Kent C. Dodds, 2026).

- Large AGENTS.md/CLAUDE.md files often burn context dollars without improving agent usefulness.
- Claude Code removed 80% of its system prompt for advanced models, showing that context engineering best practices shift quickly.
- Avoid stating the obvious; let agents discover information from the repo. Use progressive disclosure heavily.
- Minimize conflicts between system prompts, skills, and user prompts by keeping instructions general and loading skills on demand.
- Continuously re-evaluate workflows as models improve; former best practices can become myths.
