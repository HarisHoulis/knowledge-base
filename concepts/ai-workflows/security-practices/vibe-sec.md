# The VibeSec Reckoning

Vibe coding accelerates software prototyping but AI agents frequently recommend insecure configurations, creating security problems. Gautam Koul, Lucian Moss, Neil Drew-Lopez, and Daberechi Ruth Edeokoh share their experience building applications for Thoughtworks's global marketing. They learned that to combat this, teams need to write a security context file to guide the AI, be cautious with AI permission requests, create a daily security intelligence feed, and provide builders with a secure-by-default harness and templates.

- AI agents often suggest insecure configurations during vibe coding.
- Write a security context file to guide AI behavior and constraints.
- Be cautious with AI permission requests to avoid over-privileged access.
- Create a daily security intelligence feed to stay updated on threats.
- Provide builders with secure-by-default harnesses and templates.
