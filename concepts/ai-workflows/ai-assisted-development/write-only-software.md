# Complexity and Creativity in Software Engineering

Phillip Mortimer discusses the shift toward write-only software driven by AI code generation. He explains why traditional pull requests are broken and shares how engineering leaders can manage complexity (Mortimer, InfoQ presentation).

Mortimer recommends decoupling intent from implementation, automating code reviews, and building self-healing architecture to unleash developer creativity across senior engineering and architecture teams (Mortimer, InfoQ presentation).

- AI code generation is driving a shift toward write-only software.
- Traditional pull requests are broken for this new paradigm.
- Engineering leaders can manage complexity by decoupling intent from implementation.
- Automating code reviews and building self-healing architecture are recommended practices.
- These approaches aim to unleash developer creativity across senior engineering and architecture teams.
