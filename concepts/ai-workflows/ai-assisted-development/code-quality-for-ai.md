# Do software fundamentals still matter?

Building codebases that AI 'loves to work in' means prioritizing maintainability, readability, and modularity. These principles reduce cognitive load for both humans and AI, allowing tools like Copilot or other agents to infer intent and make correct changes. The takeaway is to double down on fundamentals instead of neglecting them in the rush to leverage AI.

- Code quality becomes more important for AI agents, not less.
- Software entropy, if uncontrolled, hampers AI effectiveness.
- Good design patterns provide structure that AI agents can leverage.
- Create codebases that are easy for AI to navigate and modify safely.
