# LIVE: Uncle Bob on Software Fundamentals in the Age of AI

In this interview, Uncle Bob Martin reflects on his long career in software development, spanning over half a century since his first program in 1964. He shares his initial skepticism toward AI chatbots like ChatGPT and Grock, noting that he was not impressed by early outputs. However, around December, he began experimenting with an early Grock agent and found that while it could write code quickly, it produced poor quality results that required constant cleanup. The conversation underscores the enduring importance of software fundamentals, such as clean code and human oversight, even as AI tools become more prevalent in development workflows. Uncle Bob's hands-on experience illustrates that AI agents can accelerate coding but still demand rigorous review and correction from experienced developers (Pocock, 2026).

- Uncle Bob has been a programmer for over 50 years, starting in 1964.
- He was initially unimpressed with AI chatbots but later experimented with a Grock agent.
- The agent wrote code quickly but poorly, leaving messes that required cleanup.
- Software fundamentals like code quality remain essential when using AI tools.
- AI assistance requires human oversight to manage quality and correctness.
