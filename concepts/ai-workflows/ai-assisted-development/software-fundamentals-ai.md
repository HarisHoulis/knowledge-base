# Do software fundamentals still matter?

In this short, Matt Pocock argues that software fundamentals such as code quality, managing software entropy, and good design patterns are more important than ever in the age of AI. Rather than being made obsolete, these fundamentals enable AI agents to work effectively. The key takeaway is to build codebases that are structured and maintainable so AI can understand and modify them with less friction. The video points to additional resources at aihero.dev for details on building AI-friendly codebases.

- Code quality is increasingly critical when AI agents work with codebases.
- Software entropy must be actively managed to keep AI agents productive.
- Good design patterns help AI understand and safely modify code.
- Developers should aim to build codebases that AI agents 'love' to work in.
