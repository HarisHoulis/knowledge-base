# Do Software Fundamentals Still Matter in the Age of AI?

In this short video, Matt Pocock argues that software fundamentals remain essential even as AI agents become more involved in coding. Rather than being made obsolete, code quality, software entropy, and good design patterns are more important than ever because AI agents rely on clean, well-structured codebases to function effectively.

Pocock emphasizes that managing software entropy—the gradual degradation of code quality—becomes critical when AI agents are generating and modifying code. Without solid fundamentals, AI can quickly create chaotic codebases. By maintaining good design patterns and reducing complexity, developers can build codebases that AI agents can navigate and extend reliably.

The takeaway is that investing in fundamentals is not about 'old-school' discipline; it is about enabling modern AI workflows. A well-organized codebase is one that AI loves to work in, leading to better AI suggestions, fewer bugs, and more maintainable projects.

- Software fundamentals are not made obsolete by AI; they become more important.
- Code quality helps reduce software entropy, which AI agents can otherwise accelerate.
- Good design patterns help AI agents understand and modify codebases safely.
- Building 'AI-friendly' codebases requires strong fundamentals to maximize AI effectiveness.
