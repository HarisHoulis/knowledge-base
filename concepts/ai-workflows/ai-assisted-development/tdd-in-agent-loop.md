# TDD inside the agent loop - theater or actual value?

The article questions whether Test-Driven Development (TDD) adds real value when used inside an LLM agent loop. It notes that Thoughtworks colleagues are strong advocates of TDD, and that many in the industry recommend telling agents to use TDD when building software. 

To examine this, Birgitta Böckeler conducted a few experiments, as described in the article. The title poses the central question: is TDD in the agent loop theater or actual value? This suggests an empirical investigation into the practice rather than relying on assumption.
