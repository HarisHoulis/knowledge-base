# Impressions from visiting OpenAI, Anthropic, & Cursor

In this article, Gergely Orosz shares observations from visiting the offices of OpenAI, Anthropic, and Cursor, with a central theme: the rise of cloud-based AI agents. All three companies are betting heavily on agents that run in the cloud rather than on local machines. OpenAI's acquisition of Ona (formerly Gitpod) is cited as a move to expand Codex beyond device-bound sessions, while Anthropic is investing in Claude Managed Agents, a hosted service for long-running agents. Cursor has released Cloud Agents and launched an iOS app that leverages them for asynchronous, merge-ready work (Orosz, 2026).

- OpenAI, Anthropic, and Cursor are all prioritizing cloud-based agents, expecting demand to grow massively.
- At OpenAI, over 95% of non-engineers use Codex instead of ChatGPT, signaling broader adoption of coding agents.
- Anthropic's Claude Tag (Slack integration) removes setup and context-switching, making it easier to kick off remote agents.
- Cursor's Sualeh Asif notes cloud agents lack a human feedback loop, so they 'confess' errors to improve the agent environment.
- The shift to cloud agents is driven by better coding models, mature agent infrastructure (MCP, skills), larger context windows, and cloud GPU capacity.
