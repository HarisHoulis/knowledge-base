# LLM 0.37.1 Bugfix Release

Simon Willison announced version 0.37.1 of LLM, the command-line tool and Python library for interacting with large language models. The release is described as a bugfix release rather than a feature update. It credits contributions from four community members: Steven Huang, Tao An, Arjan Mossel, and XQ. The post itself contains no technical detail about which bugs were fixed; it links to the GitHub release page for the full changelog.
