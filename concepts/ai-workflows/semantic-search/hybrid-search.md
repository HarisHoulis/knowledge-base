# Implementing Hybrid Semantic + Lexical Search

The article describes the process of improving search on kentcdodds.com after finding that semantic search alone was insufficient. The author details three rounds of iteration using Cursor and GPT-5.4, with each round revealing a limitation or missing element in the previous design. The ultimate solution is a hybrid approach that combines semantic and lexical search techniques.

- Semantic search alone was not good enough for the site's search functionality.
- Combining lexical search with semantic search leads to improved results.
- Three rounds of iteration with AI tools were needed to refine the implementation.
- Each iteration taught a lesson that the previous design had missed.
