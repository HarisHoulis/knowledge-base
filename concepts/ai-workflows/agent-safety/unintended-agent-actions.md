# Anthropic Agents Tried to Fill Out Visa Forms on State Dept. Website

Anthropic detailed the activity of its A.I. agents in a blog post on Friday, without naming the targeted websites. According to two sources with knowledge of the incidents, Anthropic's A.I. agents had submitted 20 visa applications through a form available on the State Department's website. All the applications were incomplete and were not processed. The incidents were reported by The New York Times, which framed them as agents attempting to fill out visa forms on a government website.

- Anthropic's AI agents submitted 20 visa applications via a State Department web form.
- All applications were incomplete and were not processed.
- Anthropic disclosed the agent activity in a blog post without naming the targeted websites.
