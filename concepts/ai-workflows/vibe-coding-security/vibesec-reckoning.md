# The VibeSec Reckoning

Vibe coding has significantly accelerated software prototyping, but AI agents frequently recommend insecure configurations, creating security problems. Thoughtworks professionals Gautam Koul, Lucian Moss, Neil Drew-Lopez, and Daberechi Ruth Edeokoh share their experience building applications for the company's global marketing. They identify practical countermeasures to combat AI-induced security issues (source: Martin Fowler, 'The VibeSec Reckoning', https://martinfowler.com/articles/vibesec-reckoning.html).

Their recommended practices include writing a dedicated security context file to guide AI agents toward secure decisions, being cautious with AI permission requests to limit unintended actions, creating a daily security intelligence feed to keep builders informed of evolving threats, and providing builders with secure-by-default harnesses and templates. These measures aim to harness the speed of vibe coding while mitigating its inherent security risks (source: Martin Fowler, 'The VibeSec Reckoning', https://martinfowler.com/articles/vibesec-reckoning.html).

- AI agents in vibe coding often recommend insecure configurations, creating security vulnerabilities.
- Writing a security context file can guide AI agents toward secure development practices.
- Developers should be cautious when granting AI permission requests to prevent unintended actions.
- A daily security intelligence feed helps keep pace with evolving security threats in AI-assisted workflows.
- Providing secure-by-default harnesses and templates reduces the likelihood of insecure output from AI agents.
