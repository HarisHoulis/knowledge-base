# Claude Code's system tools are SO BLOATED

Matt Pocock demonstrates how to dramatically reduce Claude Code's system prompt size by disabling unused features and tools. By customizing the global settings.json file, he shows how to drop the system prompt from 25,000 tokens down to just 8,000 tokens, resulting in a leaner, more efficient setup.

- Claude Code's default system prompt contains significant bloat from unused features and tools.
- Customizing the global settings.json file allows disabling these unused components.
- The system prompt can be reduced from 25,000 tokens to 8,000 tokens, a 68% reduction.
- A guide is available at https://aihero.dev/s/D9UXCK for step-by-step instructions.
