# LLM 0.35 Release

The LLM command-line tool has been updated to version 0.35. This release adds support for OpenAI's new GPT-6 Astra model via the model identifier gpt-6-astra. No other changes are explicitly mentioned in the post. The page also lists several recent articles on related AI topics.

- LLM 0.35 is released.
- Support for OpenAI's GPT-6 Astra model is added.
