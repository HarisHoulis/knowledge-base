# DigitalOcean Managed Agents: Managed Infrastructure for AI Agents

DigitalOcean launched DigitalOcean Managed Agents in public preview, according to Sergio De Simone's InfoQ report (InfoQ, 2026). The offering is described as a managed cloud infrastructure layer for AI agents.

The report highlights isolated microVM runtimes, governed tool access, and serverless AI inference as key capabilities of the managed agents offering (InfoQ, 2026).

- DigitalOcean Managed Agents is available in public preview.
- It provides a managed cloud infrastructure layer for AI agents.
- Key capabilities include isolated microVM runtimes, governed tool access, and serverless AI inference.
