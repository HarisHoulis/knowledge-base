# TDD inside the agent loop - theater or actual value?

The article examines the practice of instructing LLM-based coding agents to use Test-Driven Development (TDD). It notes that TDD is strongly favored within Thoughtworks and widely recommended in the context of AI-assisted software development [1]. 

Birgitta Böckeler, a Thoughtworks colleague, questioned whether such TDD instructions genuinely improve outcomes. To explore this, she ran a series of experiments to compare agent behavior with and without TDD guidance [1]. 

The article's title frames the central question: does TDD in the agent loop bring actual value or is it merely a theatrical ritual? By referencing concrete experiments, it aims to provide evidence-based insight rather than relying on conventional wisdom [1].

- TDD is a popular directive for LLM agents in software development.
- Birgitta Böckeler's experiments are presented as an empirical check on its effectiveness.
- The article contrasts 'theater' (performing TDD without benefit) against 'actual value' (real improvement in outcomes).
