# Tell Your Agents to CARE About the Codebase

Matt Pocock argues that AI agents are strong at tactical programming but weak at strategic thinking, meaning they will not naturally prioritize long-term code quality, refactoring, or architecture. Because of this, developers must explicitly guide agents to care about the codebase rather than assuming good engineering judgment will emerge on its own.

The video frames this as a necessary division of labor: the human supplies strategic direction, while the agent executes tactical work. With that guidance, Pocock claims agents can become brilliant at maintaining code quality and architecture, not just producing working code.

- AI agents excel at tactical programming but struggle with strategic thinking.
- Agents need explicit guidance to care about long-term code quality, refactoring, and architecture.
- With the right direction, agents can become brilliant at strategic code concerns.
