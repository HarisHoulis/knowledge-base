# Hiring: Part Time Instructor, Write Production Grade Code with AI

ByteByteGo is hiring a part-time instructor for a live, cohort-based course titled "Write Production Grade Code with AI". The course is designed for software engineers and focuses on teaching how to reliably ship production-grade software using coding agents. Students will learn to delegate work to agents, write executable specs and plans, and verify, review, and secure the resulting code. The instructor role involves refining the curriculum, teaching live sessions, answering student questions, and sharing practical experiences from building software with AI. The commitment is approximately 2 to 10 hours every two weeks after initial onboarding, making it flexible alongside full-time engineering work, with competitive compensation based on experience.

- Part-time instructor role for a course on shipping production-grade code with AI coding agents.
- Responsibilities include curriculum refinement, live teaching, answering questions, and sharing practical AI-driven development lessons.
- Requires 5+ years of professional engineering experience, daily use of AI agents like Claude Code, and deep understanding of agent planning, tool use, and failure modes.
- Ideal candidates can break down complex problems into clear AI-executable specs, make legacy codebases AI-friendly, and rigorously review AI-generated code for correctness and security.
- Commitment is flexible (2-10 hours biweekly) and compensation is competitive.
