# datasette-apps 0.3a0: Agent-Driven App Creation with Permission Checks

datasette-apps 0.3a0 adds support for hosting and editing custom HTML applications inside Datasette, which can be built by hand or more easily generated by LLMs through Datasette Agent. The release focuses on tightening that agent integration.

Apps can now be tagged in Datasette Agent chat messages by typing `#`, which autocompletes from apps the user has permission to view. New `app_add_stored_queries()` and `app_remove_stored_queries()` tools let the agent manage which stored queries an app may call, with write-query grants requiring user approval first.

`app_create()` now validates that each requested stored query exists and is viewable by the user, and prompts for approval of write queries before creating the app. The agent's "View app" buttons and `#` app reference links now open the app full screen in the Datasette Agent panel.

- Apps can be created by hand or generated via Datasette Agent using LLMs
- Typing `#` in agent chat autocompletes apps the user can view
- New tools let the agent add/remove stored queries an app may call, with approval for write queries
- app_create() validates query existence and permissions before creation
