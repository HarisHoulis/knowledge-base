# Building an Agent That Builds the Culture: Ramp's Inspect

Zach Bruggeman, an engineer at Ramp, describes how the company bet on building its own coding agent, Inspect, roughly a year before the talk. Inspect runs each session remotely and is fully multi-user, so it can work alongside an individual or a team across integrations like Slack and Linear. It has grown beyond code writing to include design primitives, validation agents, and validation flows, letting developers go from request to delivery inside the tool, and it connects to company data and tools such as telemetry and databases. Today about 75% of all Ramp code is written and delivered by Inspect.

With the plumbing now widely understood, Bruggeman shifts focus from technology to culture. His first lesson is to create tools that break down information silos: when a pattern or tool works well, it can be rolled out company-wide immediately, and Inspect serves as a reliable baseline so people don't have to constantly maintain their own settings. He argues individuals can't always know the best way to work with agents, so having a single Inspect for the entire company lets improvements be implemented everywhere, often invisibly, with users benefiting from changes made by others.

A second cultural mechanism is working in public by default. Because every Inspect session is public within the company, it's easier to work publicly than privately, and teammates learn by watching each other in channels they already inhabit. Formal training sessions like "how to use AI effectively" weren't needed; instead, users can ask Inspect to review recent sessions and explain how teammates structure prompts or tackle complex problems. This benefited both Ramp developers and the Inspect team itself.

- Ramp built its own multi-user, remote-session coding agent, Inspect, which now writes and delivers about 75% of Ramp code.
- Create tools that break down information silos: a single company-wide agent lets good patterns propagate instantly and provides a reliable baseline.
- Make sessions public by default so people learn from teammates organically rather than through formal AI training sessions.
- Users can ask the agent to review recent sessions and explain how others structure prompts and solve complex problems.
