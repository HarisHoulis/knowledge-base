# Your Effort Level Is Still Too High

Matt Pocock argues that setting an AI coding agent's effort level too high sabotages coding tasks. He explains the crucial difference between effort levels and why lower settings often produce better results for code exploration and simple changes. The video is a short-form tip aimed at developers using AI agents in their workflow.

- Setting an AI agent's effort level too high can sabotage coding tasks.
- Lower effort settings often produce better results for code exploration and simple changes.
- Understanding the difference between effort levels is crucial for effective agent use.
