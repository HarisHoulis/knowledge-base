# AI-Friendly Code: The Missing Link for Speed with Quality

Adam Tornhill argues that while the tooling around software development changes weekly, the fundamentals remain stable for decades, and those fundamentals should guide how we adopt agent-based programming. After switching to doing all his coding through agents since September 2025, he reports producing more software in a year than in prior decades, and his team's tracked task completion times improved two to three times faster within a few months. He stresses that speed alone understates the value: the real benefit is that faster work enables tasks that were previously impossible, and lets developers unblock themselves (e.g., handling simple GitHub Actions work) instead of interrupting colleagues, preserving flow.

However, he warns that developing with agents is more difficult than writing code by hand, and quality is the obvious challenge. He cites production data from late 2025 showing a 41% increase in defects after AI implementation, and a study of over 1,000 open-source projects where speed initially rose by 200% but within about two months the gains were completely leveled and projects became slower than before AI. He attributes this to fundamentals that agents expose rather than change.

His proposed lens is code behavior analysis, the concept from his book, applied to making better decisions about agent programming. The talk positions AI-friendly code as the missing link that reconciles speed with quality, using stable software fundamentals to guide agent workflows.

- Agent-based development can yield 2-3x faster task completion, but the greater value is enabling previously impossible work and reducing coordination overhead.
- Production data from late 2025 showed 41% more defects after AI adoption, highlighting external quality as the main risk.
- A study of 1,000+ open-source projects found an initial 200% speed gain that vanished within two months, with projects ending slower than before.
- Code behavior analysis is presented as a stable, fundamentals-based approach for making better decisions about agent programming.
