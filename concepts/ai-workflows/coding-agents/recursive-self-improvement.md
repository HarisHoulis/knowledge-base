# Pick Problems That Survive When AI Solves Coding

Ara Khan, a founding engineer at Cline, frames the talk around three goals: understanding Frontier Labs' intentions and roadmaps, planning a software career when models improve rapidly, and avoiding becoming a 'permanent underclass' as AI absorbs more coding work. He notes that projects once showcased on personal sites or GitHub can now be produced with a single request to an advanced coding agent, raising the question of how developers demonstrate skill and prove competence.

- Coding agents can now generate projects that developers once showcased on personal sites or GitHub, forcing a rethink of how skills are demonstrated.
- Khan argues careers should be planned around problems that remain valuable even as models get better at coding.
- The talk examines recursive self-improvement: an AI system helping create a more capable successor, with coding agents as the classic example.
- Concerns about profits concentrating among GPU and model companies motivate re-prioritizing which challenges developers take on.
