# Entire's Git Forge Rethinks Git Collaboration for Coding Agents

Entire is a Git forge built specifically for collaboration between human developers and AI coding agents. Its core premise is that traditional software development infrastructure, especially the pull request model, is poorly suited to an environment where AI agents generate, review, and iterate on code at high speed (InfoQ, Sergio De Simone).

- Traditional PR-based workflows are argued to be ill-suited for high-speed AI agent code generation and review
- Entire positions itself as a Git forge purpose-built for human-agent collaboration
- The project targets the mismatch between existing dev infrastructure and agent-driven iteration
