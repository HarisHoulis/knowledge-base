# datasette-agent 0.5a0: Agent Panel Alongside Datasette Pages

datasette-agent 0.5a0 introduces a feature called the panel, which lets the agent chat open and sit next to pages from Datasette, such as a table or query page. Combined with datasette-apps, this allows a user to prompt a database-backed app into existence and then modify it from the chat positioned next to that app. The release can be tried by signing in with a GitHub account at agent.datasette.io.

- The panel lets the agent chat open alongside Datasette pages like tables and queries.
- Paired with datasette-apps, users can prompt a database-backed app into existence and modify it from the adjacent chat.
- The release is available to try at agent.datasette.io via GitHub sign-in.
