# More than just code review

The article argues that the key skill for using coding agents effectively is the ability to confidently instruct them on changes and then confidently verify those changes were applied correctly. This goes beyond traditional line-by-line code review, which the author suggests has never been the most effective way to validate software changes. Instead, verification can take many forms, depending on the context and the nature of the change.

- Productive use of coding agents requires confident instruction and confident verification.
- Reviewing every line of code is sometimes necessary, but not always the best approach.
- Alternative verification methods can be more effective than eyeballing code.
