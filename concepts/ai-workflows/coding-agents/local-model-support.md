# Google Antigravity SDK Adds Local Model Support for Greater Token Efficiency and Code Privacy

Google has introduced support for local models in the Antigravity SDK, allowing developers to build and execute agentic workflows directly on their own machines. According to InfoQ, this approach lets developers retain the flexibility to mix in cloud-based models for higher-level tasks.

The stated benefits center on developer control: data privacy, inference costs, network dependencies, and computational workload distribution. By running workflows locally, developers can avoid sending code to remote services and reduce token consumption tied to cloud inference.

- Antigravity SDK now supports local models for building and executing agentic workflows on-device
- Cloud-based models can still be mixed in for higher-level tasks
- The approach targets greater control over data privacy, inference costs, network dependencies, and workload distribution
