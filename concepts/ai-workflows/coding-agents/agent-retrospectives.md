# Using the /retro Skill to Turn Agent Mistakes into Guardrails

Matt Pocock presents the /retro skill as a way to run retrospectives on an AI coding agent's mistakes and convert those mistakes into lasting improvements. Rather than letting an agent repeat the same errors, the retrospective step treats each failure as a signal to be captured and acted on.

The core practice is to automate checks and add guardrails to the codebase based on what the retrospective surfaces. This closes the loop between an agent's observed errors and the project's automated safeguards, so the same class of mistake is caught mechanically in the future.

Pocock points viewers to his published skills collection and community channels for keeping up with new skills as they are released.

- The /retro skill runs retrospectives on an agent's mistakes.
- Retrospective findings should be turned into automated checks and codebase guardrails.
- The goal is preventing repeated agent errors rather than fixing them one-off.
- Pocock maintains a public skills collection and community channels for updates.
