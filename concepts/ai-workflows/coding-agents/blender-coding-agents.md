# Using Blender with coding agents on macOS

The post demonstrates how to use Blender with coding agents on macOS. By installing the full Mac application from blender.org, users can issue natural language prompts to a coding agent like ChatGPT Codex, which then generates Blender scenes using Blender's Python API. The author provides example prompts, such as "Use the already installed /Applications/Blender to render a scene of a pelican riding a bicycle," followed by iterative requests to add a background and enhance the image. The resulting image is produced entirely through code generated by the agent, showing how AI tools can drive 3D rendering tasks without manual scripting.

- Install the full Blender macOS app from blender.org to enable coding agent integration.
- Natural language prompts to coding agents (e.g., ChatGPT Codex) are sufficient to direct Blender.
- The coding agent leverages Blender's Python API to create and render scenes automatically.
- Iterative prompts can be used to refine and improve the generated image.
