# More than just code review

The article argues that the key skill for making productive use of coding agents is the ability to confidently instruct them on changes and then confidently verify those changes. This often extends beyond traditional code review. The author notes that while reviewing every line of code is one way to achieve confidence, it has never been the most effective way to validate a software change. Instead, there are alternative methods to ensure correctness, emphasizing that effective use of coding agents hinges on clear instruction and robust verification techniques.

- The core skill for coding agents is instructing and verifying changes.
- Line-by-line code review is not always the most effective validation method.
- Confidence in changes can be achieved through alternative verification strategies.
- Clear instructions and trustworthy verification are essential for productive agent use.
