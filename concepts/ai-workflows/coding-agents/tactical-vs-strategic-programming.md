# Your Agent Is a Tactical Tornado

In this short, Matt Pocock describes AI agents as "tactical tornadoes" — they excel at making immediate, local changes but lack the long-term perspective needed for code health. The core distinction is between tactical programming, which focuses on short-term fixes and quick wins, and strategic programming, which considers maintainability and architecture over time.

Because agents default to tactical behavior, Pocock argues the developer must take on the role of strategist when working with them. The human provides direction and long-term thinking, while the agent handles the rapid tactical execution. Without this division of responsibility, agent-driven work risks degrading code health.

- AI agents behave like "tactical tornadoes," optimizing for immediate changes rather than long-term code health
- Tactical programming targets short-term fixes; strategic programming targets maintainability and architecture
- The developer must act as the strategist when directing AI agents
- Guiding agents toward long-term code health requires human strategic oversight
