# When Not to Use /grill-me: Choosing Between One-Shotting, Grilling, and Wayfinder

Matt Pocock presents a decision tree for choosing how much process to apply to an AI-assisted coding task. Small changes should be one-shotted directly, without invoking a grilling session. Medium-sized work benefits from a /grill-me grilling session, where the agent interrogates the task before implementation. Large-scale projects should use Wayfinder instead of grilling.

The core idea is matching process overhead to task size: the heavier the planning tool, the larger the task it is meant for. Using /grill-me on trivial changes wastes effort, while skipping structured approaches on large projects risks poor outcomes.

- One-shot small changes rather than running a grilling session
- Use /grill-me for medium-sized work
- Use Wayfinder for large-scale projects
- Match planning overhead to task size
