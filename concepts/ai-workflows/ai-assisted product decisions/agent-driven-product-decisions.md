# Use AI to make product decisions

Kent C. Dodds demonstrates how to use an AI agent (Cody) to make product decisions, using Cloudflare Agent Week as a case study. He shares a blog post link with the agent, which analyzes it and surfaces strategic opportunities for Cody, such as the Cloudflare Computer concept and a new workspace assistant primitive. The core lesson is that product decisions revolve around primitives, and agents can help identify and evaluate these primitives quickly by synthesizing external information and existing repo capabilities.

The talk emphasizes a durable skill: aligning with your agent to explore new platform features and convert them into product opportunities. Dodds also explains how Cody's repo sessions work, contrasting coding-agent workflows with MCP-based communication for updating packages. He highlights the importance of building on simple primitives and letting the platform handle complex mechanics, which is a key consideration when deciding what features to build or adopt.

- Agents can be used to analyze external sources (e.g., blog posts) and propose product features or primitives.
- Product decisions revolve around primitives: identifying the right abstraction levels (e.g., Cloudflare Computer vs. containers).
- Alignment with your agent is a durable skill that requires treating the agent as a collaborator in decision-making.
- Cody supports two workflows: coding-agent-driven repo changes and MCP-based repo sessions for package updates.
