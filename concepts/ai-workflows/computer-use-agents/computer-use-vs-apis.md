# Computer-use models will agentify the web, not APIs

Dhruv Batra argues that while AI agents will become the primary drivers of actions on the web, the common assumption that this will happen through APIs is wrong. He agrees that agents will increasingly interact with web services on behalf of humans, but rejects the idea that the web will be systematically reorganized around machine-readable endpoints (Batra, 2026).

He illustrates this with real-world examples: a restaurant website may present its menu as simple text, a PDF, or a gallery of JPEG images that require OCR to read. Such sites do not offer structured endpoints for queries like "list gluten-free items." Similarly, a business wanting to ask whether a school district is procuring laptops cannot rely on an API for each district. These cases represent the long tail of the web, which is built for human eyeballs, not for automated API calls. Therefore, Batra concludes, computer-use models—which can navigate and interpret web pages like humans—will be the means by which the long tail of the web is agentified (Batra, 2026).

- AI agents will become the primary actors on the web, but not through a universal API layer.
- Computer-use models will handle the long tail of websites that lack APIs.
- Many real-world sites are image-based or PDF-based, requiring computer vision and OCR rather than structured endpoints.
- The head of the web may offer APIs, but the long tail will not be retrofitted for agents.
- Examples include restaurant menus and school district procurement inquiries, where no endpoint exists.
