# Computer-use models will agentify the web, not APIs — Dhruv Batra, Yutori

Dhruv Batra argues that while AI agents will become the primary drivers of web actions, the common belief that the web will be 'API-fied' to accommodate them is delusional—especially for the long tail of the web. He agrees with the premise that agents will replace human eyeballs, but rejects the idea that websites will uniformly expose APIs or protocols for agent consumption [1]. Instead, computer-use models will be the mechanism through which agents interact with the messy, unstructured web [1].

To illustrate, Batra shows real-world examples like restaurant websites where menus are stored as PDFs or embedded as pixelated images in galleries, and school district procurement pages that lack any structured endpoint. These sites are hostile to automation and offer no JSON APIs; they require visual understanding and human-like clicking and reading [1]. Thus, computer-use agents—not APIs—will handle these long-tail scenarios [1].

While the most popular sites (the 'head' of the distribution) may provide APIs, the vast majority of the web will not. Computer-use models will 'agentify' the web by directly interacting with these unstructured interfaces, filling the gap left by the absence of APIs [1].

- APIs will not cover the long tail of the web; most sites lack structured endpoints.
- Computer-use models will be the primary way agents interact with messy, unstructured websites.
- Examples like restaurant menus in PDFs/images and school district RFPs show the need for visual interaction.
- Major platforms may offer APIs, but the long tail will rely on computer-use agents.
- The web will be agentified through human-like browsing, not protocol-driven API calls.
