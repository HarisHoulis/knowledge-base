# TDD inside the agent loop - theater or actual value?

The article examines the practice of instructing LLM-based coding agents to follow Test-Driven Development (TDD). Many practitioners, particularly at Thoughtworks, advocate this approach as a way to improve code quality and reliability. The central question is whether such instructions genuinely add value or simply give an impression of rigor without tangible benefits.

Birgitta Böckeler, curious about the actual effectiveness of TDD in agentic workflows, conducted a few experiments to determine if instructing agents to use TDD makes a real difference. The experiments are part of a broader exploration into how generative AI tools can be integrated into software development practices. The article discusses whether TDD in the agent loop is meaningful engineering practice or mere theater.
