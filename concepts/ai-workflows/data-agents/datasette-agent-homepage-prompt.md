# datasette-agent 0.6a0

datasette-agent 0.6a0 is a release of Simon Willison's agent plugin for Datasette that lets users ask questions about their data. The release consists of accumulated small fixes, with the most notable change being an agent prompt added directly to the Datasette homepage. That homepage prompt supports hash-mentions of tables and queries, letting users reference specific data objects when asking questions.

- datasette-agent is an agent plugin for Datasette for asking questions about your data
- Version 0.6a0 is mainly accumulated small fixes
- The agent prompt now appears directly on the Datasette homepage
- The prompt supports hash-mentions of tables and queries
