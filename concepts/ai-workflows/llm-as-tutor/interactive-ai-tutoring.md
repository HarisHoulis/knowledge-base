# Using ChatGPT as an Interactive Tutor to Learn Quaternions

Matt Webb describes how, after releasing version 1.0 of Galactic Compass, he expected to manually implement rotations. Instead of asking ChatGPT to write the code, he used it as a patient, interactive tutor to learn about quaternions. This approach succeeded where reading books and asking mathematician friends had not, allowing him to learn just enough to make the app work (source: https://simonwillison.net/2026/Aug/21/matt-webb/).

Webb reflects that outsourcing thinking to AI does not stop learning; rather, it pushes him to learn more. He explicitly values this outcome, highlighting how LLMs can serve as educational tools rather than mere code generators. This example illustrates a workflow where AI augments a developer's understanding and capability, rather than replacing it.

- ChatGPT was used as an interactive tutor, not as a code-writing tool.
- Webb learned quaternions enough to make his app work, despite previous difficulties with books and mathematician friends.
- Outsourcing thinking to AI encouraged further learning rather than stopping it.
- LLMs can be effective educational aids in technical workflows.
