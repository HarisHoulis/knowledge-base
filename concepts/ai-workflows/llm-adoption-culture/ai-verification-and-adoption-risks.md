# Fragments: July 21

In this fragment, Martin Fowler summarizes key findings from the Future of Software Development Retreat, most notably that code generation is no longer the bottleneck—verification is. He also highlights the emergence of 'harness engineering' as a distinct discipline, an apprenticeship crisis in the industry, and a growing expectation gap between executives and engineers. The full Thoughtworks report is cited as the source for these findings (Fowler, 2026, https://martinfowler.com/fragments/2026-07-21.html).

- Code generation is no longer the bottleneck; verification and harness engineering are the emerging challenges.
- There is a significant mismatch between executive expectations of LLM productivity and the security and governance risks that engineers see.
- Vibe coding by citizen developers creates shadow IT and security vulnerabilities, requiring separate infrastructure and deterministic controls.
- LLMs are useful for anomaly detection and code understanding in operations, but they are overestimated for autonomous incident resolution and can insert unrequested features.
- Writers should reject LLM-flavored prose and use 'Say Your Writing' techniques to preserve an authentic human voice.
