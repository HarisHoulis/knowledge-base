# Mojo🔥 is now open source

Mojo, the programming language from Modular, has been open-sourced. The announcement highlights a strategic shift from its original goal of being a full superset of Python. Instead, Mojo is now positioned as its own language, optimized to make GPU programming as painless as possible using Python-inspired syntax, though not fully compatible with existing Python code [1]. This change was formalized around August 2025, with the project explicitly stating that it may not evolve into a full Python superset and that this is acceptable [1]. The source also notes that AI-assisted coding tools are already helping migrate Python to Mojo, and future tooling and ecosystem maturity are expected to make this migration even smoother [1]. The open-sourcing is likely to accelerate adoption and community contributions, while the revised language direction clarifies Mojo's niche in the AI and high-performance computing space [1].

- Mojo is now open source, allowing wider community access and contribution.
- The project has abandoned the goal of becoming a full Python superset.
- Mojo is now its own language focused on painless GPU programming with Python-inspired syntax.
- AI-assisted coding tools are expected to ease Python-to-Mojo migration over time.
