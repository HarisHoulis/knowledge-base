# Realtime multiplayer, automation, and you! — Idan Gazit, GitHub

In this talk, Idan Gazit of GitHub Next argues that AI's initial surge focused on personal productivity—LLMs completing what we type and agents fetching resources—but the greatest value comes from enabling groups of people to do more. He frames GitHub Next's work around two durable themes: automation and collaboration, which hold true regardless of future technology changes (Idan Gazit, GitHub).

- AI's greatest value lies in enabling group collaboration, not just multiplying individual productivity.
- Automation should target tasks requiring judgment and intelligence, not just heuristics.
- Agentic Workflows is a prototype for how automations should work in an agentic world.
- Aces is a prototype for real-time multiplayer software development.
- Faster development increases the cost of misalignment; shared understanding is critical.
