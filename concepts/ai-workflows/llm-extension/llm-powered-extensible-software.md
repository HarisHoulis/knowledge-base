# Extensible Software in the Age of LLMs

Jeremy Morrell hypothesizes that LLMs create a new opportunity for extensible software on the web. By dramatically lowering the cost of authoring extensions, LLMs enable users to customize applications in ways that were previously impractical. Modern sandbox primitives further reduce deployment costs and provide strong security boundaries, allowing applications to maintain a solid, accountable core while safely supporting user-driven extensions. The vision is to give users super powers by letting LLMs fill in the missing pieces of functionality, effectively turning every application into a platform for user-defined behavior.

- LLMs radically lower the cost of authoring software extensions.
- Modern sandbox primitives provide security boundaries and lower deployment costs.
- Applications can have a solid, accountable core while users safely extend them.
- LLMs can fill in missing pieces, giving users 'super powers'.
