# Slow Down to Speed Up: AI Agents and the Changing Software Engineering Landscape

The article, based on Gergely Orosz's Craft Conference keynote, argues that AI agents have transformed software engineering in just six months. Simon Willison dates the shift to November 2025, when new models like Opus 4.5 and GPT-5.4 made agents genuinely useful. DHH also notes that earlier resistance to AI-written code faded as models improved. Data from Cursor and Linear show dramatic increases: teams shipping 5x as many pull requests, developers producing 2.5x more code, PR sizes tripling, and more changes accepted without human review.

- AI agents became genuinely useful around November 2025, driving rapid adoption and increased code output.
- Meta's worst-ever outage is presented as a cautionary tale: AI-generated, AI-reviewed code combined with gutted security and integrity teams led to account takeovers.
- Companies like Anthropic, OpenAI, Uber, and traditional enterprises are restructuring development workflows around AI agents, with Anthropic reporting 70-90% of code generated by Claude.
- Individual productivity is up, but team productivity is flat; code review quality is under pressure as AI-generated changes overwhelm reviewers.
- Startups and traditional companies are both investing heavily in AI developer tools, from code review to incident management.
