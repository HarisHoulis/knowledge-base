# Mojo is now open source

The article reports that Mojo, a programming language designed for GPU programming, is now open source. Originally conceived as a superset of Python, the project changed its vision around August 2025, acknowledging that it may not evolve into a full Python superset. Instead, the project relies on AI-assisted coding tools to help migrate Python code to Mojo, as stated in the article: 'We’re encouraged by how well AI-assisted coding tools already help migrate Python to Mojo today' (Simon Willison, 2026).

- Mojo is now open source.
- The original goal of being a Python superset was dropped around August 2025.
- AI-assisted coding tools are expected to help migrate Python to Mojo.
- Mojo is optimized for GPU programming with Python-inspired syntax, but not fully compatible with Python.
