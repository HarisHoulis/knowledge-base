# The Pulse: We need to talk about migrations with AI

The article highlights AI's growing role in large-scale code migrations, using Asana as a case study. Asana needed to migrate off the Enzyme testing framework, which involved rewriting numerous test cases. With AI, the project was completed in two weeks; without AI, it would likely have been postponed indefinitely (Orosz, 2026). This demonstrates AI's ability to accelerate tedious, mechanical engineering tasks.

- Asana completed a migration from Enzyme to a modern testing framework in two weeks using AI, a task that would otherwise have been deprioritized.
- Airbnb and Uber report similar successes with AI-assisted migrations, suggesting a broader trend.
- AI is exceptionally well-suited for framework migrations that involve repetitive code transformations.
- The article also notes shifting engineering leadership roles and skepticism toward Gartner's Magic Quadrant, which may not reflect AI-native tool quality.
