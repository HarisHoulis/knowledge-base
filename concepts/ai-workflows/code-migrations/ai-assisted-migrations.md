# The Pulse: We need to talk about migrations with AI

In this edition of The Pulse, Gergely Orosz highlights how AI is transforming large-scale framework migrations. A prime example is Asana's migration off the Enzyme testing framework, which required rewriting thousands of test cases. With AI assistance, the project was completed in just two weeks—work that would otherwise likely have been postponed indefinitely. Airbnb and Uber report similar successes, suggesting AI is exceptionally well-suited for mechanical migration tasks (Orosz, 2026).

The article also discusses the shifting landscape of engineering leadership, noting that VPE and CTO roles are adapting to a rapidly changing industry. Orosz argues these roles are critical for driving reorganization that improves engineering effectiveness. Additionally, the piece questions the relevance of Gartner's Magic Quadrant for AI code modernization tools, as AWS, Microsoft, and IBM rank above Anthropic, Cursor, and OpenAI—likely due to vendor payments rather than product merit, since AI startups refuse to pay the 'Gartner tax' (Orosz, 2026).

Other industry updates include a lengthy GitHub outage, the rise of GitHub alternatives, Slack introducing Slack Code, Claude text watermarking, and Uber open-sourcing SubmitQueue (Orosz, 2026).

- AI can accelerate large-scale framework migrations: Asana completed an Enzyme migration in two weeks, and Airbnb/Uber report similar wins.
- AI is a natural fit for mechanical, repetitive migration tasks, reducing the urge to postpone such projects.
- Engineering leadership roles (VPE/CTO) must evolve to drive effective organizational change in a fast-moving industry.
- Gartner's Magic Quadrant for AI code tools is increasingly irrelevant because vendors like AWS pay for placement while AI startups decline.
- The broader industry pulse includes GitHub outages, Slack's Code product, Claude watermarking, and Uber's open-source SubmitQueue.
