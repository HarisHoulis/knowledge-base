# Give Your Agent a Goal and Let It Be Creative

Matt Pocock describes an approach to improving AI agents by giving them a goal and letting them work creatively toward it, rather than prescribing exact steps. He illustrates this with a custom video editor project where a scorecard system tracks performance metrics, and agents autonomously iterate to improve those metrics day after day. The core idea combines verification with continuous improvement: define measurable goals, verify outcomes, and let the agent explore solutions on its own.

- Give agents a goal rather than rigid instructions, allowing creative problem-solving
- Use a scorecard system to track performance metrics for verification
- Let agents autonomously work to improve metrics over time through continuous iteration
