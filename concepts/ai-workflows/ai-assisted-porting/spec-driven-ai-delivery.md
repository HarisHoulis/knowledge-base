# Akka Tests Spec-Driven AI Delivery Across 65 Open Source Projects

Akka used 65 open-source projects to examine how specification structure, context, model selection, automated validation, and delivery guardrails affect AI-assisted software porting (InfoQ). The experiment aimed to identify factors that influence the porting process in AI-assisted development.

The experiment measured time, token use, code size, test parity, and performance (InfoQ). It found substantial variation in outcomes across different models, effort levels, and project types (InfoQ).

- Akka used 65 open-source projects to study AI-assisted software porting (InfoQ).
- The study examined specification structure, context, model selection, automated validation, and delivery guardrails (InfoQ).
- Metrics included time, token use, code size, test parity, and performance (InfoQ).
- Results varied substantially across models, effort levels, and project types (InfoQ).
