# Slow down to speed up: so much has changed in 6 months’ time

In this keynote summary, Gergely Orosz argues that the software engineering landscape has been transformed since November 2025, when a new generation of AI agents became genuinely useful. He cites data from Linear showing teams using agents now ship 5x as many pull requests as two years ago, and from Cursor showing developers produce 2.5x more code and pull request sizes have tripled. However, this speed comes with risks: more changes are accepted without human review, leading to quality and security degradation, exemplified by Meta’s worst-ever outage where an AI-generated, AI-reviewed change enabled account takeovers because security and integrity teams had been defunded and reassigned to AI labeling tasks (Orosz, 2026).

Orosz outlines how leading tech companies are adapting. At Anthropic, Claude Code generates ~70-90% of internal code, with PRDs replaced by prototypes and developers running multiple agents in parallel. OpenAI’s Codex team uses AI code review and one-click fixes, while Uber has built custom AI infrastructure including an MCP Gateway, Code Inbox, and AI-driven migration tools. Startups are quickly integrating AI agents into Slack workflows, and traditional companies like Cisco and JP Morgan are also investing heavily. Despite individual productivity gains, team-level productivity remains flat, and software quality is declining as AI slop overwhelms reviewers. Orosz advises engineers to future-proof their careers by focusing on high-judgment tasks, maintaining sharp code review skills, and understanding the broader system rather than just generating code.

- Meta’s outage shows the danger of AI-generated code with AI-only review and gutted security teams, leading to account takeovers and public embarrassment.
- Since November 2025, AI agents have dramatically increased code output and PR volume, but code review thoroughness has decreased, raising quality and security risks.
- AI adoption spans Anthropic, OpenAI, Uber, startups, and traditional companies, each building custom integrations and workflows to manage agent-generated code.
- Individual developer productivity is up, but team productivity is flat, with trends like vanishing middle management and CEOs returning to coding.
- Engineers should double down on judgment, security awareness, and architectural thinking to remain valuable in an AI-augmented development environment.
