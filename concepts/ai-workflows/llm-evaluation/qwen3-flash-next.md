# Qwen3.8-Flash-Next

The article introduces Qwen3.8-Flash-Next, a large language model with 125B total parameters but only 6B active, which provides a significant performance boost. The author tested the model on a DGX Spark using Unsloth quantized GGUF models from Hugging Face, specifically the UD-IQ1_S and UD-Q2_K_XL variants, and shared the generated pelican images. The favorite output came from the UD-Q2_K_XL model with xhigh reasoning effort. The post also links to a Hacker News discussion and is tagged with AI, generative AI, LLMs, Qwen, pelican-riding-a-bicycle, AI in China, and NVIDIA Spark.

- Qwen3.8-Flash-Next has 125B total parameters but only 6B active, leading to a significant performance boost.
- Tested on a DGX Spark using Unsloth quantized GGUF models from Hugging Face.
- Two quantized variants were evaluated: UD-IQ1_S (72.5GB) and UD-Q2_K_XL (78.9GB).
- The best result was obtained with UD-Q2_K_XL using xhigh reasoning effort.
