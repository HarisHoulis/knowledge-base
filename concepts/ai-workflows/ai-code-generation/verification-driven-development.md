# Quoting Paul Dix

Paul Dix highlights a striking example of AI-assisted software development: an AI wrote one million lines of code, then iteratively refined the codebase over several months to produce reliable software now running on millions of developer machines. He acknowledges the counterargument that an oracle (a reference implementation) made the translation straightforward, but argues this minimizes the achievement. The key insight, according to Dix, is that with a strong verification system and clear direction, AI can build highly complex software and continuously refine it until it works correctly.

- AI generated 1M lines of code and refined it over months to achieve production quality.
- The presence of a reference implementation ('oracle') does not diminish the impressiveness of the outcome.
- A robust verification system and clear goals enable AI to handle complex, high-stakes software projects.
- AI can iteratively improve its output when given proper feedback loops.
