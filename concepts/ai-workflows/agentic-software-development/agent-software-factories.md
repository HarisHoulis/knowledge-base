# Why Humans Can't Keep Up With AI-Written Code

Tariq Shaukat, CEO of Sonar, argues that agent-based software development is creating a volume problem that human review cannot absorb. He opens with a historical analogy: 1980s cars were good but inconsistent until Toyota/Lexus demonstrated that quality could be designed into the factory rather than corrected at the end. The principles of that shift—prioritize quality over volume, fix the system not the symptom, design the whole rather than isolated parts, solve problems as they arise, and empower anyone to stop the line—are, he notes, the same ideas behind Agile, Kanban, SRE error budgets, and continuous integration.

Agents change the game, and the numbers show it: a study cited by Shaukat reports a 2450% growth in lines of code written and a 240% rise in commits when asynchronous agents are added to the development cycle. Creating code is now easy and abundant, prompting teams to ask how to build agent-based software factories that scale it. Sonar's forthcoming "State of the Code Developer" survey finds 5% of developers currently use agent-based software factories, with 34% expecting to within a year and 39% in financial services.

Shaukat flags security as a core pitfall—agents that build can also find vulnerabilities and attack systems—and cites Satya Nadella's article calling for an engineering approach to containment and control built on deterministic systems design, human control, and robust operating procedures. The central limitation he highlights is that a human in the control loop does not scale: companies claim people are involved, but code volume and commit growth far outpace human capacity to review it.

- Agent adoption drives explosive code volume—2450% more lines of code and 240% more commits—making human-in-the-loop review a bottleneck.
- Toyota's quality-first factory principles (quality over volume, fix the system, design holistically, stop the line) map directly onto modern software practices like Agile, Kanban, and SRE.
- Only 5% of surveyed developers use agent-based software factories today, but 34% expect to within a year (39% in financial services).
- Agents are dual-use: they can build software and also find vulnerabilities and attack systems, so containment and control matter.
- Following Nadella, Shaukat calls for deterministic systems design, human control, and robust operating procedures to build quality and confidence into agent factories.
