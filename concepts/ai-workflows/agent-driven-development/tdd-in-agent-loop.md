# TDD inside the agent loop - theater or actual value?

The article investigates whether instructing LLM agents to follow Test-Driven Development (TDD) produces tangible benefits or is merely performative. Birgitta Böckeler, a Thoughtworks colleague, conducted experiments to test this question, motivated by the widespread advocacy for TDD in AI-assisted software development. The piece frames the debate around the potential gap between apparent rigor and real outcomes when agents are prompted to use TDD. While many practitioners recommend TDD for agents, Böckeler's experiments aim to determine if this practice genuinely improves code quality or if it's just theater. The article ultimately weighs the evidence to help developers decide whether to adopt TDD in their agent loops (Fowler, https://martinfowler.com/articles/exploring-gen-ai/tdd-in-the-agent-loop.html).
