# Stop Reviewing Diffs. Start Reviewing Systems.

Kent C. Dodds argues that code review is shifting from line-by-line diff review toward system-level review, where the focus is on how the entire system changes rather than individual lines. He presents a spectrum of review depth depending on project criticality, but notes that AI tools are enabling a trend where reviewers can rely less on reading every line and more on understanding systemic impact.

- Move from reviewing diffs to reviewing systems for a holistic understanding of changes.
- AI agents can generate system recaps, including primitives touched, risk level, system maps, and user experience flows.
- System-level review is especially useful for large changes (e.g., 3,000-line PRs) to grasp intent and impact quickly.
- This approach complements, rather than replaces, AI code reviewers that handle line-level issues.
- The depth of review should vary based on project importance and risk tolerance.
