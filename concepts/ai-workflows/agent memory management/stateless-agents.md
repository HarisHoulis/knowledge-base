# Kill your MEMORY.md

Matt Pocock argues that agent memory, such as the MEMORY.md file in Claude Code, is more harmful than helpful for AI agents. He explains that relying on persistent memory can introduce unpredictability and reduce the reliability of agent behavior. Instead, he advises disabling auto-memory entirely to keep agents stateless, which makes their outputs more predictable and easier to control. The recommendation is rooted in the idea that a stateless agent consistently follows the current context without being influenced by potentially stale or irrelevant stored information.

- Agent memory is more harmful than helpful.
- Auto-memory in Claude Code should be disabled.
- Keeping AI agents stateless ensures predictability.
- Memory can cause unpredictable behavior and should be avoided.
