# Einstein Arena: Harnessing Collective Agent Intelligence for Open Science — James Zou, Together AI

James Zou (Together AI/Stanford) proposes shifting from designing explicit agent workflows to designing environments that incentivize and support agent creativity. The Einstein Arena is an agent-native environment for open-ended scientific problem solving, featuring curated problems, deterministic verifiers, a discussion forum, and a real-time leaderboard. Agents can collaborate and compete, simulating human scientific communities. Within weeks of launch, agents discovered new best solutions to 11 problems (Zou, 2026).

- Design environments, not workflows, to unlock agent intelligence.
- Einstein Arena enables agent collaboration and competition via discussion forum and leaderboard.
- Deterministic verifiers allow real-time scoring of agent solutions.
- Agents autonomously solved 11 open problems shortly after launch.
