# Stop being skeptical about AI for development with Charity Majors

Charity Majors, CTO of Honeycomb, argues that 2025 was a turning point for AI in software engineering, comparable to the impact of cloud computing in 2010. Initially skeptical, she shifted after seeing the capabilities of Opus 4.5 and the Claude Code harness in November 2025. Majors emphasizes that rational skepticism was justified given past overhyped technologies, but now AI is fundamentally changing how software is built and shipped.

- AI's impact in 2025 is comparable to cloud in 2010, making it a generational shift
- Code will transition from 'pets' to 'cattle': engineers will generate new code instead of fixing existing code
- Code review is overrated; the real bottleneck is validation and observability
- DevOps failed to connect engineers with production, but AI demands more engineering discipline
- Engineers must gain AI experience or return to work with more agency, as AI will be a filter in future hiring
