# Implementing Hybrid Semantic + Lexical Search

The article details the author's journey to improve search functionality on kentcdodds.com. The author found that semantic search alone was insufficient for delivering relevant results. Through three distinct rounds of iteration, using Cursor and GPT-5.4, each round revealed limitations in the previous design, ultimately leading to a hybrid approach that combines semantic and lexical search methods. The process underscores the value of iterative refinement and the practical benefits of blending different search paradigms.

- Semantic search alone was not adequate for the site's search needs.
- Three rounds of iteration were required to improve the search system.
- The development process utilized Cursor and GPT-5.4 as key tools.
- Each iteration uncovered missing aspects that the previous design overlooked.
- The final solution is a hybrid semantic + lexical search approach.
