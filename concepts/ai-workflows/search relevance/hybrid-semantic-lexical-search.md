# Implementing Hybrid Semantic + Lexical Search

The author argues that semantic search alone was insufficient for search on kentcdodds.com. To address this, they implemented a hybrid approach combining semantic and lexical search. The development process involved three rounds of iteration using AI-assisted tools like Cursor and GPT-5.4, where each round revealed limitations overlooked by the previous design. The final solution integrates both retrieval methods to improve search quality.

- Semantic search by itself did not meet the required search quality.
- A hybrid semantic + lexical search approach was implemented to combine strengths.
- Iterative development with Cursor and GPT-5.4 uncovered design gaps across three rounds.
- Each iteration addressed a specific limitation missed in prior versions.
