# CORS Chat: A Browser-Based Tool for Testing OpenAI-Compatible Chat Endpoints

Simon Willison built CORS Chat to test Qwen 3.8 27B running in LM Studio on his M5 MacBook Pro and an NVIDIA DGX Spark. The tool is a web UI that exercises any OpenAI-Responses-compatible chat endpoint, and he verified it works with LM Studio using the `--cors` option and with OpenRouter.

- CORS Chat is a browser-based web UI for testing OpenAI-Responses-compatible chat endpoints.
- It works with local LM Studio instances (using `--cors`) and hosted OpenRouter endpoints.
- Conversations are persisted in the browser and can be exported as copy-pasted JSON.
- The tool progressively renders SVG images generated by the model while tokens are still streaming.
