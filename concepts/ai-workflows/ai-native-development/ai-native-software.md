# The New Primitives: Building AI Native Software — Kwindla Kramer, Daily

Kwindla Kramer, from Daily, argues that current AI engineering is focused on building agents, which he compares to the early days of web pages. He draws on Vannevar Bush's 1945 essay 'As We May Think' to contextualize the present moment as the beginning of an 'intelligence age.' Kramer suggests that just as the web evolved from static pages to full web and native applications, the field will move beyond agents to fully AI-native software. He cites Satya Nadella's concept of multimodal harnesses with tool access and progressive disclosure, emphasizing the importance of context engineering and rich context in agent design.

- Agents are the current primitive, analogous to web pages in the early web era.
- The next phase will be AI-native software, evolving beyond agents and 'agents plus plus'.
- Vannevar Bush's 1945 essay predicted many technologies and frames the current transition as a new age.
- Modern agent design uses multimodal harnesses, tools, and context engineering to create loops across models, data, and tools.
