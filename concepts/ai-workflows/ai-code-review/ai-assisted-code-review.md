# Alibaba Open Sources OpenCodeReview for AI-Assisted Code Review

Alibaba has open-sourced OpenCodeReview, an AI-powered code review CLI [1]. The tool combines deterministic pipelines for file selection, bundling, and rule matching with an LLM agent for dynamic code analysis [1].

OpenCodeReview includes built-in checks for issues such as null-pointer exceptions, thread safety, XSS, and SQL injection [1].

- Alibaba open-sourced OpenCodeReview, an AI-powered code review CLI.
- The tool pairs deterministic pipelines (file selection, bundling, rule matching) with an LLM agent for dynamic code analysis.
- Built-in checks cover null-pointer exceptions, thread safety, XSS, and SQL injection.
