# TDD inside the agent loop - theater or actual value?

The article explores whether instructing LLM agents to use Test-Driven Development (TDD) genuinely improves software generation outcomes or merely gives an appearance of rigor. Thoughtworks colleague Birgitta Böckeler conducted a series of experiments to empirically test this question, as many practitioners enthusiastically advocate TDD for AI agents. The investigation aims to distinguish between performative adherence to TDD and real benefits such as better code quality, fewer defects, or more reliable iterative development. The results, detailed in the source, provide evidence-based insights into how AI coding agents behave when given TDD-style instructions, and whether the practice should be treated as a valuable tool or an empty ritual in agentic workflows.

- TDD instructions to LLM agents are widely recommended but lacking empirical validation.
- Birgitta Böckeler ran experiments to test if TDD actually changes agent output.
- The article questions whether TDD is theater or provides genuine value in the agent loop.
- Findings aim to guide practitioners on effective use of TDD with AI coding agents.
