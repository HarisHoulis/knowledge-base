# More than just code review

Simon Willison (2026) argues that the core skill for productive use of coding agents is not just writing prompts, but confidently instructing agents on desired changes and verifying those changes were applied correctly. While reviewing every line of code is one way to verify, it is not always the most effective method. The source contends that line-by-line eyeballing has never been the best way to validate a software change, implying that other verification strategies—such as running tests, examining diffs, or checking behavior—should be prioritized. The article frames effective verification as the central competency for working with AI coding tools, rather than exhaustive manual inspection. This suggests a shift from traditional code review towards a more outcome-focused validation approach, where the goal is confidence in the final result, not necessarily reading every character of the generated code.

- The key skill for using coding agents is confidently instructing changes and verifying they were applied correctly.
- Reviewing every line of code is only one possible verification method, not the definitive one.
- Eyeballing code line-by-line has never been the most effective way to validate a software change.
- Effective verification is more important than exhaustive manual review when working with coding agents.
