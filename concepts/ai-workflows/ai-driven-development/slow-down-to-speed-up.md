# Slow down to speed up: so much has changed in 6 months’ time

In his Craft Conference keynote, Gergely Orosz argues that software engineering has been fundamentally transformed by the latest generation of AI agents, which became truly useful around November 2025. He opens with Meta's 'most embarrassing outage,' where Meta AI allowed account takeovers by simply asking it to change an email. Orosz attributes this to AI-generated, AI-reviewed code combined with layoffs and gutted security and integrity teams, warning that over-prioritizing AI at the expense of core product reliability can lead to disaster (Orosz, 2026).

- Meta's outage highlights the risks of AI-generated code and weakened security review processes.
- Data from Linear and Cursor shows PRs up 5x, code volume up 2.5x, PR size up 3x, and more changes merged without human review.
- Anthropic and OpenAI are all-in on AI agents: Anthropic reports 70-90% of code generated by Claude, while OpenAI's Codex team uses AI review and parallel agents.
- Uber built custom AI infrastructure (MCP Gateway, Code Inbox, uReview) to integrate AI agents into developer workflows effectively.
- Trends include rising individual productivity but flat team productivity, falling code quality, vanishing middle management, and increasing AI slop.
