# Multi-Agent Patterns from Spotify's AI Powered Advertising Platform

Pratik Rasam presents how Spotify Ads Manager runs production-grade multi-agent systems at scale using Google ADK Java [1]. The talk focuses on the architectural patterns that make multi-agent systems viable in production, including domain ownership models and deterministic guardrails [1].

A central theme is the hard-learned lesson of drawing agent boundaries correctly, avoiding the monolithic agent pitfall by distributing responsibilities across well-scoped agents [1]. Rasam also covers optimizing tool schemas to improve agent reliability and efficiency [1].

Evaluation and observability are addressed through tracing-based evaluation strategies, alongside practical guidance on managing costs in multi-agent deployments [1].

- Spotify Ads Manager runs production-grade multi-agent systems at scale using Google ADK Java
- Domain ownership models and deterministic guardrails are key architectural patterns
- Drawing agent boundaries correctly avoids monolithic agent pitfalls
- Tool schema optimization and tracing-based evaluation improve reliability
- Cost management is a practical concern in multi-agent deployments
