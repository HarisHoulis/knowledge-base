# Now in Android #75

Now in Android #75 is a January 2023 roundup from Android Developers covering the latest Android Studio updates, AndroidX releases, and developer articles. The new Android Studio stable version includes improvements such as auto-updating Compose Previews, recomposition counts in the layout inspector, visual XML linting for Views, parallel project imports, SDK Index integration, a redesigned logcat, and resizable emulators. These features aim to improve developer productivity and streamline the build and debugging workflow.

Notable AndroidX updates include AppCompat 1.6.0 with Android 13 per-language preferences and predictive back, Room 2.5.0 now built on Kotlin with an Upsert annotation and room-paging support, and a new Lifecycle 2.6.0-alpha04 that stabilizes collectAsStateWithLifecycle and deprecates the pausing dispatcher. New libraries include androidx.credentials for sign-in with passwords and passkeys, and privacy sandbox libraries for ad services and SDK runtime.

The episode also highlights articles on adding a domain layer to the Now in Android app, extending the Android SDK for faster feature delivery, using the Wear media toolkit for Wear OS, migrating from TextureView to SurfaceView for HDR, and achieving low-latency stylus input. Videos cover app growth topics, CameraX concepts, and the Attribution Reporting API, alongside a backstage podcast episode about Kotlin Multiplatform and the K2 compiler.

- Android Studio stable brings Compose Preview auto-update, recomposition counts, visual XML linting, and resizable emulators.
- AppCompat 1.6.0 and Room 2.5.0 are stable; Lifecycle 2.6.0-alpha04 stabilizes collectAsStateWithLifecycle.
- New androidx.credentials library enables password and passkey sign-in, while new privacy sandbox libraries support ad services and SDK runtime.
- Articles cover adding a domain layer, extending the Android SDK, Wear media toolkit, HDR migration to SurfaceView, and low-latency stylus.
- Featured videos include app growth optimization, CameraX use cases, and the Attribution Reporting API.
