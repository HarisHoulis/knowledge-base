# Kotlin and http4k - List Stock in a Browser

This video is part of a series exploring an Extreme Programming implementation of the Gilded Rose stock control system. In this installment, the customer requests the ability to view the stock list in a browser for printing. The session demonstrates a dense coding exercise where the http4k web framework and Handlebars templating engine are introduced and combined to render an HTML page.

The implementation focuses on loading stock data from the filesystem and displaying it via a simple web server. The choice of http4k aligns with Kotlin's functional style, while Handlebars provides a straightforward way to generate HTML templates. The integration showcases a practical approach to adding a web interface to an existing application, emphasizing incremental development as part of the broader refactoring journey.

The series is based on the principles from the book 'Java to Kotlin, A Refactoring Guidebook', and this video serves as a hands-on example of applying Kotlin in a real-world scenario. Viewers are encouraged to follow the playlist to understand the full evolution of the system.

- http4k is introduced as a lightweight Kotlin web framework suitable for functional programming.
- Handlebars is used for server-side HTML templating to render stock data.
- The stock list is loaded from the filesystem and exposed through a browser endpoint.
- The session exemplifies iterative development within an Extreme Programming approach.
