# Now in Android #75

The article announces the latest Android developer news, starting with the stable release of Android Studio, which includes features like automatically updating Compose Previews, recomposition counts in the layout inspector, visual XML linting, improved sync performance with parallel project imports, SDK Index integration, a new logcat, resizable emulators, and physical device mirroring (Now in Android #75).

- Android Studio updates focus on Compose tooling, layout inspection, and developer productivity.
- AndroidX releases include stable AppCompat 1.6.0 and Room 2.5.0, plus lifecycle 2.6.0-alpha04 with collectAsStateWithLifecycle no longer experimental.
- New libraries: androidx.credentials for sign-in and privacy sandbox libraries (adservices, sdkruntime).
- Featured articles cover adding a domain layer to the Now in Android app, extending the Android SDK, Wear OS media toolkit, HDR migration to SurfaceView, and stylus low latency.
- Videos highlight app growth (paywalls, push notifications), CameraX, FLEDGE, and Attribution Reporting API.
