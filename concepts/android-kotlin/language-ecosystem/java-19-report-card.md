# Report card: Java 19 and the end of Kotlin

Virtual threads earn a B, having just made the cut in preview and still requiring stabilization. Wharton concludes that Kotlin remains alive and evolving, and he encourages updating to Java 19, arguing that the latest JDK is always the best long-term version. The overall tone is optimistic about Java's future, with bigger projects like Panama and Valhalla on the horizon.

- Local methods in Java failed to materialize, receiving an F.
- Text blocks are a success, earning an A.
- Pattern matching and record patterns are still in preview, graded C.
- Virtual threads are previewing with a B grade.
- Kotlin is not dead; both Java and Kotlin are thriving.
