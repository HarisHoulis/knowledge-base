# Report card: Java 19 and the end of Kotlin

The article is a retrospective on a talk given three years prior that predicted Java 19 would end Kotlin. In September 2022, Java 19 was released, and the author evaluates how each predicted feature fared. Local methods were not delivered, despite early work, while text blocks, records, and sealed classes were successfully integrated into the language. Pattern matching for instanceof arrived in Java 16, but switch pattern matching remains in preview. Virtual threads made the cut but are also in preview.

- Local methods were not delivered in Java, despite initial progress in Project Amber.
- Text blocks, records, and sealed classes were successfully delivered as predicted.
- Pattern matching for instanceof shipped in Java 16; switch pattern matching is in third preview in Java 19.
- Virtual threads are in preview in Java 19, requiring further stabilization.
- Kotlin did not end; it evolved with features like context receivers and sealed interfaces.
