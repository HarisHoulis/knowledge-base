# Report card: Java 19 and the end of Kotlin

Jake Wharton revisits his 2019 talk predicting Java 19's features, grading each forecast against the actual September 2022 release. The article evaluates six features: local methods, multiline strings, records, sealed types, pattern matching, and virtual threads. Each is assigned a grade from A to F based on whether it shipped as expected. The overall tone is lighthearted but informative, providing a retrospective on Java language evolution over three years.

- Local methods failed to materialize, receiving an F grade despite prototype work in Project Amber.
- Multiline strings, records, and sealed types were delivered as predicted, each earning an A.
- Pattern matching received a C, as it is still in preview and lacks planned features like wildcard underscores.
- Virtual threads received a B, having just entered preview with the release of Java 19.
- Kotlin did not end; it continues to evolve with features like context receivers and sealed interfaces, coexisting with Java.
