# Report card: Java 19 and the end of Kotlin

Jake Wharton revisits his 2019 talk forecasting Java 19 and grades each predicted feature as of the September 2022 release (https://jakewharton.com/report-card-java-19-and-the-end-of-kotlin/). He gives local methods an F for never becoming a JEP, text blocks an A for being delivered, records an A for being finalized, sealed types an A for being completed, pattern matching a C for being in preview and incomplete, and virtual threads a B for just making the cut but likely needing more previews (https://jakewharton.com/report-card-java-19-and-the-end-of-kotlin/).

Despite Java's progress, Kotlin did not end, as Wharton notes it continued evolving with features like context receivers and sealed interfaces (https://jakewharton.com/report-card-java-19-and-the-end-of-kotlin/). He concludes that there is no such thing as OpenJDK LTS and the best long-term JDK version is always the latest one (https://jakewharton.com/report-card-java-19-and-the-end-of-kotlin/).

- Local methods received a grade of F because the feature never advanced beyond a branch in Project Amber.
- Text blocks and records were fully delivered and graded A.
- Sealed types were also completed and graded A.
- Pattern matching is incomplete, receiving a C, and virtual threads are in preview with a B.
- Kotlin remains viable and continues to evolve, contrary to the talk's provocative title.
