# Report card: Java 19 and the end of Kotlin

Jake Wharton reviews his 2019 talk predicting Java 19 features, grading each prediction. Local methods failed to materialize, earning an F. Text blocks were fully delivered, receiving an A. Records and sealed types were also delivered as expected, though pattern matching for switch expressions is still in preview with limitations, earning a C. Virtual threads just made it into preview, earning a B.

- Local methods, a proposed feature to nest methods inside methods, were never completed and remain an unfinished branch in Project Amber.
- Text blocks were delivered in Java 15 and are a standard feature, making the prediction a success.
- Records and sealed types were both delivered as predicted, though pattern matching for switch expressions is still evolving in preview.
- Virtual threads are arriving in Java 19 as a preview feature, but more previews are expected before stabilization.
- Kotlin did not end; it continued to evolve, and Jake Wharton recommends updating to the latest JDK version rather than treating any version as a special LTS.
