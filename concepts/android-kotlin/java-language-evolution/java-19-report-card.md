# Report card: Java 19 and the end of Kotlin

Three years after predicting Java 19 would spell the end of Kotlin, Jake Wharton reviews how each forecasted feature actually landed. He grades local methods as an F, noting that while a branch exists in Project Amber, no JEP was created. Text blocks get an A, records and sealed interfaces also get an A as they were fully delivered. Pattern matching for instanceof and switch gets a C, because it is still in preview and lacks wildcard syntax. Virtual threads get a B, having barely made the cut but still requiring preview iterations.

- Local methods in Java 19 were not delivered, receiving an F grade.
- Text blocks, records, and sealed interfaces were fully delivered and received A grades.
- Pattern matching for switches is still previewing with limitations, earning a C.
- Virtual threads were introduced in preview in Java 19, earning a B.
- Kotlin did not end and continues to evolve alongside Java.
