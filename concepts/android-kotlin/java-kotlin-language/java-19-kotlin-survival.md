# Report card: Java 19 and the end of Kotlin

In the article 'Report card: Java 19 and the end of Kotlin' (Jake Wharton, 2022), the author evaluates predictions made three years earlier about Java 19. Each language feature receives a grade: local methods failed to materialize (F), while multiline strings, records, and sealed types were delivered successfully (A). Pattern matching earned a C due to its limited preview stage, and virtual threads received a B for appearing in preview but still requiring refinement.

- Local methods were not implemented in Java 19, earning an F.
- Multiline strings, records, and sealed types are fully delivered with A grades.
- Pattern matching and virtual threads are still in preview, with C and B grades respectively.
- Kotlin remained a viable language, adding features like context receivers and sealed interfaces.
- The author advises always using the latest JDK version, as there is no official OpenJDK LTS.
