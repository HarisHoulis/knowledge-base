# Report card: Java 19 and the end of Kotlin

In this article, Jake Wharton checks his three-year-old predictions for Java 19, which he made in a 2019 talk. He grades each feature: local methods (F) because no JEP was created despite a working branch, text blocks (A) delivered as preview, records (A) delivered, sealed interfaces (A) delivered, pattern matching (C) partial with instanceof in Java 16 and switch in preview, record patterns (C) just starting in preview, and virtual threads (B) in preview but needing more work. He emphasizes that Java 19 is the latest JDK and recommends updating to it, while noting that Kotlin did not end and continued to evolve with features like context receivers and sealed interfaces. Overall, the report card is passing, and both Java and Kotlin are thriving.

- Local methods were not delivered, earning an F despite a working branch in Project Amber.
- Text blocks, records, and sealed interfaces all shipped as predicted, earning A's.
- Pattern matching and record patterns are still incomplete, earning C's for their partial state.
- Virtual threads entered preview but need more iterations, earning a B.
- Kotlin remains alive and evolving; the author urges upgrading to the latest JDK (Java 19).
