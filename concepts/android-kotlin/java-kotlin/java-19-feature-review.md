# Report card: Java 19 and the end of Kotlin

Jake Wharton revisits his 2019 talk predicting Java 19 features, grading each against actual delivery. Local methods failed to land (grade F), text blocks and records shipped as previewed (A grades), and sealed types were fully delivered (A). Pattern matching and record patterns are still evolving in preview (C). Virtual threads arrived in preview (B), marking a significant step toward lightweight concurrency.

He concludes the overall report card is passing, though one elective failed. Kotlin did not end; it continued evolving with context receivers, sealed interfaces, and exhaustive-by-default. He also reiterates his stance that there is no OpenJDK LTS and developers should always update to the latest JDK, encouraging a move to Java 19.

- Local methods were not included in Java 19, failing his prediction.
- Text blocks, records, and sealed interfaces shipped successfully.
- Pattern matching and record patterns remain in preview with incomplete syntax.
- Virtual threads arrived in preview, promising improved concurrency.
- Kotlin continues to evolve independently, and the Java update to 19 is recommended.
