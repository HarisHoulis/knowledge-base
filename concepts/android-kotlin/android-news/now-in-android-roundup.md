# Now in Android #75

Now in Android #75, Manuel Vivo summarizes the latest Android development news for early 2023, starting with Android Studio updates including Compose Preview auto updates, layout inspector recomposition counts, visual XML linting, parallel project imports, SDK Index integration, a new logcat, resizable emulators, and device mirroring (Vivo, 2023). The post also highlights AndroidX releases such as AppCompat 1.6.0 with Android 13 support, Room 2.5.0 rewritten in Kotlin with Upsert support, Lifecycle 2.6.0-alpha04 stabilizing collectAsStateWithLifecycle, and new alpha libraries for credentials and privacy sandbox features.

The episode links to several articles and videos: a guide on adding a domain layer to the Now in Android app for improved scalability, an explanation of extending the Android SDK for faster feature rollout like the photo picker, a Wear OS media toolkit for bringing media apps to smartwatches, migration guidance from TextureView to SurfaceView for HDR playback, and libraries for low-latency stylus input. It also mentions videos on optimizing paywall conversions, push notifications, CameraX concepts, and Privacy Sandbox APIs like FLEDGE and Attribution Reporting, plus a podcast episode about Kotlin Multiplatform and the K2 frontend (Vivo, 2023).

- Android Studio stable release includes auto-updating Compose Previews, recomposition counts, visual XML linting, and resizable emulators.
- AndroidX updates include stable AppCompat 1.6.0, Room 2.5.0 (Kotlin runtime, Upsert), Lifecycle 2.6.0-alpha04, and new alpha libraries for credentials and privacy sandbox.
- Featured articles cover domain layer architecture, extending the Android SDK, Wear OS media toolkit, HDR via SurfaceView, and stylus low-latency libraries.
- New videos and podcasts discuss app growth, CameraX, Privacy Sandbox APIs, and Kotlin Multiplatform/K2.
