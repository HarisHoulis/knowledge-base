# Now in Android #75

The article is the inaugural Now in Android episode of 2023, summarizing the latest Android development updates. It highlights the stable release of Android Studio, which brings improvements such as auto-updating Compose Preview, recomposition counts in the layout inspector, visual XML linting for Views, parallel project imports, SDK Index integration, a new logcat, and resizable emulators, among other features (Manuel Vivo, Now in Android #75). Several AndroidX libraries also reached stable, including AppCompat 1.6.0 with Android 13 support like per-language preferences and predictive back, and Room 2.5.0, which was converted to Kotlin and introduced features like the Upsert annotation and paging support. The Lifecycle 2.6.0-alpha04 release removes the experimental annotation from collectAsStateWithLifecycle and deprecates older APIs (Manuel Vivo, Now in Android #75).

- Android Studio stable adds Compose Preview updates, recomposition counts, visual XML linting, new logcat, and resizable emulators.
- AppCompat 1.6.0 and Room 2.5.0 are now stable; Room 2.5.0 is Kotlin-first with Upsert and paging support.
- New AndroidX libraries include androidx.credentials for sign-in and privacy sandbox libraries (adservices, sdkruntime).
- Featured articles cover domain layer architecture, extending the Android SDK, Wear OS media toolkit, HDR migration to SurfaceView, and stylus low latency.
- Videos cover app growth, CameraX, FLEDGE, and Attribution Reporting API, plus a podcast on Kotlin Multiplatform and K2.
- The issue includes a podcast episode discussing Kotlin Multiplatform and the upcoming K2 frontend.
