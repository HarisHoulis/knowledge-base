# Now in Android #75

Now in Android #75, authored by Manuel Vivo, is the first episode of 2023, covering the latest Android development updates. It highlights the release of a new stable version of Android Studio, featuring improvements such as auto-updating Compose Preview, layout inspector with recomposition counts, visual XML linting for Views, parallel project imports for better sync performance, SDK Index integration, a new logcat, resizable emulators, and physical device mirroring (Now in Android #75). The episode also summarizes notable AndroidX releases, including AppCompat 1.6.0 with Android 13 support and per-language preferences, Room 2.5.0 with Kotlin runtime and Upsert annotation, and Lifecycle 2.6.0-alpha04 which stabilizes collectAsStateWithLifecycle and deprecates launchWhenX APIs.

- Android Studio stable release brings Compose Preview auto-update, recomposition counts, visual XML linting, SDK Index integration, and resizable emulators.
- AndroidX stable releases include AppCompat 1.6.0 and Room 2.5.0, with new alpha libraries for credentials and privacy sandbox.
- Articles cover adding a domain layer to the Now in Android app, extending the Android SDK, Wear OS media toolkit, HDR migration to SurfaceView, and stylus low latency.
- Videos highlight app growth strategies (paywalls, push notifications), CameraX concepts, FLEDGE, and the Attribution Reporting API, plus a podcast on Kotlin Multiplatform and K2.
