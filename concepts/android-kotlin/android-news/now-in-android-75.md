# Now in Android #75

Now in Android #75, authored by Manuel Vivo, is the first episode of 2023. It highlights the latest stable Android Studio release, which includes improvements such as auto-updating Compose Previews, recomposition counts in the layout inspector, visual XML linting, SDK Index integration, a new logcat, resizable emulators, and physical device mirroring (Source: Now in Android #75).

- Android Studio stable release includes Compose Preview auto-updating, recomposition counts, visual XML linting, SDK Index integration, and more.
- AppCompat 1.6.0 and Room 2.5.0 are now stable; Lifecycle 2.6.0-alpha04 deprecates launchWhenX.
- New androidx.credentials and privacy sandbox libraries (adservices, sdkruntime) were added.
- Featured articles cover domain layer architecture, extending the Android SDK, Wear OS media toolkit, HDR migration, and stylus low latency.
