# Now in Android #75

Now in Android #75 is the first episode of 2023, providing an overview of new Android development tools and libraries. The Android Studio stable release includes improvements such as automatic Compose Preview updates, recomposition counts in the layout inspector, visual XML linting for Views, parallel project imports for better sync performance, SDK Index integration, a new logcat, resizable emulators, and physical device mirroring. These features aim to enhance developer productivity and app debugging.

- Android Studio stable release includes auto-updating Compose Preview, recomposition counts, visual XML linting, parallel project imports, SDK Index integration, new logcat, resizable emulators, and physical device mirroring.
- AndroidX updates: AppCompat 1.6.0 (Android 13 per-language preferences, predictive back) and Room 2.5.0 (Kotlin runtime, Upsert, room-paging for RxJava/Guava) are stable; Lifecycle 2.6.0-alpha04 stabilizes collectAsStateWithLifecycle and deprecates pausing dispatcher/launchWhenX APIs.
- New AndroidX libraries introduced: androidx.credentials for passkeys/passwords, adservices for Privacy Preserving APIs, and sdkruntime for Runtime enabled SDKs.
- Featured articles cover adding a domain layer to the Now in Android app, extending the Android SDK with the Extension SDK framework, Wear OS media toolkit, migrating from TextureView to SurfaceView for HDR, and stylus low latency libraries.
- Videos and podcasts highlight app growth topics, CameraX concepts, FLEDGE API, Attribution Reporting API, and Kotlin Multiplatform in 2023.
