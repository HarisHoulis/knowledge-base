# Now in Android #65

The Android developer newsletter Now in Android #65 highlights the latest updates as of August 2022. Android 13 is approaching official release, with Beta 4 being the final testing build after reaching Platform Stability at Beta 3; all app-facing surfaces (SDK/NDK APIs, system behaviors, non-SDK restrictions) are final, and developers are encouraged to complete testing (Now in Android #65).

- Android 13 Beta 4 is the final test release before the official launch, with all APIs and behaviors finalized.
- Jetpack Compose 1.2 is now stable, adding features like downloadable fonts, lazy grids, and tablet/Chrome OS improvements.
- Compose for Wear OS 1.0 is stable and is the recommended approach for building Wear OS app UIs.
- Developers should prepare for predictive back gestures, available in Android 13 Beta 4 developer options.
- AndroidX releases include Core splashscreen 1.0, Profile Installer 1.2, and other updates.
