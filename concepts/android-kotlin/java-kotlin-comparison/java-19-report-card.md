# Report card: Java 19 and the end of Kotlin

Jake Wharton revisits his 2019 talk 'What's new in Java 19: The end of Kotlin?' and grades each prediction against the actual Java 19 release. He gives an 'F' to local methods, which never materialized as a JEP, and an 'A' to multiline strings, which were delivered as text blocks. Records and sealed types also received high marks for being fully delivered, while pattern matching and virtual threads received lower grades due to incomplete previews (C and B respectively).

- Local methods failed to progress in Project Amber and were not included in Java 19.
- Multiline strings (text blocks) were delivered successfully and received an A.
- Records and sealed interfaces were completed in earlier Java versions, but pattern matching remains in preview.
- Virtual threads (Project Loom) made it into Java 19 as a preview, earning a B.
- Kotlin did not end; it continued evolving, and the latest JDK remains the recommended long-term version.
