# Now in Android #75

This episode of Now in Android covers the latest Android development updates, including a new stable version of Android Studio with features like automatic Compose Preview updates, recomposition counts in the layout inspector, visual XML linting, SDK Index integration, a new logcat, and resizable emulators. The issue also highlights several AndroidX releases: AppCompat 1.6.0 adds Android 13 support such as per-language preferences and predictive back; Room 2.5.0 is now stable with a Kotlin runtime and new Upsert annotation; Lifecycle 2.6.0-alpha04 removes experimental status from collectAsStateWithLifecycle and deprecates launchWhenX APIs; and new libraries like androidx.credentials and privacy sandbox components (adservices, sdkruntime) are introduced.

Several articles and videos are featured: adding a domain layer to the Now in Android app for improved architecture, extending the Android SDK via the Extension SDK framework to enable backward-compatible features like the photo picker, easing media app development for Wear OS with the media toolkit, migrating from TextureView to SurfaceView for HDR playback, and implementing low-latency stylus input. Videos cover paywall conversion, push notifications, CameraX concepts, the FLEDGE API sample, and an introduction to the Attribution Reporting API. The episode also mentions a podcast episode discussing Kotlin Multiplatform and the upcoming K2 frontend.

- Android Studio stable includes Compose Preview auto-updates, recomposition counts, and a new logcat.
- Key AndroidX releases: AppCompat 1.6.0 (Android 13 per-language prefs, predictive back), Room 2.5.0 (Kotlin runtime, Upsert), Lifecycle 2.6.0-alpha04 (collectAsStateWithLifecycle stable).
- New androidx.credentials library for password/passkey sign-in, and privacy sandbox libs (adservices, sdkruntime).
- Articles cover domain layer architecture, extending Android SDK with Extension SDKs, Wear OS media toolkit, HDR SurfaceView migration, and low-latency stylus.
- Videos explain CameraX use cases, FLEDGE sample, attribution reporting, and app growth strategies.
