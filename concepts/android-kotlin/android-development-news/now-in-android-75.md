# Now in Android #75

Now in Android #75, the first episode of 2023, highlights the latest Android Studio stable release, which brings improvements to Compose Preview with automatic updates, layout inspector recomposition counts, visual XML linting for Views, parallel project imports for faster sync, SDK Index integration, a new logcat, resizable emulators, and physical device mirroring (Now in Android #75). The episode also covers notable AndroidX updates, including AppCompat 1.6.0 with Android 13 support like per-language preferences and predictive back, Room 2.5.0 which converts its runtime to Kotlin and adds Upsert and room-paging support for RxJava and Guava, and Lifecycle 2.6.0-alpha04 that stabilizes collectAsStateWithLifecycle and deprecates pausing dispatchers and launchWhenX APIs (Now in Android #75).

New libraries introduced include androidx.credentials for sign-in with stored credentials and passkeys, and privacy sandbox libraries adservices and sdkruntime for Privacy Preserving APIs and Runtime enabled SDKs (Now in Android #75). The episode also features articles on adding a domain layer to the Now in Android app for readability and scalability, extending the Android SDK with new extension SDKs like the photo picker, easing Wear OS media app development with the media toolkit, migrating from TextureView to SurfaceView for HDR playback, and achieving low-latency stylus input via new graphics and motion prediction libraries (Now in Android #75).

Video content covers optimizing paywall conversion, engaging with push notifications, CameraX concepts with four use cases, the FLEDGE API sample, and an introduction to the Attribution Reporting API. The Android Developers Backstage podcast episode 193 discusses Kotlin Multiplatform and the upcoming K2 frontend (Now in Android #75).

- Android Studio stable includes Compose Preview auto-updates, recomposition counts in layout inspector, and visual XML linting.
- AndroidX releases: AppCompat 1.6.0, Room 2.5.0 with Kotlin runtime and Upsert, Lifecycle 2.6.0-alpha04 stabilizing collectAsStateWithLifecycle.
- New androidx.credentials, adservices, and sdkruntime libraries were introduced.
- Articles cover domain layer architecture, SDK extension framework, Wear OS media toolkit, HDR migration to SurfaceView, and stylus low latency.
- Videos and podcast focus on app growth, CameraX, Privacy Sandbox, and Kotlin Multiplatform.
