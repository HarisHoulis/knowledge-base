# Square Open Source ♥s Kotlin

Square's open source team announced a multi-day blog series centered on Kotlin, reflecting the company's commitment to the language since its internal approval for Android applications in January 2015. The posts coincide with library releases designed to smooth rough edges when using Square's open source tools from Kotlin. The series covers topics such as nullable annotations, non-null defaults, Optional handling, JSON serialization, and code generation with KotlinPoet. This initiative aims to improve the developer experience for external users who have embraced Kotlin across various platforms.

- Square internally approved Kotlin for Android apps in January 2015 and is now expanding its use to plugins and eventually server-side code.
- A series of blog posts and matching library releases address Kotlin-specific friction in Square's open source libraries.
- Topics include @Nullable rollout, default non-null behavior, Optional's role, Kotlin JSON support, and KotlinPoet for code generation.
