# Kotlin TDD - More Degrading

This video is part 13 of a series exploring a Test Driven Development (TDD) implementation of the Gilded Rose stock control system in Kotlin. The focus is on adding more item update rules, starting with a very procedural algorithm and then refactoring it into a more functional style. The approach demonstrates how TDD can guide incremental changes to a legacy codebase, allowing developers to safely introduce new behavior while continuously improving design. The video also references the book 'Java to Kotlin: A Refactoring Guidebook', which is a resource for similar refactoring techniques. The series as a whole provides a practical, hands-on look at Kotlin development practices within a TDD workflow.

- Part 13 of a Kotlin TDD series implementing the Gilded Rose kata.
- Focuses on implementing additional item update rules.
- Starts with a procedural algorithm and refactors into a more functional approach.
- References the book 'Java to Kotlin, A Refactoring Guidebook' as a resource.
