# Kotlin TDD - To Production At Last

This video is part 11 of a series exploring Test Driven Development (TDD) of the Gilded Rose stock control system in Kotlin. The episode focuses on finally integrating the code from previous episodes into production, completing the process with an approval test to demonstrate that everything works together. The series highlights the practical application of TDD and approval testing in a Kotlin project, using the classic Gilded Rose kata as a working example. The author also references the book 'Java to Kotlin, A Refactoring Guidebook' as a related resource.

- Integrates TDD-developed Kotlin code into production.
- Uses an approval test to verify the system works.
- Part of a series on the Gilded Rose stock control system.
- References the book 'Java to Kotlin, A Refactoring Guidebook'.
