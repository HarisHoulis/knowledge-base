# Kotlin TDD - More Degrading

This video is part 13 of a series exploring how Test Driven Development (TDD) guides the implementation of the Gilded Rose stock control system in Kotlin. The focus is on implementing additional item update rules, starting with a very procedural algorithm and refactoring it into a more functional style. The approach demonstrates how TDD can drive incremental changes to a codebase while keeping behavior verified through tests. The video also references the book 'Java to Kotlin, A Refactoring Guidebook' as a related resource for learning how to refactor legacy code to Kotlin. The content is practical for Kotlin developers interested in TDD and functional programming techniques.

- TDD is used to incrementally implement item update rules in the Gilded Rose kata.
- The code begins as a procedural algorithm and is refactored into a functional form.
- The video is part of a larger playlist exploring Kotlin TDD and refactoring.
- The book 'Java to Kotlin, A Refactoring Guidebook' is recommended for further study.
