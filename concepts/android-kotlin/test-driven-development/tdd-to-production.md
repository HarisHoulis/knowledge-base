# Kotlin TDD - To Production At Last

This video is the 11th part of a series exploring Test Driven Development (TDD) for a Gilded Rose stock control system in Kotlin. It marks the culmination of previous coding episodes, where the author finally integrates the developed code into production. The integration is validated using an approval test, ensuring that the system works as expected after the TDD process [source]. The series demonstrates a practical TDD workflow in Kotlin, and this episode specifically focuses on the final steps of bringing test-driven code to a production-ready state. The author also references the book 'Java to Kotlin, A Refactoring Guidebook' as a relevant resource for those interested in Kotlin development [source].
