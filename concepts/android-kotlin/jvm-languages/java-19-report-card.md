# Report card: Java 19 and the end of Kotlin

In this report card, Jake Wharton evaluates his three-year-old predictions about Java 19 features (Jake Wharton, 2022). He notes that local methods, proposed for Project Amber, were never turned into a JEP, earning an F. Text blocks were delivered successfully, earning an A. Pattern matching for switch is only in preview as of Java 19, earning a C, while virtual threads made it into Java 19 as a preview feature, earning a B. Overall, he considers the report card passing despite one failing elective. He also observes that Kotlin did not end, continuing to evolve with features like context receivers and sealed interfaces, and he argues that there is no OpenJDK LTS and the best long-term JDK version is always the latest one.

- Local methods failed to materialize in Java 19 despite early work in Project Amber.
- Text blocks, records, and sealed types were delivered successfully.
- Pattern matching for switch is still in preview in Java 19.
- Virtual threads arrived in Java 19 as a preview feature.
- Kotlin continues to evolve and is not dead.
