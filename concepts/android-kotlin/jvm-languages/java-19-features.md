# Report card: Java 19 and the end of Kotlin

Jake Wharton reviews his 2019 predictions for Java 19, grading each feature's delivery. Local methods failed to materialize, receiving an F, while multiline strings, records, and sealed types shipped successfully and earned A's. Pattern matching in switch is still in preview, graded C, and virtual threads just made the cut in preview, graded B. The article concludes that Java 19 is a strong release, Kotlin hasn't ended, and encourages developers to adopt the latest JDK.

- Local methods were not shipped in Java 19, remaining an abandoned branch in Project Amber.
- Multiline strings (text blocks), records, and sealed types were delivered as final features.
- Pattern matching for instanceof is final, but switch pattern matching is still in preview.
- Virtual threads are in preview and expected to stabilize in future releases.
- Kotlin remains a viable language, and developers should update to Java 19.
