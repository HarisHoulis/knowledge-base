# The Augmented Forest: Setting Boundaries for AI Coding Tools

Kent Beck reflects on the shifting mood around AI coding tools across his three consecutive GOTO Copenhagen talks: from fear two years ago, to panic and despair last year, to a more irritated but action-oriented stance this year. He frames anger as a signal to set boundaries, which is the theme of the talk (GOTO Conferences, 2026).

Beck introduces the idea of "tool seeds": rather than shipping a finished software tool, you hand over the dialogue/prompt that produced the tool, so it adapts to whoever uses it. He demonstrates this with a call-graph visualizer built as a D3 force-layout diagram, shared as a seed via a GitHub repository only 24 hours old (GOTO Conferences, 2026).

He contrasts two centers of gravity for software development—forest versus desert—and argues that today's tools and their surrounding culture ignore how tool structure has consequences. He criticizes Marc Andreessen's vision of programmers working all day and waking at night to make requests as both a dystopia and something familiar, linking it to the "996" work culture (GOTO Conferences, 2026).

Beck expects the tools to change rapidly—within three, six, or twelve months—and sees that as a good thing, since the current tooling culture needs to be reshaped.

- Anger about AI tools is a signal to set boundaries, not despair
- "Tool seeds" share the prompt/dialogue that created a tool instead of a packaged product, letting it adapt to each user
- Current AI tool structures and culture have consequences that are being ignored
- Andreessen's always-on programmer ideal is a dystopia reminiscent of 996 work culture
- Rapid tool churn is expected and welcome because today's tooling culture needs change
