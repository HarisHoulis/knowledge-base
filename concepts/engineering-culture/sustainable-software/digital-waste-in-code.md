# Spotting Digital Waste in Code Gives You Energy

Wilco Burggraaf's GOTO Copenhagen 2026 talk demonstrates dynamic detection of "digital waste" in unfamiliar code, showing that hidden energy inefficiencies only emerge at runtime rather than from static inspection (https://www.youtube.com/watch?v=nXhiYhxJelY). The demo centers on a few lines of PyTorch code, with a GenAI-based simulation (CodeWeave) used to analyze code not known in advance and reveal how inefficient patterns drive up energy consumption.

- Digital waste in code is best revealed dynamically at runtime, not from static code alone
- A GenAI-based simulation (CodeWeave) is used to analyze unfamiliar PyTorch code and expose inefficient patterns
- The talk connects spotted digital waste to CO2 impact and sustainability
