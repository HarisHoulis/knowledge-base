# Do Software Fundamentals Still Matter?

In this short video, Matt Pocock addresses whether software fundamentals remain relevant in the age of AI. He argues that code quality, software entropy, and good design patterns are more important than ever, specifically for AI agents working in codebases. The video emphasizes that well-structured codebases make it easier for AI tools to assist developers effectively. Pocock highlights the need to proactively manage software entropy—the natural degradation of code quality over time—so that codebases remain maintainable and AI-friendly. By applying sound design patterns and maintaining clean architecture, developers can create environments where AI agents can navigate, understand, and modify code with greater accuracy. The key takeaway is that AI does not replace the need for engineering discipline; instead, it amplifies the value of fundamentals, as AI agents thrive in codebases that are well-organized and thoughtfully designed. Building codebases that AI 'loves to work in' leads to better AI-generated suggestions and fewer errors, ultimately improving developer productivity and code maintainability (Matt Pocock, 2026).

- Code quality, software entropy, and design patterns are more important than ever for AI agents.
- AI agents perform better in codebases that are well-structured and follow good design principles.
- Managing software entropy is crucial to keep codebases maintainable and AI-friendly.
- Developers should build codebases that AI 'loves to work in' to get better results from AI assistance.
