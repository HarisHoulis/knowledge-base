# Citizens Build, Agents Execute, Experts Govern

The article argues that AI has widened the gap between building software and engineering software. While non-engineers can now create working applications over a weekend, enterprise-grade software requires far more than functioning features. The author notes that the real differentiator is not coding ability but engineering judgment—knowing whether software can be trusted in production, handling risk, and designing for security, resilience, operability, and compliance (Laycock, https://martinfowler.com/rachels-ramblings/citizens-agents-experts.html).

- AI dramatically increases who can build software, but building an app is not the same as engineering software for production.
- Enterprise concerns—data protection, failure handling, auditability, scalability, operability—are invisible in demos and weekend builds.
- Experienced engineers become more important, not less, because they provide judgment, design, and governance.
- The emerging model is: citizens build, agents execute, experts govern.
- Good design and governance matter more when agents can generate code quickly.
