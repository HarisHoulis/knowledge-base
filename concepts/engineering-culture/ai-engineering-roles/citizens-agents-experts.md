# Citizens Build, Agents Execute, Experts Govern

Rachel Laycock observes a growing gap between non-technical people who build software over the weekend with AI and engineers who understand what it takes to run software in a production enterprise. She argues that the ease of building software does not equate to software engineering, because enterprise software requires considerations like security, resilience, operability, compliance, and long-term maintainability that don't appear in demos or personal projects. This gap leads executives and engineers to describe different futures: executives see that anyone can build software, while engineers see that someone must live with the consequences in production (Laycock, https://martinfowler.com/rachels-ramblings/citizens-agents-experts.html).

Laycock introduces the phrase "Citizens build. Agents execute. Experts govern." as a way to articulate where value moves in AI-augmented software development. Citizens—non-engineers—gain new ability to express ideas as software; agents handle code generation, refactoring, testing, and bug-fixing at high speed; but experts become more leveraged, not less, by designing guardrails, platforms, engineering practices, and feedback loops that allow creativity to scale safely. At the FOSE conference, discussions focused not on coding but on design, architecture, governance, learning, and judgment—humans deciding what good looks like and reviewing agent output. The article concludes that when agents can generate code quickly, good design and engineering judgment matter more, because organizations run on trust, not just code (Laycock, https://martinfowler.com/rachels-ramblings/citizens-agents-experts.html).

- AI dramatically increases who can build software, but building software is not the same as software engineering in production.
- Enterprise software requires judgment about security, resilience, operability, compliance, and long-term maintainability that is absent from weekend builds.
- Experienced engineers become more leveraged by designing guardrails and practices that allow citizens and agents to contribute safely.
- The future is not everyone becoming a software engineer; it is citizens building, agents executing, and experts governing.
