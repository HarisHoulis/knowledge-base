# Citizens Build, Agents Execute, Experts Govern

Rachel Laycock explores a growing divide between what non-technical people think software engineering is and what it actually entails. She observes that AI now allows anyone to build a working app over the weekend, leading executives to question why engineering teams aren't delivering ten times faster. However, building software is not the same as software engineering: production systems require security, resilience, operability, compliance, and long-term maintainability—concerns that don't appear in a demo but become critical when the business depends on the software. Laycock argues that experienced engineers become more important, not less, because they provide the judgment needed to decide whether software can be trusted in production (Laycock, n.d.).

At the FOSE conference, the focus was not on coding but on design, architecture, governance, learning, and judgment. One team designed a specification, let agents work overnight, and reviewed the results the next morning. The humans' role was to decide what good looked like, make trade-offs, and judge whether the output was what they wanted. Laycock emphasizes that good design matters more when agents generate code quickly. She suggests that the real scarcity is not the ability to write code but engineering judgment—knowing what good looks like, understanding risks, and ensuring something that works is actually safe to ship. Organizations don't run on code; they run on trust (Laycock, n.d.).

Laycock introduces the phrase "Citizens build, Agents execute, Experts govern" to describe where value is moving. Citizens (non-engineers) can express ideas as software, agents execute by writing and refactoring code, and experts govern by designing guardrails, platforms, engineering practices, and feedback loops. This does not mean everyone becomes an engineer or engineers disappear. Instead, experienced engineers become more leveraged, creating the environment in which thousands of features can be built safely by people and agents. The future software organization is one where almost anyone can create, agents execute, and engineering expertise enables that creativity to scale without chaos (Laycock, n.d.).

- AI dramatically increases who can build software, but building an app is not the same as engineering enterprise-grade software.
- Production software demands security, resilience, operability, compliance, and maintainability—questions that require experienced engineers to answer.
- The real scarcity is engineering judgment, not coding ability, especially when agents generate code rapidly.
- The phrase 'citizens build, agents execute, experts govern' captures the shift: citizens express ideas, agents execute, and experts ensure trust and safety in production.
- Experienced engineers become more leveraged by creating platforms, guardrails, and feedback loops that allow safe, scalable creation.
