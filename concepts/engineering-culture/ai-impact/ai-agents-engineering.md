# Slow down to speed up: so much has changed in 6 months’ time

In this article, Gergely Orosz summarizes his Craft Conference keynote on how AI agents have transformed software engineering in just six months. He uses Meta's severe outage as a cautionary tale: AI-generated code reviewed only by AI, combined with gutted security and integrity teams, led to a serious account takeover vulnerability. This highlights the dangers of prioritizing AI initiatives over the stability of core products and the importance of maintaining human oversight in critical systems.

Data from Linear and Cursor show a dramatic surge in developer productivity: teams ship 5x more pull requests, individual coders produce 2.5x more code, and pull request sizes have tripled. However, this comes with a downsides—more changes are merged without human review, and code reviews are getting harder to keep up with. Companies like Anthropic and OpenAI have fully embraced AI agents, with high percentages of code AI-generated and multiple agents running in parallel, while Uber and others have built custom internal tools to integrate AI into their workflows.

Key trends include rising individual productivity but flat team output, the vanishing of middle management, and a decline in software quality due to overwhelmed reviews. Orosz advises engineers to develop 'taste' and learn to effectively guide and review AI-generated code, while leaders must ensure proper safeguards for reliability and security.

- AI agents became genuinely useful after November 2025, causing a rapid transformation in software engineering practices.
- Meta's severe outage was caused by AI-generated code with AI-only review and weakened security teams, illustrating the risks of over-prioritizing AI.
- Companies like Anthropic and OpenAI now generate 70-100% of code via AI, with multiple parallel agents and minimal human review for many changes.
- Code review is becoming a bottleneck; more changes ship without human review, raising software quality concerns.
- Engineers should focus on developing 'taste,' learning to guide/review AI agents, and keeping human oversight for critical changes.
