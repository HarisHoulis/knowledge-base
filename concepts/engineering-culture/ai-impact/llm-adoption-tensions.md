# Fragments: June 16

Martin Fowler's June 16 fragments collect reflections on how LLMs are reshaping programming and the broader industry. Dave Thomas finds LLMs restoring the joy of programming by removing drudgery and speeding feedback loops, echoing Kent Beck's view that LLM-assisted development is more fun. Fowler also highlights Chelsea Troy's framework of conversational 'registers' when working with LLMs, emphasizing the need to consciously match the register to the task and start fresh conversations when switching modes to keep the context window healthy.

- LLMs are making programming more enjoyable by eliminating drudgery and accelerating feedback, says Dave Thomas.
- Chelsea Troy's four conversational registers with LLMs help manage context windows effectively.
- Charity Majors warns of a growing divide between AI enthusiasts and skeptics, calling for shared engineering discipline and honest reporting of costs.
- Simon Willison attributes recent enterprise AI price hikes to product-market fit for coding agents like Claude Code and Codex.
- Mike Masnick argues decentralization and user control over data are essential to avoid enshittification and digital despotism.
