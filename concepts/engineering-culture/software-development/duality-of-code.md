# What is Code

Martin Fowler's article examines the evolving nature of source code as humans increasingly delegate coding to agents, asking whether source code will remain necessary in the future. To answer this, Unmesh Joshi presents a framework that sees code as having two distinct but intertwined purposes: it is both a set of instructions to a machine and a conceptual model of the problem domain. This duality is central to understanding how code functions and why it matters (Martin Fowler, "What is Code").

- Code serves two intertwined purposes: machine instructions and a conceptual model of the problem domain.
- Building a shared vocabulary is vital for talking to machines and expressing domain concepts.
- Programming languages act as thinking tools, shaping how developers reason about problems.
- The rise of LLMs challenges but does not eliminate the need to understand code's dual nature.
