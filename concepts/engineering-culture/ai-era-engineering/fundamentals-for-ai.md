# Do software fundamentals still matter?

In this short video, Matt Pocock argues that software fundamentals are more important than ever in the age of AI (Pocock, 2026). He emphasizes that code quality, software entropy, and good design patterns are essential for AI agents to work effectively. Pocock suggests that engineers should focus on building codebases that AI 'loves' to work in, implying that clear structure and maintainability are key enablers for AI-assisted development. The video positions fundamental practices as a critical foundation rather than an obsolete skill set.

- Software fundamentals remain crucial when working with AI agents.
- Code quality and good design patterns help AI agents understand and modify code.
- Managing software entropy is key to keeping codebases AI-friendly.
- Engineers should build codebases structured for easy AI collaboration.
