# Tools Aren't Here to Make Us Feel Good

Kent Beck argues that augmented coding tools are making developers feel bad, and that they should be reoriented around human needs rather than technical capabilities. He notes this mirrors an earlier argument made in favor of Extreme Programming (XP).

Beck anticipates the objection that tools aren't meant to make us feel good, and concedes the point—acknowledging that work is called "work" for a reason—while still framing the talk around how tooling affects developers emotionally and how design priorities should account for that.

- Augmented coding tools are currently making developers feel bad.
- Tools should be reoriented around human needs instead of technical capabilities.
- The argument parallels the earlier case made for Extreme Programming (XP).
- Beck concedes tools aren't primarily meant to make us feel good, but still treats human impact as a design concern.
