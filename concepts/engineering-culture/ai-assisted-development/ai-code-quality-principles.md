# Plus c'est la même chose: Holding AI Coding Assistants to Human Standards

Dave Thomas argues against the common claim that code quality no longer matters because 'the only thing that'll read this code is another AI.' He contends that nearly every good practice developed over the last 50 years still applies when machines write code, and that many of these principles become more important because AIs repeat the same mistakes humans make—just faster.

His talk walks through a progression of steps: first, the 'coward's way out'—recognizing that AI needs the same rules we do; then his 'superpower'; then the principles themselves; then a defense of AI, noting that AIs lack judgement; and finally a look forward at what to do next. The framing positions the audience to hold their AI coding buddy to a higher standard rather than abandoning established engineering discipline.

The core message is continuity rather than revolution: the title 'Plus c'est la même chose' (the more things change, the more they stay the same) captures the idea that AI-assisted development does not invalidate decades of accumulated software craft.

- Code quality remains relevant even if only AI consumes the code
- AIs make the same mistakes humans do, only faster, so good practices matter more
- Established engineering principles should be applied to AI-generated code
- AIs lack judgement, which is a key reason human standards must be enforced
