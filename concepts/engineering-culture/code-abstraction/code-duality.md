# What is Code

The article explores the nature of code, arguing that it serves two intertwined purposes: instructions to a machine and a conceptual model of the problem domain. It emphasizes that programming languages are not just communication tools but also thinking tools that shape how we reason about software. As humans increasingly delegate code writing to LLMs, the article questions whether traditional source code will remain central, and stresses the importance of building vocabularies to talk to machines (source: 'What is Code', Martin Fowler).

- Code has two distinct but intertwined purposes: instructions to a machine and a conceptual model of the problem domain.
- Programming languages are thinking tools, not merely a means to instruct machines.
- Building a rich vocabulary is vital for effectively talking to machines.
- The rise of LLMs may change the role of source code, but understanding its dual nature remains crucial.
