# Do software fundamentals still matter?

In the age of AI, software fundamentals such as code quality, software entropy, and good design patterns are more important than ever. Rather than being rendered obsolete by AI agents, these fundamentals become critical enablers: AI agents work best in codebases that are clean, well-structured, and follow established patterns. Poor code quality and high entropy make it harder for AI to reason about and modify code, increasing the risk of errors and reducing productivity. Matt Pocock argues that developers should invest in these fundamentals to create codebases that AI loves to work in, ensuring that AI tools enhance rather than hinder development. The message emphasizes that leveraging AI effectively requires a strong foundation in software engineering principles.

- Software fundamentals remain essential even with AI agents.
- Code quality and low software entropy are key for AI-friendly codebases.
- Good design patterns help AI understand and modify code correctly.
- Building codebases that AI loves to work in is a competitive advantage.
- AI tools amplify the importance of clean, maintainable code.
