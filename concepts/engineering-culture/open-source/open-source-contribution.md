# Introducing: How to Contribute to Open Source

The post announces a free egghead.io series, "How to Contribute to an Open Source Project on GitHub," aimed at lowering the barrier to entry for new open source contributors. It covers everything from setting up a GitHub account to doing an interactive git rebase, and points readers to makeapullrequest.com and kcd.im/pull-request as the tl;dr resources ([source](https://kentcdodds.com/blog/introducing-how-to-contribute-to-open-source)).

For project maintainers, the post suggests replacing vague invitations with a direct pointer to makeapullrequest.com. It provides a "PRs Welcome" badge for README files and text for CONTRIBUTING.md that links beginners to the free series ([source](https://kentcdodds.com/blog/introducing-how-to-contribute-to-open-source)).

For non-maintainers, the post encourages submitting pull requests to favorite projects to add those same badge and CONTRIBUTING.md resources. The stated goal is to spread the joy of open source to more people through education ([source](https://kentcdodds.com/blog/introducing-how-to-contribute-to-open-source)).

- A free egghead.io series teaches contributing to open source on GitHub, from creating a GitHub account to interactive git rebase.
- makeapullrequest.com and kcd.im/pull-request are offered as quick entry points for new contributors.
- Maintainers can add a "PRs Welcome" badge to the README and guidance to CONTRIBUTING.md to direct beginners to the series.
- Non-maintainers can submit PRs to their favorite projects to add those resources.
- The article frames education as the way to lower barriers and spread open source participation.
