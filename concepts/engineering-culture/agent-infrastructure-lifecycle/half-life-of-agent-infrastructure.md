# The Half Life of Agent Infrastructure — Ben Kus, Box

Ben Kus opens by retracting his previous year's graph-based agent recommendation, noting that while it was valid then, a better approach has since arrived. He reviews models, agent design, and retrieval, showing how each evolved dramatically within twelve months (The Half Life of Agent Infrastructure, 2026). Traditional infrastructure has a 3–5 year half-life, supporting the usual 'pick a stack, go deep, switch rarely' advice, but agent infrastructure has a half-life measured in months, breaking that advice. Kus illustrates the human cost by recounting asking an engineer to rebuild working agentic search in a new style, then proposing another rebuild the day after shipping. His answer is preparation rather than technology: make change normal, build swap-able abstractions, and switch only when eval sets justify it, not when a paper is exciting. Box reviews every AI technology on a six-month clock and evaluates vendors by how they handle change.

- Agent infrastructure has a half-life measured in months, unlike traditional infrastructure's 3–5 year half-life.
- Kus retracts his prior graph-based agent recommendation because a better approach appeared within a year.
- Teams should treat change as normal, not failure, and build abstractions that allow underlying layers to be swapped.
- Switch technologies only when eval sets show an improvement, not based on hype or exciting papers.
- Box reviews AI technologies on a six-month clock and judges vendors by how they handle change.
