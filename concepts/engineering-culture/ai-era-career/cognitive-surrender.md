# From Chrome DevTools to AI Engineering, with Addy Osmani

Addy Osmani, a 14-year Google veteran who worked on Chrome, DevTools, and Core Web Vitals, discusses his path from building a web browser at age 16 to becoming a Director of Engineering. He shares how publishing free educational materials about frontend development led to a DevRel-and-builder role at Google, and how Chrome DevTools evolved from simple debugging tools into an IDE-like environment as web frameworks and build chains grew more complex (Orosz, 2026).

- Addy Osmani built a web browser from scratch at 16 to speed up browsing, and later joined Google after creating widely used frontend educational resources.
- Chrome DevTools grew from basic debugging into a near-IDE as developers adopted complex frameworks, adding source-map-aware debugging, mobile emulation, and service worker tooling.
- AI-assisted development risks 'cognitive surrender'—the erosion of understanding—which can be countered by reviewing every major LLM decision and using 'loop engineering' for mutual amplification.
- Software engineers remain essential because an AI model cannot be accountable; adopting a 'what am I accountable for?' mindset will be key.
- Engineers should invest in product sense, go-to-market, and other non-engineering skills as roles become fuzzier—'Don't be just an engineer.'
