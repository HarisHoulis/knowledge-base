# From Chrome DevTools to AI Engineering, with Addy Osmani

In this interview, Addy Osmani recounts his path from building a web browser at age 16 to becoming a Director of Engineering at Google, working on Chrome DevTools and Core Web Vitals. He explains how DevTools evolved from simple debugging tools to a near-IDE, and notes that memory debugging remains underdeveloped despite improvements like flame graphs and deep tracing (source).

- Addy Osmani built a web browser at 16 and later joined Google after publishing free educational frontend resources.
- Chrome DevTools grew from basic debugging into a comprehensive toolset, but memory management debugging has not advanced significantly in a decade.
- AI-assisted development risks 'cognitive surrender'—eroding engineers' comprehension—so engineers should understand every major LLM decision and aim for 'mutual amplification'.
- Software engineers remain essential because AI cannot be accountable; designated humans own and approve code.
- Engineering roles are unbundling, so engineers should develop product sense, go-to-market skills, and other non-engineering abilities—'don't be just an engineer.'
