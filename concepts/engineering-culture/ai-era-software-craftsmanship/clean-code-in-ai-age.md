# LIVE: Uncle Bob on Software Fundamentals in the Age of AI

In this live interview, Uncle Bob Martin reflects on his long career, starting with his first program in 1964 on a toy computer. He emphasizes the importance of learning programming fundamentals, recalling that he wrote programs on paper and executed them in his head before having access to machines. He describes his journey from a temporary job at 16 to a real programming job at 18, and how these early experiences shaped his philosophy of software craftsmanship.

Martin discusses his initial skepticism about AI, having tried ChatGPT and Grok without being impressed. However, he later used an early Grok agent to write code for a project, finding that it worked but made a mess that required constant cleanup. He likens the agent's output to leaving 'little dog doo behind,' reinforcing that while AI can be fast, it still produces messy code that needs disciplined cleanup. This leads to his central point: even in the age of AI, the fundamentals of clean code and careful craftsmanship remain essential.

- Uncle Bob started programming in 1964 and stresses the value of learning fundamentals hands-on.
- He was initially unimpressed with early AI tools but found that agents could write code.
- AI-generated code often requires significant cleanup and can leave behind messy artifacts.
- Clean code principles and disciplined craftsmanship remain critical when working with AI assistance.
