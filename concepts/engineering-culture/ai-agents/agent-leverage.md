# How to increase your leverage with agents

Kent C. Dodds argues that AI coding agents are not replacing developers but rather pushing them up the abstraction ladder, as has happened throughout programming history. He notes that what agents do today were tasks he performed himself months ago, and expects this trend to continue, freeing developers to focus on higher-leverage work (Dodds, 2026).

The key is to identify what you are doing now that can be automated by an agent. While taste, judgment, and system design/architecture review may remain human responsibilities, agents can handle more concrete tasks, enabling developers to tackle larger, more strategic problems. Dodds illustrates this with a personal example of using an agent to perform a health assessment on an architecture idea while at a theme park, then orchestrating subagents for each improvement (Dodds, 2026).

The broader implication is that durable skills—like understanding systems and making high-level decisions—become more important as agents handle lower-level implementation. Dodds encourages developers to continuously find the next layer of abstraction and push their agents to handle the current busy work, thereby increasing their own leverage (Dodds, 2026).

- Agents automate current tasks, shifting developers to higher-leverage work rather than replacing them.
- This is a continuation of the historical trend from assembly to high-level languages to natural language.
- Focus on what repetitive or concrete work you do today and delegate it to an agent.
- Human skills like taste, judgment, and architecture design remain valuable and are augmented by agents.
- Agents can orchestrate subagents, allowing parallel exploration of multiple ideas.
