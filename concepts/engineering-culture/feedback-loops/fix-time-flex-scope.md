# Thinkie: Fix Time, Flex Scope

Kent Beck describes a recurring anti-pattern: teams fall into a loop where longer and longer feedback loops seem to produce bigger results, so they keep stretching the cycle time. The proposed transformation is to invert the constraint—fix the time budget for the feedback loop and instead work on gradually fitting more scope into that fixed window.

Beck notes this pattern surfaced while he was re-conceiving augmented coding around human needs, observing that current practice is producing ever-longer feedback loops (citing Anthropic's research on measuring agent autonomy). The takeaway is to treat loop duration as the invariant and scope as the variable to grow.

- Watch for the trap of ever-longer feedback loops justified by bigger results
- Invert the constraint: hold loop time fixed and grow scope within it
- Beck applies this to augmented coding, where agent workflows are lengthening feedback cycles
