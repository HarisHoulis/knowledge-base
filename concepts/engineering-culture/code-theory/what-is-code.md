# What is Code

The article examines the fundamental nature of code, especially as AI agents increasingly write code. Unmesh Joshi argues that code serves two intertwined purposes: it is both a set of instructions to a machine and a conceptual model of the problem domain. These two aspects are inseparable—code must communicate with the computer while also expressing a human understanding of the domain.

Building a precise vocabulary is vital for talking to machines, and programming languages function as thinking tools that shape how we model problems. As LLMs become more involved in software development, understanding this dual nature becomes crucial for evaluating whether source code itself will remain necessary in the future.

- Code is both machine instructions and a conceptual model of the problem domain.
- A precise vocabulary is essential for communicating with machines.
- Programming languages act as thinking tools, not just execution syntax.
- The dual nature of code shapes how we approach LLM-driven development and the future of source code.
