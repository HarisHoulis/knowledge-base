# Anti-Patterns in Software Blogging

Simon Willison highlights Michael Lynch's piece on anti-patterns in software blogging, focusing on two that resonated with him. The first is overreliance on links as a substitute for explaining terminology; Willison admits he does this constantly and suspects almost nobody clicks the links. Lynch's rule of thumb, clarified in a Lobste.rs comment, is that an article should still make sense to a reader who clicks nothing.

The second point is about voice: beginner software bloggers often believe they must write in a stiff, overly formal style to be taken seriously, when they should simply write the way they talk. Willison calls this point crucial.

Willison adds his own observation that as more developers delegate writing to AI, software blogging is becoming bland and homogenous, and readers are hungry for writing with personality.

- Don't rely on links to explain terminology—articles should make sense without any clicks
- Write in your own voice rather than a stiff, overly formal style
- AI-generated writing is making software blogs bland and homogenous, so personality stands out
