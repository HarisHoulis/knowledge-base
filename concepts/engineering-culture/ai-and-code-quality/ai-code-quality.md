# Do software fundamentals still matter?

In the age of AI, software fundamentals such as code quality, design patterns, and managing software entropy remain critical, arguably more so than ever. As AI agents become increasingly involved in codebases, the quality of the code directly influences how effectively these agents can work. Poor structure and accumulated technical debt can hinder AI's ability to understand and modify code safely, while well-designed codebases enable AI to make reliable, targeted changes.

- Code quality and software entropy are more important than ever when AI agents are working in a codebase.
- Good design patterns help AI understand and navigate code, improving the quality of AI-generated changes.
- Maintaining low entropy in codebases reduces the risk of AI introducing bugs or conflicting with existing architecture.
- Software fundamentals like clear structure and modularity are key to building codebases that AI agents can work with effectively.
