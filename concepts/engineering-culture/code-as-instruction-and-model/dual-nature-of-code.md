# What is Code

In 'What is Code', Martin Fowler reflects on the evolving role of source code as humans increasingly delegate writing to agents. Unmesh Joshi's perspective, highlighted in the article, argues that code serves two intertwined purposes: it is both a set of instructions to a machine and a conceptual model of the problem domain. This duality is essential for understanding how programming languages function as thinking tools rather than mere syntax.

- Code has two intertwined purposes: instructions to a machine and a conceptual model of the problem domain.
- Programming languages are thinking tools that help build a vocabulary to communicate with machines.
- The dual nature of code affects how we work with LLMs and the future of source code.
- Understanding code's conceptual role is vital for effective software engineering.
