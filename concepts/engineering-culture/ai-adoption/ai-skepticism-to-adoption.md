# Stop being skeptical about AI for development with Charity Majors

In this Pragmatic Engineer episode, Gergely Orosz sits down with Charity Majors to discuss why AI skepticism was rational in 2025 but is increasingly untenable by 2026. Majors explains that her turning point came in November 2025 with Opus 4.5 and the Claude Code harness, which transformed coding assistants from shell scripts into serious infrastructure. She compares AI's impact on software engineering to how cloud computing reshaped infrastructure around 2010, arguing that AI has now clearly crossed a generational threshold (Orosz, 2026).

- AI's impact on software engineering in 2025-2026 is comparable to the cloud's impact in 2010; skepticism was justified earlier but now adoption is essential.
- Shipping code that no human has read will become a 'when' not 'if', shifting the bottleneck to verification systems like tests and conformance checks.
- Code review is overrated; humans add the most value in conversations and product decisions, not line-by-line correctness checking.
- DevOps failed to close the loop between developers and production, and AI-driven non-deterministic systems demand more engineering discipline, not less.
