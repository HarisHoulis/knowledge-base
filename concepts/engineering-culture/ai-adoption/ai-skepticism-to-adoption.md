# Stop being skeptical about AI for development with Charity Majors

The article summarizes a podcast episode in which Charity Majors, CTO of Honeycomb, argues that AI's impact on software engineering became undeniable in 2026. She notes that while skepticism was rational in 2025 because past technologies like COBOL and no-code overpromised, AI is now a generational shift comparable to cloud computing in 2010 (source: https://newsletter.pragmaticengineer.com/p/stop-being-skeptical-about-ai-for). Her personal turning point came in November 2025, when Opus 4.5 and coding harnesses like Claude Code transformed AI from a shell script into serious infrastructure (source: same URL).

- Skepticism about AI was rational until 2025; now AI is a generational shift similar to cloud in 2010.
- Coding harnesses like Claude Code matter as much as model quality; they raised AI from a script to serious infrastructure.
- Engineers will eventually ship code they never read; code may move from 'pets' to 'cattle', where broken code is regenerated instead of fixed.
- Non-deterministic AI-generated code demands more engineering discipline, especially in validation, testing, and observability.
- Career advice: get AI experience now; engineering leaders should run toward the wave and consider IC work to regain agency.
