# Stop being skeptical about AI for development with Charity Majors

In this episode of The Pragmatic Engineer, Gergely Orosz sits down with Charity Majors, CTO and cofounder of Honeycomb, to discuss how her perspective on AI has evolved. While skepticism was rational in 2025, Majors argues that by 2026 it's clear AI is fundamentally changing software engineering. She initially saw AI as having a bigger impact than a new programming language but was unsure it would be generational; her turning point came in November 2025 with Opus 4.5 and the maturation of coding harnesses like Claude Code, which transformed AI-assisted coding from shell scripts into serious infrastructure (source: "Stop being skeptical about AI for development with Charity Majors", https://newsletter.pragmaticengineer.com/p/stop-being-skeptical-about-ai-for).

- AI's impact on software engineering in 2025 is comparable to cloud computing's impact in 2010.
- Code review is overrated; the critical human value lies in problem-solving, not reading code.
- AI-generated code requires more engineering discipline, especially around validation and observability.
- The shift from editing code to generating code mirrors the 'pets to cattle' transition in infrastructure.
- Engineers should adopt AI now; lack of AI experience will become a filter in future job interviews.
