# Stop being skeptical about AI for development with Charity Majors

Charity Majors, CTO of Honeycomb, discusses her evolving perspective on AI in software engineering. Initially skeptical in early 2025, she encouraged engineers to try vibe coding to better understand the technology. Her turning point came in November 2025 with Opus 4.5 and, more importantly, Claude Code harness, which transformed coding harnesses from shell scripts into serious infrastructure. She now compares AI's impact to that of cloud computing in 2010, predicting a generational shift in how software is built (Gergely Orosz, 2026).

- Charity Majors evolved from AI skeptic to believer, crediting Claude Code's harness as a turning point.
- AI's impact on software development is comparable to cloud computing's effect on infrastructure in 2010.
- The 'pets to cattle' transition may apply to code: generate new code instead of fixing old code.
- Code review is overrated; engineering discipline should shift toward verification and observability.
- Engineers should embrace AI and gain experience, as future job interviews will filter for it.
