# Fragments: July 21

Martin Fowler's 'Fragments: July 21' summarizes key discussions from the second Future of Software Development Retreat, referencing the Thoughtworks report's five headline findings: verification is now the bottleneck (not code generation), 'harness engineering' is emerging as a discipline, there is an apprenticeship crisis, the executive/engineer expectation gap is a major risk, and legacy modernization is a near-term value pool (Fowler, Fragments: July 21). The article highlights the board-vs-engineer divide, where management focuses on productivity gains while engineers worry about risks like security. A cautionary tale illustrates this: ML-optimized air filter replacement saved $50 million but caused $100 billion in damages when models trained on desert equipment were used in the Arctic, where rotting mosquitoes create a fire hazard. Fowler stresses the need for sensors and rapid feedback to avoid such failures.

- Code generation is no longer the bottleneck; verification is, and 'harness engineering' is becoming a distinct discipline.
- Executive/engineer expectation gaps on AI are riskier than technical limitations; controls are needed for vibe coding and shadow IT.
- LLMs are useful for operations (anomaly detection, cross-referencing code and event traces) but overestimated for incident resolution, which requires human adaptability.
- Agent auto-remediation demands careful documentation and feedback loops, as agents don't learn—they only update context.
- LLM-generated prose is increasingly recognized and discrediting; Fowler advises writers to 'say your writing' to preserve a human voice.
