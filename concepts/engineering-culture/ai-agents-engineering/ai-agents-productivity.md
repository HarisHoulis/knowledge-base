# Slow down to speed up: so much has changed in 6 months’ time

In this article, Gergely Orosz summarizes his Craft Conference keynote on how AI agents have transformed software engineering in the past six months. He opens with Meta's most embarrassing outage, which was caused by AI-generated and AI-reviewed code combined with layoffs and reassignments of security and integrity teams. This serves as a warning about prioritizing AI initiatives over the health of core products. Orosz argues that the shift began in November 2025 with the release of more capable models like Opus 4.5 and GPT-5.4, making agents genuinely useful. Data from Linear and Cursor show that developers now ship 5x as many pull requests as two years ago, produce 2.5x more code, and that pull request sizes have tripled, while an increasing number of changes are merged without human review (Orosz, 2026).

Orosz details how leading tech companies are adapting: Anthropic is all-in on AI agents, with Claude generating 70-90% of internal code and ~100% of Claude Code; OpenAI's Codex team uses AI code review and lets developers run multiple agents in parallel; Google uses Gemini widely but lags in coding capability; Uber has built extensive internal AI infrastructure like Code Inbox and uReview; startups are integrating AI into Slack; and traditional companies like Cisco and JP Morgan are investing heavily. Despite these gains, Orosz notes that individual productivity is up but team productivity is flat, and that code quality is falling, with GitHub reliability issues and AI slop overwhelming quality-focused developers. He advises engineers to focus on 'taste' and adapting workflows, while leaders should be cautious about sacrificing reliability for AI speed (Orosz, 2026).

- Meta's outage shows the dangers of AI-generated, AI-reviewed code and gutting security teams in favor of AI initiatives.
- Since November 2025, AI agents have become genuinely useful, leading to 5x more PRs, 2.5x more code, and 3x larger PRs.
- Leading companies like Anthropic and OpenAI now let AI generate most code, but human review is becoming a bottleneck.
- Individual productivity has risen, but team productivity is flat and software quality is declining.
- Engineers should future-proof careers by developing 'taste', improving code review skills, and learning to work effectively with AI agents.
