# What is Code

The article, authored by Martin Fowler, explores the evolving nature of code, especially as AI agents increasingly write code. It emphasizes that code serves two distinct but intertwined purposes: it is both a set of instructions to a machine and a conceptual model of the problem domain. The author argues that building a shared vocabulary to communicate with machines is vital, and programming languages act as thinking tools that shape how we understand and solve problems. As we work with large language models (LLMs), this dual nature becomes critical: code is not just executable syntax but a representation of human intent and domain understanding. The article suggests that even with AI assistance, the need for clear conceptual models and precise instructions persists, influencing how we approach future software development.

- Code is simultaneously instructions to a machine and a conceptual model of the problem domain.
- Programming languages are thinking tools, not just syntax; they shape our understanding of problems.
- The rise of LLMs and AI agents changes who writes code, but the need for clear intent and domain modeling remains.
- A shared vocabulary between humans and machines is essential for effective code generation and maintenance.
