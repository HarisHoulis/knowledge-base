# Citizens Build, Agents Execute, Experts Govern

Rachel Laycock observes a growing gap between what executives and experienced software engineers think software engineering is, especially as AI enables non-engineers to build working applications over a weekend. While these 'citizen builders' are excited and productive, they are creating software without considering the requirements of production-grade enterprise systems: security, resilience, operability, compliance, and maintainability. Laycock argues that this does not diminish the value of experienced engineers; instead, it makes their judgment more critical, as they are the ones who know whether software can be trusted in production (Laycock, Rachel's Ramblings).

The article introduces a framework: 'Citizens build. Agents execute. Experts govern.' This is not about strict roles but about where value is moving. AI lets everyone express ideas as software, and agents write and iterate code rapidly, but experts are needed to govern what can exist in production, design guardrails, and create environments where creativity can scale safely. Laycock emphasizes that organizations don't run on code; they run on trust, and engineering expertise is the leveraged commodity that makes safe scaling possible (Laycock, Rachel's Ramblings).

- AI has dramatically increased who can build software, but building a weekend app is not the same as enterprise software engineering.
- Experienced engineers matter more, not less, because they bring judgment about production readiness, security, and long-term maintainability.
- The future of software work is 'Citizens build, Agents execute, Experts govern' — expertise provides the guardrails for scalable creativity.
- Software exists to run in production and solve problems safely; organizations run on trust, not just code.
