# AI-Generated Code Fails to Boost Productivity Due to Downstream Bottlenecks

A Harvard study of 718 firms, using the Jellyfish analytics platform, found that AI coding assistants and agents increase the volume of code produced but do not yield a corresponding increase in completed work (InfoQ, Sergio De Simone). The disconnect is attributed partly to downstream effects: AI-generated code raises the workload in later development stages, particularly code review.

The finding challenges the assumption that faster code generation translates directly into higher throughput, suggesting organizations should look beyond code-volume metrics when assessing AI tooling value.

- AI coding assistants and agents increase code volume but not proportionally completed work.
- AI-generated code increases downstream workload, especially in code review.
- Study covered 718 firms using the Jellyfish analytics platform.
- Code-generation speed is a poor proxy for end-to-end productivity.
