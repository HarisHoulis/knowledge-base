# Bliki: Paracelsus Maxim

Martin Fowler discusses the Paracelsus Maxim, originating from the 16th century Swiss physician Paracelsus, which states that 'the dosage alone makes it so a thing is not a poison.' He applies this to programming: few practices are purely good or bad; rather, their value depends on context and dosage. Fowler highlights global data as an example, noting that a little global data, especially when immutable, can help propagate information across a program, but becomes dangerous in large quantities. He encourages developers to ask 'in what contexts' and 'in what doses' when evaluating habits.

- The same practice can be beneficial or harmful depending on dosage.
- Global data is an example: small amounts of immutable global data are useful but large amounts become dangerous.
- When assessing programming habits, consider both context and dosage.
