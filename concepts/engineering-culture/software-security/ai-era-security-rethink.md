# The Pulse: Time to rethink software security because of AI?

This Pulse edition surveys a cluster of high-profile security incidents and breaches that occurred within a single day, many of them fueled by AI. The framing is that attackers gain an advantage by using AI, forcing defenders to respond and rethink software security practices (Gergely Orosz, The Pragmatic Engineer).

The issue also covers Anthropic's new version control system, which the creator of an open source high-throughput version control server accuses of ripping off their design without credit — described as a poor look for a leading AI lab. An Industry Pulse roundup touches on Saudi Arabia's "problematic" offer to pay bail for an alleged OpenAI spy, Shopify building tooling for self-healing software, Foursquare's disappointing sale, and Claude Code getting a major speed boost with gzip.

Finally, the piece highlights predictions from software engineer and Amp cofounder Thorsten Ball about the future of software development, including bold calls such as open source no longer making sense.

- A wave of security breaches and vulnerabilities hit tech in a single day, many involving AI, prompting calls to rethink software security
- Attackers are seen as gaining an edge through AI, putting pressure on defenders to adapt
- Anthropic faces accusations of copying an open source version control design without credit
- Industry notes include Shopify's self-healing software tooling and a gzip-driven speed boost for Claude Code
- Thorsten Ball's predictions include the claim that open source no longer makes sense
