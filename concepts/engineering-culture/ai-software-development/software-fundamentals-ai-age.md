# LIVE: Uncle Bob on Software Fundamentals in the Age of AI

Uncle Bob Martin, interviewed by Matt Pocock, recounts his early start in programming at age 12 in 1964 with a three-bit finite state machine. With no machine to execute code, he learned FORTRAN, COBOL, and PL1 by writing programs on paper and manually running them in his head. This foundation shaped his lifelong emphasis on software fundamentals, which later became central to his influential book Clean Code (Pocock, 2026).

Martin shares that he was initially unimpressed by AI coding tools, but around December of the previous year he tried an early Grok agent on a real project. While the AI could write code, it did a poor job and consistently left messes that he had to clean up. He describes the experience as "interesting because it's fast," but the constant need to fix AI-generated output highlighted the importance of understanding code deeply (Pocock, 2026).

The conversation implies that even as AI becomes more capable, engineers must retain core software engineering skills—such as code cleanliness and careful review—to effectively leverage AI as a fast but imperfect assistant (Pocock, 2026).

- Uncle Bob started programming in 1964 at age 12 and learned by manually executing programs on paper.
- He authored Clean Code, a highly influential book on software craftsmanship.
- His early experience with an AI agent (Grok) produced poor-quality code requiring constant cleanup.
- Software fundamentals remain essential even as AI accelerates code generation.
- AI is fast but can create messes that developers need the expertise to resolve.
