# What is Code

Unmesh Joshi argues that code serves two intertwined purposes: instructions to a machine and a conceptual model of the problem domain. The conceptual model is crucial because it provides a shared vocabulary for humans to reason about the system, enabling communication and design. Without a clear model, code becomes mere mechanical instructions, difficult to maintain or extend.

As LLMs and agents increasingly generate code, the nature of source code may shift. Joshi suggests that the conceptual model remains vital even if the textual representation changes. The model captures intent and structure, which are essential for both human and machine collaboration. The future may see code becoming more abstract, but the need for a conceptual blueprint persists, and this affects how we work with AI tools.

- Code has two purposes: instructing machines and expressing a conceptual model of the problem domain.
- The conceptual model is essential for human communication and reasoning about software.
- Programming languages are thinking tools, shaping how we approach problems.
- With LLMs, source code format may change, but the underlying conceptual model remains critical.
- Understanding code as a model helps guide how we leverage AI in software development.
