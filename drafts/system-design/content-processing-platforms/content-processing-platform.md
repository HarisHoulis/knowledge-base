# Dropbox Riviera Evolves into AI-Ready Content Processing Platform

Dropbox has evolved Riviera from a file preview service into a universal content processing platform (Kumili, 2026). The platform now supports more than 300 file formats and over 100 transformation capabilities, making it a broad system for handling diverse content types rather than only previews.

Riviera processes hundreds of thousands of transformations per second (Kumili, 2026). It supports Dropbox products including Search, Replay, Sign, and Dash, indicating the platform serves multiple internal and user-facing workloads.

The platform's APIs enable asynchronous content extraction for AI and RAG workflows (Kumili, 2026). This positions Riviera as infrastructure for AI-oriented content processing, not just traditional file preview or transformation.

- It supports more than 300 file formats and over 100 transformation capabilities.

- Its APIs enable asynchronous content extraction for AI and RAG workflows.
