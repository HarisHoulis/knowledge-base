# Beyond Zero: Google Publishes Successor to BeyondCorp

Google has published a research paper introducing Beyond Zero, described as a "security model for the AI era" that extends Zero Trust to autonomous AI agents. The approach is positioned as a successor to BeyondCorp, adapting zero-trust principles to environments where non-human actors make and execute decisions.

The core architectural shift is granularity: access decisions move from the application level down to individual resources and actions. Beyond Zero combines static authorization controls with dynamic, AI-driven decisions, allowing enforcement to occur at machine speed for both humans and agents.

- Google introduced Beyond Zero in a research paper as a security model for the AI era.
- It extends Zero Trust to cover autonomous AI agents.
- Access decisions shift from the application level to individual resources and actions.
- The model combines static authorization with dynamic AI-driven decisions.
- Enforcement is designed to run at machine speed for humans and agents alike.
