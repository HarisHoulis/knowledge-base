# APIs for Agents: Rethinking API Programs in the MCP Era

In this presentation, Jim Gough and Andreea Niculcea explain how Morgan Stanley uses Architecture as Code with CALM (Common Architecture Language Model) to modernize its API program [1]. They describe integrating Model Context Protocol (MCP) and Agent-to-Agent (A2A) communications into that program [1].

The talk also covers enforcing automated governance through deployment gates and executing zero-downtime platform upgrades, with the goal of safely scaling enterprise AI and agentic workflows [1].

- Morgan Stanley modernizes its API program using Architecture as Code with CALM.
- The approach integrates MCP and A2A communications.
- Governance is enforced automatically through deployment gates.
- Zero-downtime platform upgrades are used to safely scale enterprise AI and agentic workflows.
