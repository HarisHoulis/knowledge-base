# Announcing ActionBarSherlock Version 4.0

ActionBarSherlock 4.0 was released as a feature-complete backport of the Android 4.0 Ice Cream Sandwich action bar and its supporting widgets to Android 2.x and up [1]. The release was timed exactly one year after the first 1.0 tag, a historical milestone for the library [1].

The release lets applications integrate a 100% API- and theme-compatible action bar with very little effort, avoiding the need to interface with a custom third-party action bar or extend the ActionBarCompat sample [1]. Developers can instead focus on their app's content [1].

Within the next 48 hours, the author planned to add a migration guide for apps coming from the v3.x branch and update the website with new screenshots [1]. The library and sample applications were made available for download from the project website [1].

The author notes that some bugs still exist and may appear depending on usage, but the library is under constant development and is more stable than not [1]. He also encouraged use of the Google group for discussions and pull requests for fixes [1].

- Version 4.0 is a feature-complete backport of the Android 4.0 action bar and supporting widgets to Android 2.x and up.
- It provides 100% API and theme compatibility, reducing the need for custom third-party action bars or the ActionBarCompat sample.
- The release occurred exactly one year after the initial ActionBarSherlock 1.0 tag.
- A migration guide for v3.x users and updated website screenshots were planned within 48 hours.
- Bugs remain, but the library is under active development and the author encourages forum discussion and pull requests.
