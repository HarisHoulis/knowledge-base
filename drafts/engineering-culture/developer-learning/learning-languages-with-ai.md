# C++26 for Lazy Programmers — Will Briggs & Todd Montgomery, GOTO 2026

At GOTO 2026, Todd Montgomery interviews Will Briggs, author of "C++26 for Lazy Programmers." Briggs has taught at Lynchburg University since 1998, and the book grew out of that teaching [1]. The "lazy" label is partly humorous, aimed at readers who want to have fun, but it also carries a real engineering value: do as little work as possible, writing less but better code so there is less to maintain [1].

Asked whether learning new languages still matters given AI, both speakers argue it matters more than ever. Briggs acknowledges the recurring claims on X that software development as a profession is dead, but says he tests the tools roughly once a year (most recently Claude) and finds they handle toy problems yet never medium-difficulty tasks [1]. Montgomery argues that reading code is now more important because the code AI produces is the medium through which it responds to you — if you don't know the language, you don't know how to learn from it [1].

Both use AI daily. Briggs says it speeds up his work but can also slow him down if used unwisely, e.g. accepting a suggested fix that leads down a path he later regrets [1]. He cites his own WordPress site work as an example: without knowing PHP he could not have made the changes he wanted. People he knows in industry report the same — AI helps a little, but you still need to know the business [1]. He adds that you only become a good programmer by programming a lot, which in turn requires loving it [1].

- Learning programming languages is as important as ever; with AI, the ability to read code matters even more.
- Briggs's yearly tests of AI assistants show they solve toy problems but fail at medium-difficulty tasks.
- "Lazy" programming means writing less, better code to reduce long-term maintenance, not avoiding work.
- AI can speed you up or mislead you; unwise use of its suggestions leads to code you later regret.
- Becoming a good programmer requires programming a lot, which requires enjoying it — the book targets readers who want to have fun.
