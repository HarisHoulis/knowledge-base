# React DevTools

The post responds to criticism that React component state cannot be inspected with browser dev tools. The author points out that the official React DevTools browser extension exists and can be used to inspect component state, suggesting the critic either forgot or did not know about it. To make the tool more widely known, the author shares an 8-minute video demo of the extension, with a gif acting as a preview summary. The author notes that the video is dated and that modern DevTools are even better, and links to the egghead.io lesson "Install and use React DevTools" as part of The Beginner's Guide to ReactJS.

- The official React DevTools browser extension allows inspecting React component state.
- The post was prompted by criticism claiming there are no browser dev tools for component state.
- The author shares an 8-minute video demo of the extension and notes modern DevTools are even better.
- The linked lesson is part of The Beginner's Guide to ReactJS on egghead.io.
