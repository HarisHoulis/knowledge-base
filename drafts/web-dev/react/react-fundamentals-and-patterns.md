# Learn React Fundamentals and Advanced Patterns

Kent C. Dodds announced two egghead.io video courses: The Beginner's Guide to ReactJS and Advanced React Component Patterns (Dodds, 2017). The beginner course is free forever and targets React newbies; it focuses on React fundamentals, JSX translation to JavaScript calls and objects, and uses a single index.html per lesson to keep focus away from production tooling, ending with moving to a production environment and deploying to Netlify (Dodds, 2017).

The advanced course is subscriber-only after an initial free week and aims to teach advanced patterns for making React components more flexible, simpler, and easier to build, use, and maintain (Dodds, 2017). It progressively refactors a simple <Toggle /> component through patterns including compound components, higher order components, render props, prop collections, prop getters, component state initializers, control props, context providers, shouldComponentUpdate, and Redux with render props, highlighting tradeoffs and combinations (Dodds, 2017).

- The Beginner's Guide to ReactJS is free forever on egghead.io and teaches React fundamentals via single index.html lessons, ending with production setup and Netlify deployment.
- Advanced React Component Patterns is subscriber-only and covers compound components, higher order components, render props, prop collections/getters, state initializers, control props, context, shouldComponentUpdate, and Redux integration.
- The advanced course uses a simple <Toggle /> component progressively refactored through each pattern to show relative tradeoffs and how patterns can be combined.
- Both courses are intended to help developers understand what problems React solves and build components that are more flexible, simpler, and more maintainable.
