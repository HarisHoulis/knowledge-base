# Build a Software Pipeline: Help Your Agent Help You

Kent C. Dodds argues that we are in the age of personal software: agents now build bespoke tools that work exactly the way you want, which makes you more productive — but only if you understand what actually makes you productive and what agents can unblock you from [Dodds, 2026]. The core practice is to review everything you do today, hand that work to an agent, and then go one step further: convert what agents do today into deterministic code so the agent doesn't have to do that work either. That shift moves token spend from many dollars down to less than a penny for what deterministic software can handle [Dodds, 2026].

He describes this in terms of levels of abstraction: you move work up the abstraction ladder and on to the next step, rather than doing it yourself or paying an agent to redo it every time [Dodds, 2026].

A recurring pain point is model selection. Dodds says he hates choosing which model to use for a given task and doesn't want to babysit the "team leader" by telling it which models to use for which jobs — that's just more babysitting [Dodds, 2026]. His preference is to use a model he thinks will do the job at a reasonable price. He highlights Devin Fusion (Cognition's software development agent) as a loop that routes between models while the agent runs, using strong leadership for planning, ambiguity, and validation while cheaper assistants do the bulk of the work [Dodds, 2026].

Concrete examples of his personal packages: a release-notes generator that runs around 3:00 AM, looks at the last 24 hours, and produces notes from what entered main (used for Cody, Cody Video, and Cody Exchange); a travel map seeded from his calendar that the agent updated once, after which the agent no longer needs to be involved for new events; a memory package for files and contacts; home-maintenance reminders for appliances and filters; a visualization of commits and codebase growth; a mailroom and inbox for system email; a daily 7–8 AM Discord message linking to a morning roundup of interesting things happening that day and the day before; curtain automation control; and a check that surfaces items he can resolve by running a Cursor Cloud agent or his Grok bot [Dodds, 2026].

- We are in the age of personal software: agents build tools tailored exactly to you, and this only pays off if you know what actually makes you productive [Dodds, 2026].
- The two-step pattern: give agents the work you do today, then convert what agents repeatedly do into deterministic code — cutting token costs from many dollars to less than a penny [Dodds, 2026].
- Model selection shouldn't require babysitting; Devin Fusion routes between models during the run, with strong models for planning, ambiguity, and validation and cheaper assistants for bulk work [Dodds, 2026].
- Personal automation examples include automated release notes (last 24 hours of main, ~3 AM), calendar-driven travel map, memory store, home-maintenance reminders, Discord morning roundup, and curtain control [Dodds, 2026].
- Once a pipeline is deterministic, the agent can be removed from the loop — e.g. the travel map no longer needs agent involvement for new events [Dodds, 2026].
