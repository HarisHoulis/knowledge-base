# Teaching Engineers, Trusting AI: How Education Enabled Autonomous Code Review

Sarah Deitke explains how Duolingo drives cultural AI adoption beyond simply providing access to tooling (Deitke). The company uses internal AI literacy workshops and observability dashboards to build understanding and trust around AI systems (Deitke).

The presentation includes a case study on redesigning code review with an automated PR risk-assessment bot (Deitke). This shows how an AI workflow was introduced into an existing engineering process to support review decisions.

Deitke demonstrates that pairing targeted developer education with safe AI guardrails can speed up delivery without increasing defect rates (Deitke). The core argument is that education and trust are prerequisites for effective autonomous code review (Deitke).

- Duolingo's AI adoption strategy goes beyond tooling access through internal AI literacy workshops.
- Observability dashboards are used to support AI adoption and oversight.
- A case study redesigned code review using an automated PR risk-assessment bot.
- Pairing developer education with safe AI guardrails sped up delivery without increasing defect rates.
