# How To Write With An LLM

The post highlights Thomas Ptacek's Rule Number One for writing with an LLM: “You may not use a single word an LLM suggests to you.” Simon Willison endorses this as a form of “intellectual personal protective equipment” and advises being strict about it (Simon Willison, 2026).

Willison explains that he does not let LLMs write content for his blog, but he does use them for fact-checking, spelling and grammar, and as an occasional thesaurus. He links to his proofreading prompt as an example of that limited use (Simon Willison, 2026).

The rule appeals to Willison because LLM-suggested text “has that weird smell to it” and because it serves as a good principle to stay disciplined. The piece also notes that Thomas later shows a screenshot of his personal LLM copyediting tool, shares a prompt to help build one, and—in an update—shares his system prompt in a Hacker News comment (Simon Willison, 2026).

- Rule Number One: never use a single word an LLM suggests to you; be strict about it.
- Simon Willison uses LLMs for fact-checking, spelling/grammar, and occasional thesaurus work, but not for writing blog content.
- The rule is framed as intellectual personal protective equipment and a discipline aid because LLM text has a “weird smell.”
- Thomas Ptacek shared a personal LLM copyediting tool, a kickstart prompt, and later his system prompt on Hacker News.
