# Rebuild YouTube with AI Course Enrollment

ByteByteGo is closing enrollment for a live course called "Rebuild YouTube with AI," taught by a former YouTube engineer. The course starts Saturday, September 26, and enrollment closes in 24 hours (ByteByteGo, 2026). It is part of ByteByteGo Live, which gives 12 months of access to all current and upcoming courses.

The course covers using AI agents to build a realistic MVP of a YouTube-like application. Students learn to scope which YouTube features to build, break work into tasks, plan changes, review generated code, and recover from bad diffs or sessions that go off track. They also build across the stack: turning mockups into React pages and creating a backend with Postgres, authentication, and video uploads.

Additional topics include adding semantic search and related videos using multimodal embeddings, with discussion of how this approach differs from production recommendation systems. Students test features with Playwright, deploy to Vercel, and track watch time in an admin dashboard. The post also lists other live courses on AI evals, AI cost optimization, AI engineering fundamentals, Claude Code, production-grade AI systems, and trust-optimized AI development.

- Includes semantic search and related videos using multimodal embeddings.
- Testing with Playwright, deployment to Vercel, and an admin dashboard for watch time.
