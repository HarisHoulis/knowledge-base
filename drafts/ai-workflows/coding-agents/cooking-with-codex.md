# Cooking with Codex: Six Ways to Use OpenAI's Coding Agent

In this master class, Charlie Guo and Gabriel Chua of OpenAI's development team frame Codex as a cooking-show-style toolkit for building software. They open with examples of what people have made with it — an Ableton synthesizer plugin, video editing in Premiere, games, and a self-driving golf cart — and note that usage is spreading everywhere, including on mobile while commuting or walking a dog (AI Engineer, "Cooking with Codex").

The session highlights new capabilities meant to speed up giving Codex context: recording and playback, so users can show Codex a task rather than describing it; broadcasting a session to move work between the cloud, a remote device, and a local device; a publicly available mobile app; and device pairing for security. Other recent ingredients include plugins, desktop usage, multimodality, and app snapshots. Because Codex's code and application server are open source, it can be hosted anywhere — one user built it into three e-ink devices.

The heart of the talk is the "six ways to cook with Codex." Step one is supplying context, which lives in documents, your head, conversations, mail, Notion, and Linear. With that context, Codex can act independently: the presenter shows Codex starting to debug a browser in the background, reading slides while he speaks, and collaborating on long tasks.

- Codex is used across unexpected domains, including Ableton plugins, Premiere video editing, games, a self-driving golf cart, and e-ink devices.
- New features include recording/playback to demonstrate tasks, session broadcasting across cloud and local devices, a public mobile app, device pairing, plugins, multimodality, and app snapshots.
- Codex is open source and can be self-hosted anywhere via its application server, and existing agent configurations can be imported.
- The first of six "cooking" steps is providing context drawn from documents, mail, Notion, Linear, and the user's own head.
- Codex can act autonomously in the background and collaborate with users on long-running tasks.
