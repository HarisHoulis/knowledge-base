# Anthropic Says Nobody Needs a Mental Model of Claude Code. Practitioners Are Testing That

Anthropic published a description of how the Claude Code team reviews code now that Claude writes roughly 90% of it, including the claim that nobody on the team keeps a complete mental model of the codebase. The post documents a pull request that went through more than fifty review rounds overnight, a reviewer that spent most of its effort on pre-existing code, and a control the team says it does not yet have. The article frames these details as claims that practitioners are now testing rather than accepting at face value.

- Claude reportedly writes about 90% of Claude Code's code, shifting the team's role toward review.
- Anthropic claims no one maintains a complete mental model of the codebase.
- A single pull request ran more than fifty review rounds overnight.
- The review process spent most of its effort on pre-existing code, not new changes.
- The team acknowledges lacking a control it says it does not yet have.
