# LAST CALL FOR ENROLLMENT: Build with Claude Code

ByteByteGo is relaunching "Build with Claude Code," a 2-day intensive cohort-based course taught by John Kim, who has trained hundreds of engineers at Meta to use Claude Code in real production workflows. The course kicks off on September 16th, and enrollment closes in 24 hours.

The curriculum covers the agentic loop, context engineering, and memory layers that make Claude Code useful for real projects. It also teaches building with Claude Code Skills, MCPs, and hooks to give Claude the tools and feedback loops it needs to self-correct, plus parallel development with Git worktrees, subagents, and agent teams. A capstone project lets participants ship something real on their own stack, and the course includes live sessions, assignments, and office hours.

The post does not mention any requirement for a Claude Pro subscription. It is a promotional announcement, and a comment criticizes the $2999 price while asking whether enrollment is possible without Claude Pro.
