# We Built an AI Support Agent That Resolves 80% of Tickets

Matt Lawler, a Deployment Support Engineer at AssemblyAI, describes how demand for voice AI infrastructure led to about 1,000 API registrations per day, overwhelming a single onboarding engineer. The talk frames forward-deployed engineers (FDEs) as embedded customer contacts who help with technical and commercial needs, but notes that this manual model does not scale when inbound volume is high [source].

The team first tried a ready-made chatbot pointed at their documentation. It resolved only about 10% of conversations, so the team still had to process roughly 900 tickets per day. This made clear that a turnkey documentation bot was not enough to handle the support load [source].

The talk argues that FDEs and similar teams should automate their own work so they do not become bottlenecks, freeing time for deals that need a human approach. The resulting AI support agent is claimed in the talk title to resolve 80% of tickets [source].

- AssemblyAI provides voice AI infrastructure, including speech-to-text and full-stack voice agents, and sees roughly 1,000 API registrations per day [source].
- The manual FDE-led onboarding model does not scale when one onboarding engineer must handle high inbound volume [source].
- A ready-made chatbot connected to documentation resolved only about 10% of conversations, leaving about 900 tickets per day [source].
- The team built an AI support agent, described in the talk title as resolving 80% of tickets [source].
- The speaker advises FDEs/FTEs to automate their own work so they are not bottlenecks and can focus human effort on higher-value deals [source].
