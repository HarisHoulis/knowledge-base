# The Pulse #191: a new trend of CPU shortages

The Pulse #191 reports a new industry trend: after GPU shortages and memory shortages driven by AI companies, CPU capacity is now also becoming scarce (Gergely Orosz, The Pulse #191).

The article attributes this CPU shortage to AI agents, which use significantly more CPU through tool usage (Gergely Orosz, The Pulse #191). The practical takeaway for teams that will need more compute in the future is to secure it now (Gergely Orosz, The Pulse #191).

- After GPU and memory shortages driven by AI companies, CPU shortages are now emerging.
- AI agents are cited as a driver because they use a lot more CPU with tool usage.
- Readers who expect to need more compute in the future are advised to secure it now.
