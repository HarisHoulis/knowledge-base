# LLM 0.36 Adds New OpenAI Models and Conversation Support Controls

LLM 0.36 is a release of the LLM tool. It adds support for two new OpenAI models: `gpt-6-sol` for GPT-6 Sol and `gpt-6-luna` for GPT-6 Luna ([source](https://simonwillison.net/2026/Sep/22/llm/)).

Model plugins can now declare `supports_conversation = False` for models that only accept single-turn prompts. When these models receive assistant or tool history, LLM raises `llm.ConversationNotSupported`, and `llm chat` rejects them before starting a session ([source](https://simonwillison.net/2026/Sep/22/llm/)). The first plugin to use this is `llm-typesafe` ([source](https://simonwillison.net/2026/Sep/22/llm/)).

Reasoning traces in the Markdown output of `llm logs` are now wrapped in `<details><summary>` tags ([source](https://simonwillison.net/2026/Sep/22/llm/)).

- Adds `gpt-6-sol` and `gpt-6-luna` OpenAI model support.
- Model plugins can declare `supports_conversation = False` for single-turn-only models.
- Single-turn-only models raise `llm.ConversationNotSupported` on assistant or tool history, and `llm chat` rejects them before starting.
- `llm-typesafe` is the first plugin to use `supports_conversation = False`.
- Reasoning traces in `llm logs` Markdown output are wrapped in `<details><summary>` tags.
