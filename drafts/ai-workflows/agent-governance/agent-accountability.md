# Governing AI Agents as a Digital Workforce, Not Just Software

Tim Tyler (Gravitee) argues that organizations still govern AI agents as if they were ordinary software applications, when they should be treated as a digital workforce. He opens with a deliberately absurd job posting—no ID, no documents, no manager, shared passwords, 24/7 work, no consequences for mistakes—and notes that no one would hire a person under those terms, yet this is effectively how many organizations deploy agents today. The tension is real: a CTO may say an agent "isn't really a software application," while HR insists it is, leaving AI leaders torn.

- Agents are currently governed like software, but behave more like employees, requiring workforce-style management
- Every agent needs a unique identity in a shared registry as the single source of truth
- Each agent needs a named human sponsor who owns its purpose, budget, and accountability
- Agents should be treated as teammates with shared context, not digital clones of their operator
