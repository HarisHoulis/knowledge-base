# Building a Zero-Dependency Web UI for Gemini Live Audio

Google released Gemini 3.8 Live and 3.8 Live Extended Thinking, two speech-to-speech models shaped similarly to OpenAI's GPT-Live family (source). Simon Willison used GPT-6 Astra Extra High pointed at the documentation to generate a browser UI for trying the new models (source).

The resulting tool lets a user select a model and voice preset, enter an optional system prompt, and start a voice conversation in the browser, including the ability to interrupt the model while it is talking (source).

The implementation uses no libraries (source). It connects to the `wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1alpha.GenerativeService.BidiGenerateContent?key=...` WebSocket endpoint and uses the Web Audio API `AudioContext` for both capture and playback (source). A Gemini Live tutorial is referenced for getting started with that WebSockets API (source).

- Gemini 3.8 Live and 3.8 Live Extended Thinking are new speech-to-speech models analogous to OpenAI's GPT-Live family.
- The demo UI supports model and voice selection, an optional system prompt, and interrupting the model mid-speech.
- The client is library-free: a raw WebSocket connection to the Gemini BidiGenerateContent endpoint plus Web Audio API AudioContext for capture and playback.
- The UI itself was generated by pointing GPT-6 Astra Extra High at the Gemini docs.
