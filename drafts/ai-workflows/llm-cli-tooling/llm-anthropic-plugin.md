# llm-anthropic 0.29 adds Claude Opus 5.5 support

Version 0.29 of the llm-anthropic plugin adds support for Anthropic's Claude Opus 5.5 model, making it callable from the llm command-line tool via `llm -m claude-opus-5.5 "prompt goes here"`. The release is dated 22nd September 2026.

The release lands the same day as an article covering "Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, and a new price war", indicating the plugin was updated promptly alongside the model announcement. Other recent posts on the same blog cover Jev's "System One" / Decision Models and generating running routes with GPT-6 Astra and ChatGPT Work.

- llm-anthropic 0.29 adds Claude Opus 5.5 as an available model.
- Usage is via the llm CLI: `llm -m claude-opus-5.5 "prompt goes here"`.
- Released 22 September 2026, the same day as the Claude Opus 5.5 / GPT-6 Sol / GPT-6 Luna price-war announcement.
