# Context Engineering at LinkedIn: An Organizational Context Layer for AI Agents with MCP

Ajay Prakash presents how LinkedIn addressed the limitations of AI agents working in large codebases (InfoQ). Rather than relying on agents' inherent capabilities alone, LinkedIn built a context layer to supply them with organization-specific knowledge.

The solution is Contextual Agent Playbooks and Tools, built on the Model Context Protocol (MCP). It serves procedural memory, code search, and runbooks directly to coding agents (InfoQ).

Prakash shares the architectural details of this context layer along with the operational guardrails used to run it. The reported outcome is a 20% productivity boost with zero loss in reliability (InfoQ).

- AI agents are limited when operating in large codebases, motivating a dedicated context layer.
- LinkedIn's Contextual Agent Playbooks and Tools are built on the Model Context Protocol (MCP).
- The layer delivers procedural memory, code search, and runbooks directly to coding agents.
- Reported results: 20% productivity boost with zero loss in reliability.
- The presentation covers architectural details and operational guardrails.
