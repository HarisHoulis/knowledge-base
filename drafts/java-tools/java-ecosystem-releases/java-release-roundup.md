# Java News Roundup: TornadoVM 7.0, Groovy 6.0, GraalVM, Hibernate, Quarkus, Gradle, Maven

The Java News Roundup for the week of September 21st, 2026, reports several notable releases across the Java ecosystem (Redlich, 2026). TornadoVM 7.0 and Groovy 6.0 reached general availability, while GraalVM and Gradle issued point releases (Redlich, 2026).

Quarkus and GDK for Micronaut received maintenance releases, and Maven 4.0 reached its seventh release candidate (Redlich, 2026). Micrometer Metrics and Tracing published milestone releases, and Open Liberty and Hibernate ORM issued beta releases (Redlich, 2026).

- TornadoVM 7.0 and Groovy 6.0 reached GA (Redlich, 2026).
- GraalVM and Gradle shipped point releases (Redlich, 2026).
- Quarkus and GDK for Micronaut got maintenance releases (Redlich, 2026).
- Maven 4.0 reached its seventh release candidate; Micrometer Metrics and Tracing published milestones; Open Liberty and Hibernate ORM released betas (Redlich, 2026).
