# Java News Roundup: TornadoVM 8.0, JNoSQL, Endive, JReleaser, JBang, LangChain4j, Quarkus Almanac

This InfoQ roundup covers Java ecosystem news for the week of October 26th, 2026, headlined by the GA release of TornadoVM 8.0, a tool for accelerating Java workloads on GPUs and other heterogeneous hardware. Alongside it, several projects shipped point releases, including JNoSQL, Endive, JBang, JReleaser, and LangChain4j.

JobRunr issued a maintenance release, while Hibernate ORM and Hibernate Reactive both moved forward with beta releases. The roundup also introduces the Quarkus Almanac, a new resource for the Quarkus community.

The article is a brief news digest rather than a technical deep dive, so it primarily serves as a pointer to the individual project announcements for details on features and fixes.

- TornadoVM 8.0 reached general availability
- Point releases for JNoSQL, Endive, JBang, JReleaser, and LangChain4j
- JobRunr shipped a maintenance release; Hibernate ORM and Hibernate Reactive issued betas
- The Quarkus Almanac was introduced to the community
