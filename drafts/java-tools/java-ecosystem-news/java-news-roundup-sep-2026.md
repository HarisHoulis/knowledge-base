# Java News Roundup: JDK 27, Open J Proxy, A2A Jakarta, Azul Payara, BoxLang, Netflix ja

The Java news roundup for September 14th, 2026 highlights several releases and updates across the Java ecosystem [source: InfoQ]. JDK 27 and LibericaJDK 27 reached general availability, alongside the 1.0 releases of Open J Proxy and A2A Jakarta [source: InfoQ].

The roundup also covers point releases for Azul Payara, JHipster, JetBrains Ktor, and BoxLang [source: InfoQ]. Additionally, Netflix introduced 'ja', described as a modern JMS command line development experience for Java developers [source: InfoQ].

- JDK 27 and LibericaJDK 27 reached GA.
- Open J Proxy 1.0 and A2A Jakarta 1.0 were released.
- Point releases arrived for Azul Payara, JHipster, JetBrains Ktor, and BoxLang.
- Netflix introduced 'ja', a modern JMS command line development experience for Java developers.
