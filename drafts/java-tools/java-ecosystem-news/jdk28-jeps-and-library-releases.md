# Java News Roundup: JDK 28 JEPs, Azul Payara, Gatherers4j, Google ADK, and Apache Camel CVEs

This roundup covers the week of October 12th, 2026 in the Java ecosystem. Three OpenJDK JEPs were targeted for JDK 28, signaling early planning for the next feature release. The October 2026 edition of Azul Payara was also announced.

Several libraries shipped point releases: Gatherers4j, Yupiik Fusion, Google ADK for Java, and Google ADK for Kotlin. Notably, Google's agent development kit now has parallel Java and Kotlin offerings.

On the security side, 38 CVEs were resolved in Apache Camel, a substantial batch of fixes worth attention for teams running Camel-based integrations.

- Three OpenJDK JEPs were targeted for JDK 28.
- Azul Payara released its October 2026 edition.
- Point releases arrived for Gatherers4j, Yupiik Fusion, and Google ADK for both Java and Kotlin.
- Apache Camel resolved 38 CVEs, a significant security update for Camel users.
