# Java News Roundup: New OpenJDK JEPs, CDI 5.0, Spring, Open Liberty, RefactorFirst, ADK for Kotlin

The September 7th, 2026 Java roundup highlights new OpenJDK JEPs covering ahead-of-time compilation and structured concurrency (Michael Redlich, InfoQ, 2026-09-14). These JEPs represent the most notable platform-level developments of the week.

On the release front, the roundup reports GA releases of Jakarta CDI 5.0 and ADK for Kotlin 1.0, alongside the September 2026 edition of Open Liberty and point releases of TornadoVM and RefactorFirst (Michael Redlich, InfoQ, 2026-09-14). A maintenance release of Micronaut is also included.

Rounding out the week, first release candidates of Groovy 6.0 and Gradle 9.8 were announced, and coverage touches on Spring (Michael Redlich, InfoQ, 2026-09-14).

- New OpenJDK JEPs proposed for ahead-of-time compilation and structured concurrency.
- Jakarta CDI 5.0 and ADK for Kotlin 1.0 reached GA.
- September 2026 Open Liberty edition released, plus point releases of TornadoVM and RefactorFirst and a Micronaut maintenance release.
- First release candidates of Groovy 6.0 and Gradle 9.8 announced; Spring also featured.
